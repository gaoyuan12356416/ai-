# 独立手机版（2026-11-07）

用户选择现有域名下独立私有入口，原报表及其他文件不调整。手机版位于现有保护目录的`mobile/`子目录。

`index.html`从本话题当前主报表派生，只增加相对base、手机版标题和提示、样式及展示辅助JS。原有全部内联业务脚本保持字节一致，已有外部JS、数据及localizations文件不修改。

`<base href="../">`让手机版直接使用父级数据和规则文件。不得将其改成固定域名；COS私有存档包含同样的父目录资源。后续刷新父数据即可被手机入口使用，无定时器、自动任务、媒体写操作或数据查询。

mobile.css仅调整排版、点击区域、弹窗和表格卡片；mobile-view.js只增补表头文字标签、阶段外层details折叠容器及滚动/关闭导航，不改表格值、表格内部节点次序、过滤器值、确认状态或复制结果。不要把表格转换成脱离原DOM的新业务组件。

验证：360/390/430手机宽度及1440原版，同筛选下榜单和KPI一致、36条确认素材及35个复制ID一致，AF D0等列显示一致，取消勾选使复制失效，无页面JS错误。页面及素材弹窗无横向溢出。保留小语种校验、Top+Good及复制类型。

三种手机宽度均通过阶段折叠展开、复制区定位、小语种全选/半选、语言切换清空选择和3个ID复制回归，无JS错误，小语种弹窗无横向溢出。

发布时只添加新mobile目录，不替换原站任何现有文件。上线前后校验整个原站baseline哈希。原父路径的Feishu鉴权覆盖子目录，无需改nginx、owner配置或重启服务。

回滚：确认mobile目录仍属于本版本后，将精确目录移动回本次数据盘工作目录的rollback-mobile；原报表和业务数据无需回滚。GitHub分支为codex/yuesiying-mobile-20261107。
