# 测试用例

- 租户/普通用户/人员/剧名/语言/频道筛选与原聚合结果、CSV一致。
- 全局同 ID 冲突不能被人员筛选隐藏；保留已知 32 字符别名。
- 单 ID 56 天查询一次索引读取，较大 ID 范围分为不交叉 14 天段，ID 使用 c_id_dt 和精确 BINARY 比较。
- 空候选仍验证源日期；无匹配为零，缺失日为 null。
- 覆盖或中间批次超时整来源不可用，失败不缓存；成功缓存含 ID 集和站点。
- 超过总行数、重复行、越界日期、站点和 ID 不匹配拒绝成功。
- 独立日报继续原采集契约，Facebook 保留冻结 Page/素材范围。
- 生产指定 Post 的长范围 UI/API/CSV对齐独立 SQL；8 个历史源缺失日不可伪装为完整。
