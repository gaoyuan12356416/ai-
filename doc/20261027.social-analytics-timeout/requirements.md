# 社媒看板查询超时修复

用户授权修复、上线，并使用指定 YouTube Post 与 2026-09-01—2026-10-26 UTC 验收。症状：筛选单个剧目仍聚合整站 56 天，触发 MySQL 3024，效果指标为空。

设计：仅对网页 YouTube/X 查询按完整冻结目录生成候选 campaign ID，再应用原有用户权限及筛选。全局目录仍交给归属校验，保留别名冲突、成功发布日期和手动短链规则。查询使用已有 c_id_dt 索引，每批最多 100 个 ID；不超过 10 个 ID 时读取完整索引范围，较大范围每段最多 14 天；语句保持 8 秒，整个网页采集最多 40 秒。覆盖日期用 sd 索引单独读取。失败不缓存、不返回假零；范围内源缺失日期继续提示。

验收：目标长范围页面、API、CSV 均显示实际访问/点击/安装/收入；保留真实缺失日。其余人员/租户不可见；独立日报 release、发布账本、短链不变。不得用延长数据库超时或全站扫描替代。
