# 测试用例

## 测试范围

候选选择、账号子集、原子建队列、FIFO/短剧归属、重入、完成计数、零候选与既有安全失败。

## 测试数据

全部为临时 SQLite、Fake Sidecar 和 Mock 媒体预检；不调用真实 X 写接口。
