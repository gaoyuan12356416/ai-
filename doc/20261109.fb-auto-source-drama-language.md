# DramawaveSource 空语言回退

DramawaveSource 视频的语言经常为空，而 `data_source_id` 已关联目标产品的 `ads_drama_info.content_id`。原筛选只比较素材语言，因此即使关联剧目语言与 Page 一致也没有候选。

素材自身语言优先。仅当素材产品为 DramawaveSource 且语言为 NULL、空串或空白时，使用目标 `app_id` 下关联剧目的语言。自动选材沿用现有元数据规则，在已上架、已到投放时间、模板上线窗口及类型条件内选择最新记录；指定素材入口沿用其已上架/已到投放时间规则。没有有效关联语言的素材局部跳过或显示原入口的明确错误，不猜测语言、不写回素材库。

普通分页和指标优先查询都先保留缺语言的来源行，经关联元数据读取后再做 Page 语言匹配。只有语言匹配后的候选进入排序、保留数量与每剧数量计算；简介查询使用最终语言。其他产品、非空素材语言、黑名单、时长、指标、冷却、授权、共享池、回执和写入保护保持原规则。
