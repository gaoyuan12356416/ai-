# 测试用例

|范围|验收|
|---|---|
|模板字段|仅描述/三项全填/全部空/纯空白，空值不覆盖发布原值|
|共享和隔离|同租户普通发布人互读写，不同租户模板隔离|
|并发|首次并发写仅一次成功；旧version返回409，清空仍递增|
|身份/安全|频道变更或移除拒绝；非法宏/长度/类型拒绝；无Cookie、无模块/导航权限、跨域保存拒绝；DTO不泄露凭证|
|频道目录|独立于素材配置，异常频道可编辑；搜索ID/名称；授权/首评检查状态不误当发布许可|
|草稿|选择套用、允许手改、切换空字段保留当前内容、迟到响应不串频道；读取失败保留文本并禁止提交，重试恢复|
|冻结|提交最终手改值；以后改模板与同operation_id重试不改已提交任务|
|UI|桌面和390px手机、编辑器滚动、共享导航、模板字段摘要和修改人|
|回归|宏/首评权限/封面审核/预约/幂等/已有worker相关测试；浏览器预约和轮询竞态|
|上线|GitHub exact SHA、备份、两份静态、窄重启、健康、只读业务核验；回滚保留数据库并拒绝漂移|
