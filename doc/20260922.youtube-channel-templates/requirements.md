# YouTube 频道列表与自定义模板

2026-09-22 用户确认并授权实现、GitHub-first 部署。

## 行为
同租户每个真实频道共用一份标题、视频描述、首评模板；所有有 YouTube 权限的发布人可维护。新建发布选择频道时，按字段覆盖非空模板；纯空白不覆盖。切换频道保留新模板空字段对应的表单当前值，不恢复初始值。带入后允许手改。现有默认描述仍是初始值。第一版不增加封面要求、发布时刻等配置。

模板保存、后台频道刷新、任务提交和 worker 执行均不重新套用模板。任务冻结提交文案，后续模板修改不影响草稿或历史任务。宏复用 {name}/{desc}/{url}，提交时展开并校验最终长度。

## 页面
YouTube 社媒新增频道列表，展示名称、真实 ID、频道链接、授权状态和原因、首评权限、核验时间、模板摘要和修改人/时间；支持搜索与刷新。编辑模板三个字段均可空，全部清空表示不覆盖。编辑授权失效频道不触发发布预检。新建发布等待模板时禁用三个文案字段及提交；失败保留当前内容、阻止提交并允许重试；迟到响应按草稿对象和请求对象隔离。

## 数据与权限
SQLite 新增 youtube_channel_template，主键 tenant+channel_id；同租户共享、跨租户隔离。API 路径里的 local_id 由服务端按 app_id=1479 重新查频道，保存请求还必须匹配真实频道 ID。版本 CAS 防止并发覆盖。复用 Cookie、youtube_auto_publish 模块、导航鉴权及 same-origin JSON 写入约束。频道列表不依赖素材 SQL 配置。不改 MySQL、发布账本、短链、封面审核、预约及平台写入语义。
