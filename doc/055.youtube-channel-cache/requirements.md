# YouTube 频道鉴权与读取缓存

2026-09-11 用户要求：现有频道真实鉴权，失败标注且不能选；优化工作台初始加载、频道及素材读取。

频道读库后以 OAuth 刷新、实际 scopes、channels.list(mine=true) 精确身份与 longUploadsStatus=allowed 预检。eligible 仅代表有资格开通，需要手机验证，不等于 allowed。停用/凭证缺失/授权失效/身份冲突/权限不足/长视频未开通/未知全部禁选，保留可见原因和独立检查时间。自定义封面缺少只读资格API，不承诺最终平台发布成功。

最近 thumbnails.set 403 forbidden 作为独立已知拒绝事实阻断。以不可变 thumbnail/succeeded 事件解除，不能使用其他操作更新的任务更新时间。管理员在 Studio 确认功能后可明确提交人工核验，仍需当前实时鉴权通过；审计绑定频道与具体失败时间，新失败重新阻断，刷新Token不能自行清除。既有 unknown 视频不重新上传。

频道快照300秒TTL，4个并发预检，每轮只读一次账号列表；新建提交、审核后入队均实时校验选中频道，缓存不能授权写入。频道变更不改旧任务冻结身份。

素材按 SQL全文+规范化搜索词缓存，300秒TTL、最长900秒旧值、最多32项、最多2个后台读取；冷miss返回正在更新，过期先显旧值后台更新，错误明确显示，SQL变更隔离旧缓存。source.get始终实时读库，搜索在SQL LIMIT100前执行。业务数据不存浏览器持久缓存。

验收：无真实测试视频、封面设置或首评；正常鉴权/失效/串号/未开通/未知/人工确认权限均验证；UI不闪屏、旧搜索不覆盖；生产比较同一只读接口冷/热耗时、保留任务和通知。
