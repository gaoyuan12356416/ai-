# FB 自动发布模板：独立素材产品

模板编辑页新增可选择或输入的「素材产品」，常用选项为 `DramawaveSource` 和 `Dramawave`。保存为 `config.material_product`，自动选材的普通分页、指标优先查询和指定素材发布均按该字段匹配 `ads_custom_source.product`。

Page 池仍决定目标 `app_id/product`、剧目上架/简介查询、效果指标产品和原短链归因。旧版本缺少新字段时沿用目标产品，不迁移或自动修改线上模板，不启用模板，不创建验收发布任务。素材语言、时长、删除状态、黑名单、发布权限和原任务保护规则保持原有业务含义。

python scripts/test_fb_auto_material_product.py -v

六项后端用例覆盖：保存/读取/编辑、服务器目标映射不覆盖选择、旧模板兼容、字段校验、两条自动候选查询及指定素材校验。UI 用例执行真实编辑脚本，验证旧配置回显、选择、保存、重新载入和其他产品名称，保持频次与版本字段。

## GitHub-first 部署和回退

分支 `codex/fb-auto-material-products-20261109`。在服务器从 GitHub 检出精确提交后：

```bash
python3 scripts/deploy_fb_auto_material_product.py prepare --folder /mnt/data-disk/fb-auto-material-product-20261109/deployment
python3 scripts/deploy_fb_auto_material_product.py activate --folder /mnt/data-disk/fb-auto-material-product-20261109/deployment
```

部署复制当前 FB runtime，仅覆盖两个业务 Python 文件及编辑页 HTML/JS，保留其它并行修复；同步主 API 和 Nginx 的两份静态资产，更新脚本缓存版本。主 API 的旧 FB 自动发布仓库不是该功能的执行副本，不覆盖或重启主 API。

部署目录保存文件哈希、原版本、在线 SQLite 备份及依赖调度器快照。使用既有 FB HTTP 请求排空和安全切换脚本，只切换 FB sidecar，恢复原本活动的关联触发器，并验收 FB 调度健康。未完成平台请求与当前账本不重置，未改数据库结构。

```bash
python3 scripts/deploy_fb_auto_material_product.py rollback --folder /mnt/data-disk/fb-auto-material-product-20261109/deployment
```

回退恢复代码/静态文件，不恢复旧数据库。如果当前配置或未完成批次已经使用不同于目标产品的素材产品，旧代码会改变选择含义，脚本拒绝直接回退；此时保留兼容选择器，先明确处理这些配置/任务。
