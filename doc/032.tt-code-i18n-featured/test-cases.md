# 测试用例

## 测试范围

覆盖语言解析、UI 文案、分语言缓存安全、Featured 展示与点击、搜索跳转以及旧 `/tt` 兼容。

## 测试数据

- 浏览器标签：`en-US`、`zh-CN`、`zh-TW`、地区语言、未知标签、空值。
- 语言快照：完整英文/中文桶、缺桶、少于 5 条、重复 ID、陈旧时间、非法封面、含消耗字段。
- 搜索：有效 code、有效剧 ID、404、429、超时和无发布记录通用回退。
