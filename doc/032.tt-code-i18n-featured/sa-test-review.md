## 补充要求

- 生产只读 canary 需证明单次全语言查询的语法、耗时和行数上限。
- 真实浏览器至少覆盖 `en-US`、`zh-CN`、`zh-TW` 和 `ar`。
- Featured 单击测试必须拦截导航，禁止为了验收产生任何发布行为。
- 部署后同时核验旧 `/api/public/tt-drama/featured` 和新 bundle，避免误覆盖旧 schema。
