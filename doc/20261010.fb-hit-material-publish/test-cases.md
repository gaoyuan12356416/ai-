# 验收用例

- 单个有效ID覆盖不同语言以及未设语言的Page，各一条相同素材；重复Page拒绝。
- 暂停、缺授权、历史unknown、活动相同素材、14天历史素材分别跳过，其他Page可入队；全跳过有回执。
- 不同用户范围/版本/停用/总开关/预制开关/重叠池/容量变化拒绝。
- 同ID重复提交和两个store并发各只创建一次；同操作不同请求冲突；其他操作仍受活动素材占用限制。
- 原请求已提交但丢响应后，改模板/源库甚至关闭开关，再同操作重试仍返回原run；审计后的400保持浏览器操作ID。
- 冻结摘要或任务赋值篡改禁止执行；prepare/claim走真实代码并保持跨语言；Graph未知结果不能重放。
- 精确素材不存在/非视频/已删/产品不符/剧集未开放/黑名单/简介冲突拒绝；时长缺失探测成功可用，失败/超时/过长拒绝。
- 列表旧启停和手动执行不变；既有每日频次文字/随机时间配置不变。
- 浏览器空白、多ID输入拒绝；重复点击只一请求；刷新后恢复；成功展示中文跳过原因、运行详情；storage不可用时不发送。
- 部署仅指定文件、GitHub精确提交、旧文件/SQLite备份、无在途任务才重启；发布前后账本和模板哈希一致；恢复原timer状态。
