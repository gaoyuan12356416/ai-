# 爆款素材发布

2026-10-10，Asia/Shanghai。用户要求在 FB 模板列表操作栏新增【爆款素材发布】，输入单个素材 ID 并确认后，为模板配置的每个 Page 各发布一次同一素材。

用户已确认：跨语言覆盖；保留暂停和同素材 14 天去重，展示跳过原因；作为独立手动加发，不占用日常自动发布次数。

沿用模板随机排重制作、文案、短链和发布账本。保持有效授权、来源视频/剧集资格、黑名单、容量、活动素材占用及未知发布结果保护。Page 局部不可用只跳过对应 Page；共享数据源失败则整轮拒绝。模板停用时按钮禁用；服务端复核身份范围、版本和开关。

仅实现并部署能力，不因开发验收发送真实 Facebook 帖子。部署不修改模板配置、日程或已有发布事实。

交互：按钮 -> 素材 ID 输入框 -> 确认发布 -> 本轮编号、排队数、跳过数和逐 Page 原因 -> 直接打开本轮发布记录。可再发另一个素材。网络中断和页面刷新沿用原 operation_id 查询/完成同一轮。

实现：既有 POST templates/{id}/run-now 增加三个字段的精确素材形式；现有两字段的自动选材手动执行不变。SQLite BEGIN IMMEDIATE 事务按 Page 冻结素材、配置和跳过事实。run.config.hit_material_publish 记录不可变摘要及请求回执；不新增业务表。

验收：各语言 Page 使用同一指定素材；每个 Page 最多一任务；暂停、授权、未知、活动占用、14天冷却分类可见；不因失败或重复点击重复入队；素材时长缺失可只读探测；保留旧自动/手动CLI行为。
