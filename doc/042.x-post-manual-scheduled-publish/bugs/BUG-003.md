# BUG-003 主 API 并发部署覆盖手动发布时间字段

## 严重级别

P1。

## 现象

2026-08-12 16:35:56 和 16:36:05，两次生产手动发布请求均返回 HTTP 400：`手动发布请求字段不完整或包含未知字段`。立即发布和定时发布都无法创建任务。

## 影响边界

请求在主 API 字段校验层终止，未进入 X Sidecar；`x_post_manual_run`、queue、publish log 和真实 X Post 均未新增。

## 根因

X 定时发布部署后，另一项 TT 自动发布“强制关闭”主 API 补丁从较旧的 `app.py` 基线部署，覆盖了 X 路由对可选 `publish_mode`、`scheduled_at` 字段的支持。Sidecar、静态页面和 X 数据库仍保持正确版本。

## 修复

- 以 X 定时发布提交 `11db78a96af86ea776af85be96f225caf47eb21b` 为基线，重放 TT 强制关闭主 API 补丁。
- 保留 X 路由的 required/allowed 字段分层校验和发布时间透传。
- 在 TT 主 API 契约套件加入跨功能回归，要求 TT overlay 同时保留 X 的 `publish_mode`、`scheduled_at`。
- 生产只替换 Git 提交中的 `app.py` 与 TT client，并仅重启主 API；不切换 X Sidecar、不改 SQLite/Token/Timer。

## 验证要求

- X 与 TT 主 API 契约测试同时通过。
- 匿名立即/定时请求均只到达 Cookie 鉴权并返回 401，不得因字段集合返回 400。
- 主 API 健康为 200，TT 强制关闭 route 仍存在。
- X manual/queue/log/Post 计数保持不变；不得创建真实发布任务作为部署 canary。

## 验证结果

- X/TT 主 API 契约 39 项、X 手动发布/runner/UI 相关 40 项全部通过，没有真实 X 请求。
- 生产于 2026-08-12 16:53:51 +08:00 仅重启 `drama-material-api.service`；新 PID `3291043`，主 API 健康为 200。
- 立即和定时完整字段 payload 的匿名生产边界请求均返回 `401 auth_required`，没有再返回字段集合 400。
- 部署前后 manual/queue/log/confirmed Post/unknown 均为 `7/182/182/181/0`，active reservation 为 0；未创建任务或 Post。
- X Sidecar 仍是 `11db78a96af86ea776af85be96f225caf47eb21b`，PID/启动时间未变化；15 个 Token 的哈希、`0600` 权限和 owner 均未变化。

已修复并关闭。
