# 测试用例

## 测试范围

- 页面入口和权限。
- 任务创建、编辑、发布、复制、删除。
- 状态流转和审核。
- 素材上报字段映射。
- 密钥不泄露。
- 本地语法检查。

## 测试数据

- 管理员账号：使用现有飞书 admin 登录用户。
- 普通用户账号：使用管理员授权后的普通用户。
- 产品：从 CPU 服务器产品权限查询返回的任意可用产品。
- 国家/语言：`MX/es`、`US/en`。
- 任务数量：1、20、0、21。
- 参考素材：任意 jpg/png 测试文件。
