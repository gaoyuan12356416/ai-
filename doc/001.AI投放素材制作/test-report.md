## 遗留风险

- 本地 Windows 没有线上 mysql 客户端，`admin_user_group` 映射只能在线上 CPU 服务器验证。
- `AD_MATERIAL_REQUIREMENT_COMMAND` 和 `AD_MATERIAL_GENERATION_COMMAND` 当前为可配置适配层，本地默认走占位需求/占位素材，真实生成需要线上命令接入。
- 最终上报接口需要使用部署环境 token 做一次端到端验证。
