# DramaWave 人工图片效果对比

需求：在现有 AI 图片日报中单列 DramaWave 非 AI 来源图片，与 AI 图片比较投放效果。

实现与口径见 `ops/ai-image-daily/README.md`。变更仅影响独立日报采集、静态报告和同日修订发布，不改广告、素材或发布业务队列。来源待核对和 AI 接口导入未验证图片不会混入人工。三产品原 AI 指标保留。

本地验证：`python -B -m unittest discover -s ops/ai-image-daily -p '*test*.py' -q`（122 项）、`node --check ops/ai-image-daily/report.js`、`git diff --check`。覆盖人工/AI 来源排除、同应用效果、共同投放单元、七日去重和加权比例、查询完整性、修订未知结果恢复和原历史快照保留。浏览器验证昨日/七日、共同范围、产品切换及窄屏。

部署：GitHub 推送精确 SHA 后，CPU 43.166.187.96 的 `/mnt/data-disk/deploy/ai-image-daily/repo.git` fetch 该分支，archive `ops/ai-image-daily` 与此文档到 `releases/<SHA>`；先以 `deploy.validate_release` 核对 Git blob，再从该 release 使用现有 `/mnt/data-disk/ai-image-daily-v3` 状态运行 `report.py --revision --prepare-only`。检查冻结报告、库存/事实分区和校验结果；确认日报 service 空闲后仅暂停日报 timer，执行该版本 `deploy.py --repo ... --expected-commit <SHA>`。通过 `--publish-prepared` 发布同一冻结批次，验证公网 SHA、历史原版、对比数据和网页交互，再恢复原 timer。无主 API 或发布服务重启。

回滚：使用部署器返回的安装备份运行本次 release `deploy.py --rollback <安装备份>`。若需恢复旧首页，再以本次 release `report.py --state /mnt/data-disk/ai-image-daily-v3 --restore-public <本次发布备份>` 回退可变入口。验证后 `systemctl enable --now ai-image-daily.timer`。保留所有历史快照、修订版、素材事实和账本，不恢复旧业务数据库。
