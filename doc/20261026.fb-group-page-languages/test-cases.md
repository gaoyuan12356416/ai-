# 测试用例

1. 全部有语言、指定单/多语言、仅空语言、指定语言加空语言、全部不选拒绝；保存回读及旧客户端不擦除配置。
2. 多组重复、空加非空、全空、不同非空冲突、非法非空、别名及三种中文区分；筛选前聚合，筛选后授权，完整组选集权限。
3. 同语言优先，空语言取余下其他语言，最新优先；无料/不足/额度/unknownPage下执行可用子集，不重复占用。
4. 旧v1配置/任务、随机持久计划保持，v1首次保存v2暂停，语言改变暂停，冻结后成员/权限/语言属性变化失败并保留占用。
5. 目标预览分页、搜索仅显示、权限、并发及幂等、陈旧响应/重复请求；手机390px、桌面1440px。
6. 增量迁移排练、旧列投影哈希不变、部署白名单与漂移保护；真实来源与页面只读预览，不入池/保存/启用或发测试帖。
