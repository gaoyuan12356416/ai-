# BUG-001 素材排期可修复媒体未进入 GPU 重制

## 发现阶段

2026-08-24 生产 run 318 台账核查。

## 现象

7 条 `invalid_media_codec`、2 条 `invalid_media_dimensions`，全部在 X 上传前失败；repair 审计字段为空。

## 复现步骤

1. material schedule 选择一个编码或尺寸不合规素材。
2. scheduler 以 deferred 空指纹创建 queue。
3. Sidecar 发布阶段下载/probe。
4. probe 直接终结 queue，不调用 GPU repair。

## 期望结果

建队前识别两类错误，完成 GPU 重制和二次校验后再冻结 queue。

## 实际结果

queue 先冻结，最终 probe 只记录失败。

## 根因分析

052 为降低到点头阻塞，把 material schedule 改为 metadata-only deferred；已有 `_preflight_candidate` repair 分支不再被 schedule runner 调用。

## 修复说明

material schedule 重新调用 `_preflight_candidate`，共享跨页 repair budget；成功输出显式冻结为 preflight，失败继续扫描。

## 影响文件

- `scripts/x_post_schedule_runner.py`
- `scripts/test_x_post_schedule_runner.py`

- py_compile、git diff --check：通过。
