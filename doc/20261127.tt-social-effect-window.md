# TT 模板社媒统计窗口

`metric_window_days` 同时用于广告与社媒筛选、排序；按选材时北京时间计算此前 N 个完整日期。X/Facebook 浏览互动读取日末可用累计观测的差额，缺起止快照、过期或回落为未知。收入按相同日期范围的源 UTC 发生日汇总；TT 自身仍只支持归属收入。

TT 画像保留原完整性规则，并独立保存 `profiles/social-income.json` 的逐日收入。窗口查询保留人员、租户、产品、语言与素材身份限制；不以累计值或零填补缺日。任务冻结窗口与待补收入日期，既有任务不重算、不重发。

测试：`python -B -m unittest tests.test_tt_promotion_effects tests.test_tt_promotion_social_metrics tests.test_tt_promotion_publishing -q`；JS 语法校验。实际日期/渠道/旧快照未知与权限均有隔离验证。
