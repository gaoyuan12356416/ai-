# BUG-001 自动发布未按剧语言选择账号

## 发现阶段

需求分析与代码基线审计。

## 现象

素材具备 `material_language`，账号设置没有剧语言。素材入池时先按素材 ID hash 绑定一个自动账号，正式调度再按该账号分池领取，因此系统无法保证素材剧语言与最终账号一致。

## 复现步骤

1. 配置两个自动账号。
2. 加入一条 `material_language=es` 的素材。
3. 当前服务在解析素材语言前按素材 ID hash 选择账号并写入 intake。
4. 到期调度仅执行 `WHERE account_id=? AND status='available' ORDER BY created_at,id`。

## 期望结果

自动到期账号只领取与其当前 `drama_language` 精确匹配的语言 FIFO；无匹配时素材继续等待且不创建 queue。

## 实际结果

账号选择与素材语言无关；账号改语言后，旧分片也不会动态重匹配。

## 根因分析

028 为去除入池阶段的账号能力依赖，选择了“入池时稳定分配账号、素材池按账号分片”的兼容方案。当时账号模型没有剧语言，也没有发布时跨池选择要求。

## 修复说明

- 账号设置新增默认 `en` 的 `drama_language`。
- 自动运行按当前账号语言跨全池原子领取同语言最老 `available` 素材。
- 无匹配保持等待，不 fallback。
- 领取时冻结实际账号和该账号当前 `is_aigc`。
- 手动立即发布/canary 继续使用精确账号分池。
- active manual canary 的精确素材从其他账号自动候选中排除。
- 自动匹配使用持久规范路由键和复合 FIFO 索引；非法历史语言隔离而不阻断池。
- 已有 run/queue/publish_id 不重新选材。
