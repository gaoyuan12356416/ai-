# 044.x-account-language-routing 需求与技术设计

## 背景

X 账号此前没有内容语言属性。X Auto 模板、素材池和短剧池只能在已配置账号内按既有顺序发布，无法保证内容语言与账号运营语言一致。生产现状中，账号 19、20 承接日语模板，历史模板使用 `jp`，而标准语言代码是 `ja`。

## 目标

1. X 账号列表新增“剧语言”下拉列，新账号默认 `en`。
2. X Auto 模板、素材池定时发布、短剧池定时发布只向同语言账号生成新任务/队列。
3. 历史任务、队列和随机计划不改写；账号语言只影响后续新生成执行事实。
4. 长视频 Premium 中继账号必须与目标内容同语言。

## 范围

### 包含

- 账号语言持久化、管理员更新接口、审计日志和 UI。
- `jp` 与 `ja` 的兼容比较，新增数据统一存储为 `ja`。
- 素材候选到账号的语言路由。
- 短剧首次绑定、后续绑定一致性和账号改语言冲突保护。
- X Auto 模板保存、启用、预览、任务生成和执行前校验。
- 队列冻结 `account_drama_language` 审计字段与显式冻结标记；历史队列标记默认 0。
- 生产迁移脚本与账号 19、20 的 `ja` 初始化方案。

### 不包含

- 不重写历史模板版本、历史任务、历史队列或已生成随机计划。
- 不自动修改素材/短剧源数据的语言。
- 不通过真实 X 发帖验证部署。
- 不自动改变模板或排期配置中的账号集合。

## 用户故事 / 业务规则

- 管理员可在 X 账号列表逐账号选择剧语言；默认值为 `en`。
- 素材池发布扫描全局候选，但仅将候选分配给仍待分配的同语言账号；其他语言候选不记为素材校验失败。
- 短剧池中未绑定短剧只绑定同语言账号；已绑定短剧继续使用原账号。
- 若账号仍有未完结绑定短剧，不能将账号改成与该短剧不一致的语言。
- X Auto 模板的所有账号必须与模板语言一致；`jp` 模板与 `ja` 账号视为一致。
- 已冻结任务在执行前如发现账号当前语言与任务语言不一致，安全失败，不改投其他账号。
- Premium 中继来源与内容语言必须一致。

## 交互与流程

1. 管理员从账号列表下拉选择语言。
2. 后端校验语言代码、管理员身份和未完结短剧绑定。
3. 保存成功后，仅后续候选选择/任务创建读取新语言。
4. 三条自动发布链路在各自的冻结边界再次校验并保存账号语言。

## 技术设计

### 影响模块

- `features/x_accounts`: 账号 schema、语言规范化、内部 API。
- `features/x_posts`: 素材/短剧选择、队列冻结、Premium 中继。
- `features/x_auto_posts`: 模板校验、任务快照、执行时复核。
- `static`: 账号列表、X Auto 模板、素材池和短剧池账号提示。
- `scripts`: 调度器路由、显式生产迁移与离线测试。

### 数据结构

- `x_authorized_account.drama_language TEXT NOT NULL DEFAULT 'en'`
- `x_post_queue.account_drama_language TEXT NOT NULL DEFAULT 'en'`
- `x_post_queue.account_drama_language_frozen INTEGER NOT NULL DEFAULT 0`
- 语言规范：小写、下划线转连字符、最长 32；主标签 `jp` 规范为 `ja`。

### API / 接口

- `POST /api/admin/x-accounts/{id}/drama-language`
- 内部转发：`POST /internal/accounts/{id}/drama-language`
- 请求体：`{"drama_language":"ja"}`
- 账号 DTO 新增 `drama_language`。

### 异常与边界

- `x_account_drama_language_invalid`: 语言代码非法。
- `x_account_drama_language_conflict`: 未完结绑定短剧冲突。
- `x_post_account_language_mismatch`: 候选与账号语言不一致。
- `x_post_drama_account_language_mismatch`: 已绑定短剧与账号语言不一致。
- `x_auto_account_language_mismatch`: 模板/任务与账号语言不一致。
- 历史非标准 `material_language` 仍可读取；只有带显式账号路由语言且冻结标记为 1 的新自动队列执行严格校验。

## 验收标准

- 账号列表显示语言下拉，已有未指定账号显示 `en`。
- 管理员更新后读取返回规范值；非管理员不能更新。
- `jp` 内容可路由到 `ja` 账号，不能路由到 `en` 账号。
- 混合语言素材候选按语言而非输入顺序分配账号。
- 混合语言短剧按语言首次绑定，绑定冲突拒绝。
- X Auto 不允许保存/启用不匹配账号，并在执行前再次校验。
- 同语言 Premium 中继可用；跨语言中继不可选。
- 全量 X 离线测试通过，不创建真实 X Post。

## 风险与待确认

- 生产账号 19、20 必须在新服务恢复调度前设为 `ja`，否则现有日语模板会安全失败。
- 账号语言变更不会自动修订模板账号集合，运营需同步检查受影响模板。
- 当前生产所有未完结短剧绑定均为 `en`，因此迁移 19、20 不与短剧绑定冲突。
