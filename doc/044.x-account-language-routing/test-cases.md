# 测试用例

## 测试范围

语言规范化、账号 schema/API/UI、素材路由、短剧绑定、X Auto、Premium 中继、迁移备份和既有 X 发布回归。

## 测试数据

- 账号：`en`、`ja` 两类，包含非 Premium 与 Premium。
- 内容：`en`、`ja`、历史 `jp`。
- 生产迁移模拟：19/20 -> `ja`，其他账号保持 `en`。
