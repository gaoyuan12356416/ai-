# BUG-002 随机发布配置在桌面 100% 缩放下错位

## 状态

已关闭，纯 CSS 布局缺陷，不涉及随机发布业务逻辑。

## 现象与影响

启用随机发布配置后，在桌面浏览器 100% 缩放下，发布描述模板与自动发布配置被错误并排压缩；配置开关、保存按钮和账号发布设置出现拥挤、溢出或错位。配置读取、保存及随机计划生成均不受影响。

## 根因

右侧外层 `.column` 使用 CSS Grid，但没有定义显式列；其直接子项 `.direct-test-panel` 设置了 `grid-column: span 2`，浏览器因此生成两个隐式列，并把前面的描述模板和 `.setting-grid` 自动排到同一行的两个半宽列中。随机发布新增控件提高了配置区最小宽度，使原有隐式列问题明显暴露。

## 修复

- 将 `.direct-test-panel` 改为 `grid-column: auto`，恢复右侧外层单列流。
- 保留 `.schedule-panel` 在内部 `.setting-grid` 中跨两列的既有桌面布局。
- 在 `1680px` 及以下将 `.setting-grid` 和 `.schedule-panel` 收敛为单列，避免中等桌面宽度下再次拥挤。
- 未修改 DOM、JavaScript、API、配置字段或随机调度逻辑。

- 2560、1920、1680、1600、1440、1280、1180、820px 宽、100% 缩放浏览器检查通过：页面与随机计划区无横向溢出，保存按钮和账号发布设置无重叠。
