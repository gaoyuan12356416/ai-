# SA 评审意见

有条件通过。必须先完成所有高/中风险项，再进入开发；本期不得把远端数据库
放入公开请求链路，也不得公开花费。

## 决策记录

- 数据源固定只读 `101.32.56.53:63350/kunlunads_dev`，查询范围为
  `Dramawave + [w2a]drama-double + data_source=6 + 上海昨日`，默认全 platform。
- 页面 API 由 Nginx 精确 alias 数据盘 JSON，不新增在线数据库 handler。
- 公开卡片直接使用快照中已校验 ID，并通过现有 `createTarget()` 生成目标。
- 无有效快照时保留当前人工审核静态卡片，但不为其伪造 content ID。
