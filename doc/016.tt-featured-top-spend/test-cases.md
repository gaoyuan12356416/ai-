# 测试用例

## 测试范围

- 上海昨日计算、只读连接、排行 SQL、元数据筛选和原子快照。
- Nginx 精确 JSON 路由、前端动态渲染和 W2A 参数透传。
- LKG、数据不足、陈旧快照、非法字段、CSP 和现有搜索回归。

## 测试数据

- 固定当前时间 `2026-07-27T16:00:00+08:00`，期望 source_date
  `2026-07-26`。
- 包含重复 content_id、相同 spend、非法 ID、缺封面、非白名单封面、
  多语言变体和不足 5 条的假数据。
- 生产只读目标日 `2026-07-26`，配置
  `Dramawave/[w2a]drama-double/data_source=6`。
- W2A 透传样例：`?af_adset_id=XXX`。
