# BUG-001 账号列表自动发布状态列首屏不可见

## 发现阶段

生产验收。

## 现象

用户在 X 账号列表未看到“自动发布 Post”列。

## 复现步骤

1. 在 1024px 或 1100px 宽度打开 `/x-account-list.html`。
2. 保持表格横向滚动位置为 0。

## 期望结果

账号名称旁直接显示“已配置/未配置”。

## 实际结果

列存在于第 5 位，但表格固定最小宽度 2080px，窄屏必须横向滚动；HTML 无缓存控制，旧标签页还可能保留旧结构。

## 根因分析

列位设计没有考虑常见窄桌面视口，同时页面缓存合同只覆盖 API，未覆盖 HTML 壳。

## 修复说明

- 将状态列移动到紧跟账号名称的第 2 列。
- 设置 120px 最小宽度且不换行。
- 为页面配置 no-store/no-cache，并给导航入口添加版本参数。

## 影响文件

- `static/x-account-list.html`
- `static/navigation.json`
- `deploy/nginx-x-oauth.conf`

## 验证命令与结果

静态契约与全部 X 回归已通过：状态表头和行单元格均紧跟账号列，
导航 URL 带版本参数，Nginx exact location 包含 no-store/no-cache。
真实浏览器回归待生产部署后执行。

## 回归结论

代码级回归通过，生产浏览器待验收。
