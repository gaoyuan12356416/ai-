# 测试用例

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| AS-01 | 初始化旧 SQLite | 自动新增账号设置表，既有三张表和历史任务不变 |
| AS-02 | 查询未配置账号 | 返回 `configured=false`，不含凭据 |
| AS-03 | 首次保存完整设置及版本 0 | 保存成功，版本为 1 |
| AS-04 | 携带当前版本更新 | 保存成功，版本加 1 |
| AS-05 | 携带旧版本更新 | 返回版本冲突，原值不变 |
| AS-06 | 不携带版本 | fail-close，不写入 |
| AS-07 | 开启商业披露但未选品牌 | 校验失败 |
| AS-08 | 披露开关与品牌开关不一致 | 服务端拒绝 |
| AS-09 | TikTok 禁止评论但请求开启 | 保存失败 |
| AS-10 | 隐私范围不在实时列表 | 保存失败 |
| AS-11 | 未配置账号创建任务 | 入池失败，GPU 不开始制作 |
| AS-12 | 客户端提交遗留账号设置字段 | 服务端忽略，冻结已保存配置 |
| AS-13 | 创建任务后修改账号配置 | 历史任务快照不变 |
| AS-14 | 修改配置后同幂等键重放 | 返回原任务，不重复制作 |
| AS-15 | 发布池 UI | 无账号级编辑控件，有只读摘要和管理入口 |
| AS-16 | 个号管理 UI | 设置完整、互动按实时能力置灰、无平台默认值 |
| AS-17 | 权限与同源 | 未登录/无权限/跨站写入均被拒绝 |
| AS-18 | 敏感字段扫描 | 页面、响应、日志和表结构无 Token |
| AS-19 | 既有 TT 回归 | 固定描述、门禁、队列、Runner、GPU 协议不变 |
| AS-20 | 生产关闭态验收 | 页面可用，队列和真实 Post 数量不增加 |
