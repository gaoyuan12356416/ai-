# 测试用例

1. 相同 `preview_id` 的计划观察和计划正式执行只返回正式执行一行。
2. 手动试算观察记录继续展示。
3. 没有对应正式执行的计划观察记录继续展示。
4. `run_mode=observe` 筛选不会重新显示已配对的预检子记录。
5. 正式执行详情包含预检执行 ID、时间和状态。
6. 默认前端请求 `page_size=20`；接口拒绝 `page_size>100`。
7. 执行日志接口拒绝 `page>1000`。
8. 日期范围超过 93 天返回安全的 400 校验错误。
9. 新请求发起时取消旧的日志请求，旧响应不得覆盖新结果。
10. 生产索引名称、列顺序和 `EXPLAIN` 使用情况符合方案。
11. 合并展示不修改执行、目标、Preview 或 runner_event 行数。
