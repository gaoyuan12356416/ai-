# BUG-002：日报 service 磁盘预检误判沙箱只读挂载

- 严重程度：P1，首次启动被 ExecStartPre 阻断。
- 状态：代码修复及本地防护回归通过，待精确 SHA 部署后真实 service 复验。
- 影响范围：独立 `ai-image-daily.service`；失败发生在报告程序运行前，尚未查询 SQL 或上传 COS，timer 未启用。

## 原因

`ProtectSystem=strict` 将 `/mnt/data-disk` 挂载根目录设为只读，`ReadWritePaths=/mnt/data-disk/ai-image-daily` 则只给日报状态目录写权限。`deploy.py:check_disk()` 始终对挂载根目录调用 `os.access(..., W_OK)`，因此将正确的最小写权限配置误判为磁盘不可写。

## 修复

保留真实挂载 UUID 和至少 1 GiB 可用空间守卫。已有日报状态目录时检查该目录的可写性；只有首次安装且状态目录不存在时，才检查数据盘根目录可写性。没有扩大 systemd 写权限，也没有降级到根盘。

修改文件：`ops/ai-image-daily/deploy.py`。

## 回归验证

本地内存 mock 自测覆盖：

1. STATE 存在且可写、挂载根目录只读时通过，并只检查 STATE。
2. STATE 不存在时检查数据盘根目录可写性。
3. STATE 存在但不可写时拒绝。
4. 数据盘 UUID 错误时拒绝。
5. 数据盘可用空间不足 1 GiB 时拒绝。

Python 语法检查与上述 5 项自测均通过。上线执行者须补充新 SHA、真实 `ExecStartPre` 通过、报告执行及 COS readback 结果；当前修复记录不代表已重新部署。
