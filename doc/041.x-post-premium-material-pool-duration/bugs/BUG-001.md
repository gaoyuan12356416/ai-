# BUG-001 Premium 修复链仍裁剪为 599 秒

## 发现阶段

SA 代码评审。

## 现象与根因

正式素材池候选上限放宽后，`features/x_posts/media_repair.py` 的 Premium 策略仍为 600/599 秒。只要原片因编解码器、尺寸或帧率需要修复，763 秒视频就会被错误裁短。

## 修复

- Premium 修复边界改为 14400/14399 秒。
- CPU/GPU profile 从 v3 升为 v4，禁止复用旧产物和错配运行。
- 增加 763.938 秒保留及 14400.001 秒边界测试。

## 验证

`scripts.test_x_post_media_repair` 与相关定向回归通过，最终结果见测试报告。
