# X 频道选择与发布时过滤

模板、素材池自动发布及短剧池自动发布允许选择和保存当前受限的频道。配置保留完整选择；全部所选频道受限也不自动关闭配置。每次执行根据当前授权、批准发布、平台限制及原有账本保护过滤频道；正常频道继续。恢复后，保留在配置中的频道可参与后续新批次。

模板发布前的账号限制记为 `skipped`，不选素材、不建外部执行队列。全受限批次完成时保留每条跳过原因，不产生帖子。缺失账号、格式、权限、版本、素材防重、在途及未知写入保护继续执行。已冻结任务不改绑、不重发。人工指定素材与账号的一一映射仍使用原有人工发布校验。

前端解除这三处自动发布的禁选、选择回退及保存状态检查，保留受限状态提示。全选包含当前显示的受限频道。仅修改普通与画像两个现行 X 运行环境的相关代码及对应静态页面；不保存用户模板、修改选中频道或补发历史任务。

验证：`python -m unittest scripts.test_x_channel_selection scripts.test_x_auto_post_service -q`，29 项通过；`node scripts/test_x_channel_selection_ui.cjs`，5 个实际选择、全选和提交函数场景通过。扩大运行 `test_x_post_multi_schedule_store` 时发现 5 个失败、3 个错误；对未修改基线 `bce2221c` 的同 7 个用例重跑，复现完全相同的 5/3 结果，属于已有账本保护测试与当前实现口径差异，本次不改这些执行保护。旧运行器测试还有两处断言与当前“恢复后重验并允许加入批次”的既有行为不一致；新增直接调用运行器账号筛选的测试覆盖六类受限状态，均正确过滤并保留正常频道。
