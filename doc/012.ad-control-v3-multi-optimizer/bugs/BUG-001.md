# BUG-001 ad-control-v3-multi-optimizer

## 发现阶段

生产验收，2026-07-17。

## 现象

王鹏打开 V3 规则组页面后显示“当前账号映射到多个优化师，系统已安全阻断”，页面不可用。

## 复现步骤

1. 使用王鹏 Feishu 账号登录。
2. 打开 `/api/ad-control/v3/ui/rule-groups`。
3. 页面请求 `/api/ad-control/v3/meta`。

## 期望结果

页面正常加载，387 和 686 两个优化师范围同时生效。

## 实际结果

页面 HTML 返回 200，但 meta 连续返回 409 `optimizer_identity_ambiguous`。

## 根因分析

源身份表中同一精确邮箱对应 optimizer 387 与 686。旧 resolver 强制普通用户只能解析到一个 optimizer；它无法表达“同一人的多个有效投放别名”，因此按安全策略阻断。

## 修复说明

增加强身份多别名模型、规则组关系表、逐别名扫描与去重；姓名多命中仍阻断，普通用户仍不能伪造 optimizer_id。

## 影响文件

`catalog.py`、`service.py`、`repository.py`、`live_execution.py`、`schemas.py`、`assets/app.js`、SQL 和 V3 测试。

## 验证命令与结果

见 `../test-report.md`；生产验证需确认 meta=200 且 optimizer_ids=[387,686]。

## 回归结论

待线上只读冒烟后关闭。
