# 实现计划与责任

1. backend：渠道适配器、严格campaign归因、源指标、共享聚合、API/CSV及隔离测试。
2. frontend：新独立页面/分组/质量展示/旧入口与定点导航，桌面及390px真实浏览器隔离测试。
3. daily：共享collector、卡片/分片、保留发送账本、权限继承脚本和鉴权审查。
4. 主实现：X冻结归因、发布接入/租户透传、迁移协调、固定快照全量验证、GitHub明确提交部署与读回。

按requirement-dev-standard-flow执行并行工作与独立交叉审查。所有数据快照/预览/生产备份只在output私有目录或数据盘，禁止入Git。
