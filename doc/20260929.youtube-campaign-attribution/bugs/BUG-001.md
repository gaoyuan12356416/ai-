# BUG-001: manual-link metrics omitted and revenue dimensions mixed

Cause: the report required an exact (full campaign ID, campaign name) match. The source stores only 32 characters for IDs and can attach a different link's campaign name/YouTube channel to revenue rows. Thus legitimate manual-link metrics were excluded or displayed as zero despite source data.

Fix: globally unique campaign-ID resolution against immutable backend contexts, with a collision-safe 32-character storage alias and frozen owner/drama/channel labels. Historical links and source data are unchanged. See test-report.md and deployment-evidence.md for actual validation.
