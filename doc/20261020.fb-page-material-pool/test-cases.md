# 验收用例

| 编号 | 输入/操作 | 预期 |
|---|---|---|
| T01 | 同批素材A明日、B空、C今晚，多Page | B立即、C今晚、A明日；每素材目标Page同计划时间 |
| T02 | 相同时刻3素材，调整顺序 | 同Page按原素材顺序；后项不能加工先成而越序 |
| T03 | 过去/无时区/非法时间、映射缺项/多项 | 提交拒绝且无半批任务，保留输入 |
| T04 | 跨午夜以及多Page配对 | 按各自北京时间计划日计数，复用1000额度 |
| T05 | v1请求/历史批次、v1草稿、pending op | 老任务不变；pending先查；转换明确清空旧时间 |
| T06 | 建Page后编辑/重建、历史创建人 | 编辑保留创建人；重建新身份快照，缺姓名显示ID |
| T07 | 无池GET、批量加200、跨页选择、同素材重复 | GET不写；有界查询；不重复待处理项 |
| T08 | 同时入池/设置/置顶/删除 | version CAS，409无丢失更新或部分改动 |
| T09 | pool add响应丢失、原operation重试 | 同操作同请求返回原结果，不重复加；异内容409 |
| T10 | 保存计划、启用、普通修改、暂停重新启用 | 初次暂停；归启用人；普通保存不换人 |
| T11 | 一/多个HH:mm，重复或空时间 | 每点1条；空/重复拒绝；北京时间准确 |
| T12 | tick重复/并发/改版本/重建Page | 同真实Page同日同时点至多1任务 |
| T13 | 重启/长停机/空池/容差超期 | 不补历史点；素材不凭空消费 |
| T14 | 成功/明确失败/暂时来源错误/unknown | 成功一次；失败下点下一条；临时保留；unknown暂停 |
| T15 | 槽冻结中异常、额度不足 | 槽/item/task/link一致；无孤儿、无同槽换第二条 |
| T16 | 启用人注销/权限撤销/邮箱失效/Page失权 | 当前身份复验拒绝，不能借系统管理员代发 |
| T17 | 入池后修改文案/剧语言、删除配置 | 文案最新；语言暂停标不匹配；删除停池但冻结历史不改 |
| T18 | 修改排序/删除已绑定项，跨槽GPU完成逆序 | 已绑定操作拒绝；发布保持跨槽顺序 |
| T19 | 历史成功再加，入池后出现新重复事实 | 明确确认，新的重复需重新确认；active不能绕过 |
| T20 | 普通用户跨租户/他人task详情、公共内部接口 | 不泄露任务详情或身份；公网内部路由拒绝 |
| T21 | 2310短链宏、随机加工、取消竞态 | 原合同保持，独立不可覆盖链接，不降级原片 |
| T22 | 1440/820/390，非空真实API，刷新/错误输入 | 列表弹窗可用、无横向溢出，错误保留编辑 |
| T23 | 迁移旧生产副本、二次迁移、回退 | 旧数据摘要不变、幂等，保留任务/链接 |

模拟时钟可跨天；Graph与身份解析均可注入；生产验证不触发Facebook发帖。
