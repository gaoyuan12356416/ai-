# 验收用例

| 编号 | 级别 | 场景与输入 | 预期 |
|---|---|---|---|
| SK-01 | P0 | 同短链有多任务、跨日期复用和多个国家设备收入行 | 发布与收入独立汇总，无重复金额；原始粒度聚合后再归属 |
| SK-02 | P0 | 短码大小写不同、空键、未知键 | 精确匹配；未匹配指标保留；总额守恒 |
| SK-03 | P0 | 各表平台编号及未知平台编号 | TikTok/FB/IG/YT/X正确转换，未知不伪装成其他平台 |
| SK-04 | P0 | 同名账号、同content_id跨产品、多团队 | 依靠稳定复合键归属，不合并名称；不硬编码团队 |
| SK-05 | P0 | 退款/收入修正，源行从某日消失，重跑相同日期 | 新版本完整替换该日，不累加、不残留旧金额 |
| SK-06 | P0 | 第N天读取失败或只读端验证失败 | 不发布半套版本；旧完整快照仍可查询，状态显示失败 |
| SK-07 | P0 | 重建14日同时保留更早已累计日 | 新窗口生效且较早历史不丢失；回滚仍可读上一版 |
| SK-08 | P0 | 未登录、无模块授权、管理员、获授权用户 | 分别401、403、成功、成功；无个人归属假设 |
| SK-09 | P0 | 同一筛选、固定version查询表格/图表/CSV | 数值与版本一致；版本失效明确报错，不静默读新版 |
| SK-10 | P1 | 收入国家/设备筛选用于发布视图；非法维度、排序、日期 | 不混用口径；不接受SQL注入或任意字段 |
| SK-11 | P1 | 任务取消/未知状态且item_failed为0 | 计划、成功、失败、状态分别显示；不报全部成功 |
| SK-12 | P1 | 缺失日期、成功采集零行、无快照 | 区分缺失/零值/未就绪，不把故障当0 |
| SK-13 | P1 | 14日真实数据默认页、常用组合筛选、分页导出 | 记录实际耗时；首页/常见筛选目标≤2秒；不访问远端源 |
| SK-14 | P1 | 页面刷新、同一采集任务重入、服务重启补执行 | 页面只读快照；采集单实例；日调度为11:00 Asia/Shanghai |
| SK-15 | P0 | writer配置指向源schema/错误端口或DDL混入运行路径 | 拒绝；仅本功能ads_ai三表可写；源读取63350 |
| SK-16 | P1 | 查询技能初始化、调用、危险shell字符作为filter、缺helper | 名称准确、参数安全引用、错误清楚；无凭据写入/输出 |
| SK-17 | P0 | 首次14日回填2026-10-19至11-01 | 每日完成/控制量可核查，总盘与所有维度一致，无今天快照 |

源控制数据可能回补：单元测试使用合成样例；生产验收与同轮查询控制量比较，不强行写回固定值，也不将真实业务金额写入公开测试文档。测试结果由执行者记录，不在本用例表预设通过。
