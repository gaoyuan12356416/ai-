# SocialKit 每日效果报表与查询技能

## 业务目标

提供 AI 后台独立的 SocialKit 效果报表，把发布执行与收入归属分别统计，再按共享维度分析。首次覆盖 2026-10-19 至 2026-11-01；默认显示已发布的最近 14 天，不纳入当天未完结快照。

用户确认每天北京时间 11:00 更新前一天，并在同一轮重新核算最近 14 个日期；获授权用户查看全部报表范围，不按个人归属隔离。更早已累计历史继续保留。

## 数据定义

- 收入范围是 `ads_facebook_page_insight.channel='socialkit'`，UTC 日期、USD。源粒度为日期、站点、精确 campaign、收入国家、设备系统。
- 通过 `campaign = social_short_link.short_code` 精确关联短链归属；短链和任务/账号的社媒平台编号分别转换。账号依据团队、平台、外部 ID，剧目依据 App ID、content ID，名称不参与归因。
- 任务范围是 `deleted_at=0`，使用账号当地 `schedule_date`。计划、成功、失败内容分别取 item_total、item_success、item_failed；任务数单列。未知 task_status 保留原值。
- 同短链可跨任务/日期复用。两类事实分别汇总，不原始联表，不计算单帖收益/ROI。金额使用整数分或 Decimal。
- 未归属收入和指标保留，不伪装为零，也不因为单行无匹配而阻止整份报告。没有源数据与源查询失败分别展示。

## 页面

独立 `/socialkit-analytics.html`，沿用 QuickNav、UiTopbar 和 Feishu Cookie 鉴权；新增 `socialkit_analytics` 模块权限。三个视图：总览、收入效果、发布执行。提供 KPI、趋势、平台/产品占比、TOP 排名、最多三维分组、排序分页及同版本 CSV。

收入筛选涵盖日期、团队、产品、平台、账号、剧目、素材类型、创建来源、收入国家、设备系统。发布视图另外使用账号语言/国家、任务原因/状态；效果国家和设备不得套用到发布数据。

显示源更新时间、报表更新时间、日期口径和未归属情况。页面刷新只加载已发布版本，不触发远端源查询。

## 存储与执行

`ads_ai` 使用 socialkit_effect_daily、socialkit_publish_daily、socialkit_refresh_runs 三类专用表，保存新批次和逐日有效版本。源读只走 63350 和外部 SocialKit；内部自动化读使用 SQL FIFO Gate。63353 仅写本功能表，DDL 由独立迁移执行。全轮采集和只读端对账完成后原子发布本地 JSON/SQLite 查询快照；失败保留旧完整版本。保留累计历史和当前/上一成功版本。

## 交付边界

不改变生产发布任务、账号授权、原始收入表或现有社媒报表口径；不发送飞书消息。查询技能 UI 名称为 `socalkite效果数据查询`，内部名 `socalkite-effect-query`，包含只读入口、表关系及核查方法，不含凭据。

## 验收

14 个日期全部回填并逐日对账；维度加总守恒；权限正确；页面/接口/CSV 同版本；真实数据首页及常见组合筛选目标 2 秒以内。部署遵循 GitHub 提交后精确版本部署，记录回滚点，回滚保留中间数据与业务源记录。
