# 测试用例

## 测试范围

- Resolver 输入、只读查询、字段清洗、缓存、并发与异常语义。
- 公共 HTTP 路由、状态码、响应头和无鉴权访问。
- `/tt` 加载、命中、未命中、异常、封面失败与参数透传。
- 冷查询、热缓存和封面 CDN 分项测速。

## 测试数据

- 已知有效 ID：`l9rP6ey2CB`
- 合法格式但不存在：`ZZZZZZZZZZ_NOT_REAL_2026`
