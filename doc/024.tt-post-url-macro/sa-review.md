## 决策记录

- `{url}` 使用单花括号，内容 ID 继续使用双花括号，避免兼容性变化。
- 短链在队列创建时稳定，长链中的实际队列 ID 在领取后填入。
- 不用零宽字符或特殊 Unicode 换行规避客户端展示。
