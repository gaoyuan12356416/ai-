# Independent video creation studio

The video editing menu opens `/video-editing-ai.html` as a full viewport studio. Its light background, blue actions and typography follow the AI backend. The layout follows the evaluated Beidou workflow: conversation, persistent player, source/result thumbnails, analysis tracks, configuration dialogs and output copy panel.

The host supplies authentication only. All creative operations use `/api/ai-video-editing`; the new `/studio/` routes persist sessions, messages, frozen submissions, caption/audio compositions, platform copy and ZIP exports in the existing independent editor database. No old editing, publishing, language or catalog business API is called. Existing assets/projects/tasks remain intact.

Sessions support GET/POST and versioned PATCH. `/sessions/{id}/analyze`, `/submit`, `/messages`, `/scripts` expose the corresponding operations. Submissions require an operation ID, preserve configuration snapshots, recover an already saved project after interruptions and keep failed output retries distinct from completed artifacts. `/runs/{id}/retry` retries failed stages. `/copies/{task_id}` saves or generates platform-specific text. `/exports` validates all task ownership before streaming a private ZIP through `/exports/{id}/media`.

The CPU prepares timed captions and speech; the dedicated GPU worker renders the final composition, including ASS subtitles, watermark, audio mixing and supported visual effects. Its internal audio download checks the worker lease, task audio reference, owner and digest. Composition changes preserve 720×1280, 30 fps and the frozen clip frame count. GPU SIGTERM drains the current render before exiting.

Emotion samples come from a separate visual emotion assessment with a reason, not confidence scores or audio loudness. Unsupported observations remain empty. Available languages and voice capabilities are returned by the service. Standard speech is supported; multi-character natural voices, original hard-caption erasure and actual social publishing are not represented as working capabilities. No points or payments are added.

## Validation and rollout

Run `python -m unittest discover -s tests -p 'test_ai_video_editing*.py' -v`, `node --check static/video-editing-ai-studio.js` and `git diff --check`. Tests cover owner isolation, session version conflicts, submission and message receipts, resume after project save, source bounds, real media/voice/effect rendering and lost completion reconciliation.

Commit and push before deployment. Stage the exact commit in `/mnt/data-disk/ai-video-editing-deploy/checkouts/<sha>`. Preserve the database via SQLite backup and both active release targets. Stage the complete `features/ai_video_editing` package on GPU because the new finishing step imports composition/runtime. Drain only the independent render worker, activate its release, then run `scripts/deploy_ai_video_editing.py install <sha>` on CPU. Other backend services and schedulers do not require restarting.

Rollback CPU with `python3 scripts/deploy_ai_video_editing.py rollback <sha>` from its checkout. Restore GPU `current` to the recorded prior release and restart only `ai-video-editing-render.service`. Keep databases and output files; additive studio tables are compatible with rollback. The old worker must not consume newly composed jobs: finish those jobs before rolling back GPU, or leave the new worker installed while rolling back the UI/API.

## Standards review — 2026-11-18

The user requested a standards recheck before release. Findings and corrections:

- Shared host chrome was incomplete: the standalone page omitted `quick-nav.js` and `ui-topbar.css`. It now calls `QuickNav.render` with `videoEditingAi`, and `UiTopbar.render` handles the user card, login/logout and refresh. A modal navigation drawer preserves the full viewport editing layout selected by the user. Shared navigation controls permission filtering, current-group expansion and root-relative links. No shared component source was overwritten.
- New HTML/CSS/JavaScript and studio/composition Python code were compressed and hard to maintain. They are now consistently formatted source files.
- Caption-only translation combined with spoken narration passed translated words to the original-language voice. It now keeps the original narration text; translated speech still uses the target language. A focused regression test checks the bilingual captions and original spoken text together.
- Opening another session retained externally selected works from the previous session. Session loading now clears that transient selection and the copy panel.
- All creative API requests stay under `/api/ai-video-editing`; only existing Feishu auth/topbar and navigation are shared. The existing assignable `video_editing` permission gates this page's API. Tenant plus user ownership checks remain in the independent store, including private media and exports.

Local verification after these fixes: 13 relevant unittest cases passed; JavaScript syntax and diff whitespace checks passed. Real GPU/public-browser acceptance remains a release check, not inferred from the local layout preview or unit results.
