# BUG-GCP-002 升级验收器未覆盖全部证据与缺口

## 发现阶段

2026-08-27 独立QA，发布前。选优计算正确，但对验证产物做变异测试后，部分损坏字段仍能通过验收。

## 根因与修复要求

- 仅比较入选集合和部分数值，没有完整比较映射、来源、A可用性、top50、素材CTR、完整映射金额；布尔1与true未区分。
- 缺口计数没有全部从原始缓存独立重算。
- 平台消耗真实0时，生成器沿用累计占比0，验收器预期null，导致合法B行误拒。

应补独立原始缓存计数、严格布尔检查、证据字段和负向变异测试；真实0沿用既有契约，不把缺失平台金额改成0。修复前禁止把验收器PASS当最终发布门禁。实际复测记录见测试报告。

## 修复完成

验收器已逐项校验精确来源、布尔类型、素材CTR、CPC、排名、完整映射消耗、每类映射/FX缺口与原币金额。补充17项变异/边界测试，零Campaign消耗的合法B行按既有累计0契约验证。全量148后端和46前端通过；运行代码不因验收器修复而改变。待真实七个月产物验证后放行发布。
