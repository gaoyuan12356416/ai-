# 测试用例

## 测试范围

2026-10-19：封面专用产品接口、封面 metadata 查询、上传映射、自动筛选与去重、分产品失败隔离。自动测试只使用合成行、临时 SQLite 和 mock，不连接生产、不生成图片、不上传。真实图片与生产素材库回读由发布负责人另行执行并留证。

## 测试数据

- DramaWave 1479、FreeReels 979、Moboreels 3360、MoboShort 2373；跨产品重复 content_id 使用 synthetic-shared。
- 指标边界：999.99 / 1000 / 1000.01 配合 44.99 / 45 / 45.01；新产品 2999.99 / 3000 / 3000.01 配合 0 / 44.99 / 45。
- 原封面：非空 HTTPS、空/纯空白 cover、较旧有效资源、较新空资源、相同更新时间不同资源 ID；Moboreels 的 sub_url 为空。URL 处理沿用既有 strip 行为，公网可解码性由真实验收检查。
- 临时账本含成功、进行中、失败任务及另一产品同 content_id；另含不存在数据库、缺表数据库和损坏数据库。
