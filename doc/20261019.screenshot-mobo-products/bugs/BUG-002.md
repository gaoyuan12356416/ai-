# BUG-002 跨 Python 版本 AST 指纹预检兼容

状态：已修复，本地完整快照与 Linux Python 3.9 预检均通过，部署成功。

生产源码 SHA256 与快照一致，但 Python 3.14 的 ast.dump 默认省略空字段，Python 3.9 保留，导致同一函数指纹不同。初版规范化又未处理其他生产函数中的 bytes 常量。两次均在预检阶段停止，未改动生产。

修复：递归规范化 AST 字段、排序 JSON、忽略新版 type_params，bytes/complex/Ellipsis 常量使用带类型的 repr。验证完整生产复合快照全部函数，保留漂移与重复补丁拒绝测试。
