# BUG-005 接收记录与正式素材使用不同标识

状态：已修复只读验收/恢复工具，不改运行时生成、上传或数据库。

2026-10-19 上游放开包名后，两个验收任务都回调成功。只读查询确认接收记录为data_source=102，data_source_id为稳定的外部material_id，初始type=2（即便传入图片）；正式素材才是data_source=6、data_source_id=content_id、type=1。

旧工具仅按剧ID和图片type读取，漏掉尚未转正式素材的接收记录。修复为分别查询两个命名空间，预检遇到任一接收/正式记录均停止重发；最终验收仍只接受正式图片并校验产品、剧ID、名称和SHA256。已有出站请求和任务不重提。
