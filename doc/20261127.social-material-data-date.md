# 社媒素材效果按数据日期

`/x-material-effects.html` 的开始、结束日期现在筛选数据日期，结果按数据日期、渠道、素材命名空间和素材 ID 分组。旧帖子在所选日期产生的数据参与统计，帖子发布日期不作为范围筛选条件。

- 默认最近七个完整的北京时间日期，支持昨日、近七天、近三十天以及自定义起止日期。
- 浏览、点赞、评论、分享及可用的 X 转发、引用、收藏，采用相邻北京时间日期最后一次观测的累计计数差。当天发布的帖子起点为零；历史缺快照、字段观测过期、计数下降均为未知。该值是采样差额，不能声称精确的平台事件时间计数。
- 收入直接读取所选 UTC 数据日期的已验证归因事实。仅在 verified income scope 覆盖且没有缺失日时，稀疏收入记录缺行可以计零。UTC 与北京时间日期的差异在页面明确显示。
- 素材在某天没有互动样本或收入证据时不创建该日数据行。同一素材有部分帖子缺数据时保留这些帖子在覆盖数中，已知小计与完整值分开。收入的已核验零值属于有数据。
- 汇总卡片的素材数去重，数据天数为匹配数据行的日期数；金额及互动是所选日期已知小计。关联帖子数是每一日期素材行的帖子数，不声称当日发布数。API `post_count` 表示查询范围的帖子日观测槽，用于覆盖率分母。
- 明细固定到点击行的数据日期，保留原 X 授权账号、Facebook 所有人/租户权限。主表仍沿用原报表汇总权限。
- 目前日数据来自此前新增的约 32 日留存；更早日期或缺失的相邻快照不会从累计值反推或摊分。查询今天会显示尚未完整提示。

本地验证：`python -B -m unittest tests.test_social_material_daily tests.test_social_material_effects tests.test_social_effect_window -q`；`node --check static/x-material-effects.js`；`git diff --check`。

先提交并推送 GitHub，再由 CPU 43.166.187.96 检出确切提交运行：

```
python3 SOURCE/scripts/deploy_social_material_daily.py stage DEPLOYMENT
python3 SOURCE/scripts/deploy_social_material_daily.py activate DEPLOYMENT
```

```

```
