# Page 素材池取消素材产品限制

Page 管理里的素材池此前因 `ads_custom_source.product != Dramawave` 跳过素材。
现在按 ID 预览、入池、时点调度和发布前复核都接受任意素材产品。
只调整 Page 素材池；共享来源适配器的其他调用保持原政策。
来源6、有效视频/时长、同语言已上架剧目、Page授权及防重规则保持。

四个运行文件：`features/fb_video_publish/{sources,pool,pool_scheduler,worker}.py`。
按实际线上文件与基线 b5606afe 逐文件比对，仅覆盖这四个文件；主 API 副本同步但不重启。
使用现有 FB 排空切换和调度依赖恢复流程，保留全部任务、短链、回执及数据库。

验证：`python scripts/test_fb_pool_any_product.py -v`，四个文件语法检查及 `git diff --check`。
上线前、后只读复核用户截图的 11 个 ID；不添加生产素材、不创建测试帖。

服务器先从 GitHub 拉取此分支，再以检出的脚本执行：

```sh
python3 scripts/deploy_fb_pool_any_product.py prepare --folder /mnt/data-disk/fb-pool-any-product-20261106/deployment
python3 scripts/deploy_fb_pool_any_product.py activate --folder /mnt/data-disk/fb-pool-any-product-20261106/deployment
```

回滚同一检出版本中的脚本，保留当前业务事实：

```sh
python3 scripts/deploy_fb_pool_any_product.py rollback --folder /mnt/data-disk/fb-pool-any-product-20261106/deployment
```

回滚后新产品的待执行素材会再次受到旧产品校验限制；应保留素材池和任务记录，不能重置或重发。
