# 测试场景
- 已 published 或 unknown 队列不触发写入；unknown 同账号/转发账号暂停，独立账号继续。
- 两个工作槽：慢账号不阻止后续健康账号补位，同账号不并发。
- FB 单工作槽异常，其他槽继续耗尽任务，无回执任务不重试。
- X 超过 500 个被阻塞候选，后方正常账号仍可领取。
- 手动部分预检失败：保留配对、原 candidate_rank、失败审计、最终计数和幂等回读；全部失败零队列。
- 个人批次未知项只拦自身账号，其他所有权/语言检查仍有效。
- 短剧待核对项与原归属保持，其他账号仍可领取。
- 跨日未开始 claim 保留原 identity；已有旧 stopped 记录仍需原审核恢复逻辑。
- 原有定时不提前、重复请求、未知结果、转发、素材预留和平台守卫回归。
