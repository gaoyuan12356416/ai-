# 测试用例

## 测试范围

查询口径、游戏映射、双事实聚合、SQLite 事务、版本化发布、浏览器筛选/导出/响应式布局、鉴权缓存头、systemd 定时刷新和回滚边界。

## 测试数据

- 单元测试：Fake MySQL/临时 SQLite/临时发布目录；
- 生产只读基线：2026-08-24 `Neonarcade` 与手工转化数据；
- 浏览器：桌面 1440×900、手机 390×844；
- 不创建广告、不写 MySQL、不触发外部发布。
