# BUG-007 Unity 渠道安装/曝光/点击缺失

## 发现阶段

2026-08-26 用户验收生产报表 `https://ai.yingliangads.com/reports/ai-game-performance/`。

## 现象

Unity 目前只有手工转化安装/成本；“渠道安装、曝光、点击”均为 0。真实数据存在于只读表 `kunlunads_dev.ads_unity_insights`。

## 根因

v6 的 delivery 刷新只读取 `ads_custom_source_insight` 平台 0/1/3，该表不覆盖 Unity。前端虽会并列加载 Unity conversion，但没有 Unity delivery 事实可贡献渠道指标。

## 修复口径

- 单日读取 `ads_unity_insights FORCE INDEX(idx_date)`，严格 `product='Neonarcade' AND category=0`；category 1 与 category 0 重复安装/花费，禁止合计。
- `starts -> 曝光`、`clicks -> 点击`、`installs -> 渠道安装`；`views` 为完整播放，不冒充曝光。
- Unity raw spend 不进入有效花费；继续使用 manual cost fallback；CPI 保持既有 source spend 除渠道安装，本次 Unity 为 0。
- 负 source ID 隔离两张源表主键；新增 `source_game_id` 采用旧缓存原位增量迁移。
- 只以同日 `campaign_id + creative_pack_id/ad_id` 和严格 `projectid[数字]` 丰富游戏维度；不 Join 两侧指标，多游戏/未匹配保持显式状态。

## 失败优先证据

新增自动化覆盖查询边界、starts 映射、ID 命名空间、同日映射、指标守恒、旧缓存迁移和前端 CPI。首次执行时，同一广告键跨日对应不同 project 的夹具被误判为 ambiguous，证明候选映射缺少日期边界；已交回实现修复。
