# BUG-005 CSV Blob URL 生命周期过短

## 发现阶段

生产登录态浏览器回归；页面、筛选与数据均已正常加载。

## 现象

点击“导出当前 CSV”后页面无报错，但自动化在 15 秒内没有观察到下载事件。

## 根因分析

原实现创建临时 `<a>` 后直接点击，并在同一同步调用栈立即释放 Blob URL；这在部分浏览器或扩展控制环境中可能早于下载管理器接管。

## 修复说明

- 临时锚点先挂入 DOM，再触发点击；
- 1 秒后释放 Blob URL 并移除锚点；
- 前端契约增加 UTF-8 BOM、CRLF、DOM 锚点与延迟释放断言；
- CSV 仍只包含当前视图、筛选和分组后的结果，不传输到服务器。

## 影响范围

仅影响浏览器本地 CSV 导出；不影响数据读取、缓存、Nginx、MySQL 或定时刷新。

## 验证命令与结果

- `python -m py_compile ...`：PASS；
- `python -m unittest discover ...`：18/18 PASS；
- `python validate_frontend_contract.py`：PASS，包含 BOM/CRLF/锚点生命周期断言；
- 新 release 与生产登录态浏览器回归待发布后补充。

## 回归结论

本地回归通过；待服务器与真实浏览器回归。
