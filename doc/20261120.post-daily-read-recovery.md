# 发布日报读取恢复与已核实数量

FB 使用回滚日志数据库时，繁忙写入会使两秒读取超时。日报现在在只读事务中先取得读取快照，对数据库锁竞争最多等待十五秒；其他错误立即返回。保留二十五秒查询预算、只读连接与禁止写入设置。

X 的随机模板短暂启用后关闭，可能从未生成日计划。不存在的历史随机时刻无法可靠推算，完整应发数量仍保留未知。采集器额外记录冻结计划和运行已证明的数量，以及缺失计划的模板、版本和启用区间；重复发布证据同步去重。卡片将可证明的应发、未完成显示为 `≥数量`，成功和跳过继续显示确数。数据源读取失败仍显示未知，不通过零值或当前配置补齐历史。
