# BUG-002 领取客户端暂停意图必须先持久化

2026-09-20 独立部署脚本审查发现；尚未执行暂停，无线上影响。

原脚本先写paused=false，再发SIGSTOP和读状态。SIGSTOP异步完成，若确认或后续落盘失败，恢复代码仅看paused会漏恢复真实停止的进程。

修复：拒绝接管原本T/t的进程；将stop_requested、PID、start_ticks、initial_state先原子写入并fsync，再重新核对身份并发SIGSTOP，以5秒上限等待停止确认。恢复根据stop_requested或paused执行，并核对同一PID/start_ticks及unit MainPID。另将HK新env及旧drop-in校验前置到所有服务停止之前。

验证：独立静态复核通过，无剩余阻断；脚本py_compile通过。实际暂停/恢复结果在最终CPU验收记录中回填。
