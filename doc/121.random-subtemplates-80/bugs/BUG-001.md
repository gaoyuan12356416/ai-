# BUG-001 新生成JSON跨平台换行不固定

发现时间：2026-09-20，首次暂存后的Git whitespace检查；尚未部署。

现象：Windows `Path.write_text` 将新JSON换为CRLF；这些文件为保持SHA配置了Git -text，因此提交检查把CR识别为尾随空白，且相同生成逻辑在Linux下会产生不同manifest字节。

根因：JSON原子写入使用文本模式，未显式指定UTF8字节及LF。

修复：新构建器改用write_bytes固定UTF8/LF；只规范本次新manifest、additions与receipts，原base-manifest保持原字节，42个媒体文件及artwork不变。更新新manifest SHA，重新校验目录及其确定性选择；逐帧媒体证据保持可追溯。

状态：已修复。新SHA为b5df776a88bdfa961e60f60d6076c6915f37c5fd5ed8ade973dc4be7205eea6c；42项/2640帧完整复验通过，2000种子重复性与80项覆盖通过；45个Git index blob（manifest、base、artwork、42媒体）SHA一致；git diff --cached --check通过。工作报告将此修正称为BUG002，与本记录为同一构建问题。
