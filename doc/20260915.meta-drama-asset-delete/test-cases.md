# 验收用例

| 编号 | 场景 | 预期 |
|---|---|---|
| S01 | content_id指定英文版本，同资源其他语言存在 | 只命中指定content_id |
| S02 | series_code资源有多语言/多记录 | 展开该资源所有明确版本，冲突列阻止 |
| S03 | 仅选择W2A，无App | 仅W2A product，父App只解析资料 |
| S04 | 非短剧826、无权限产品、51输入/21产品 | 明确拒绝，无删除 |
| S05 | 名称子串/残缺marker/来源字段不全 | 不匹配或阻止；完整历史marker才可补充 |
| S06 | 素材product/语言冲突、同Ad跨产品 | 阻止且显示原因 |
| E01 | 三类阶段7种非空组合，前端逆序提交 | 服务端固定Creative→Ad→Video |
| E02 | Creative失败 | 其余Creative和后续Ad/Video继续 |
| E03 | Video执行 | DELETE视频节点，不能仅删账户关联 |
| E04 | 共享对象多条Ad引用 | 去重一次；范围外引用阻止 |
| E05 | Meta权限/100/超时/500/缺失分页 | 不得标已删除，失败/阻止/未知分类正确 |
| E06 | 重复request_id或不同任务同对象竞争 | 幂等返回或全局锁，未知结果不重放 |
| E07 | 成功后再次执行、明确失败人工重试 | 成功跳过，仅pending/failed可领取 |
| E08 | 台账claim/finish失败 | 不发出下一次DELETE，保留未知隔离 |
| E09 | 重启/PID重用/活进程 | 只回收死亡执行者；人工恢复，不自动删除 |
| A01 | 未登录、API Token、无模块权限 | 拒绝，普通权限默认为false |
| A02 | 产品/模块撤销，读取他人任务 | 拒绝或停止新增删除 |
| A03 | 旧任务详情和旧执行URL | 只读显示；执行410/404 |
| U01 | 产品搜索、多选、改输入、单独阶段 | 范围清楚、旧预览失效、确认阶段数量一致 |
| U02 | 对象分页、过滤、零命中、历史日志 | 统计不被分页覆盖，空状态明确 |
| U03 | execute HTTP响应丢失/503 | 保留同request_id核对，不能发新重复任务 |
