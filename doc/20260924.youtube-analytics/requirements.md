# YouTube 数据报表

2026-09-24。新增 YouTube 社媒 > YouTube 数据报表，复用现有飞书 Cookie、YouTube 模块及导航权限。普通用户仅本人，管理员同租户。

## 指标与维度
- 生成人：自动发布的冻结归因 owner，手动短链的 owner；不是素材上传人。历史链接仅在原发布账本与唯一租户映射证明归属后纳入。
- 剧名、剧 ID、频道 ID/名、语言、链接类型来自本地冻结记录，不用当前频道或剧库覆盖历史归因。
- 点击/访问来自落地页 clicks/views，不是 YouTube 播放或曝光。安装取 installs。付费转化默认取 recharge（数据库注释为充值人数），跨日累加每日人数，不能当作跨日去重人数或购买事件次数。
- 收入/退款取 revenue/refund_revenue，USD；先按整数美分加总。安装率=安装/点击，付费率=充值人数/安装；零分母显示空，不平均分组百分比。
- 生成链接数按链接 UTC 创建日统计，效果按 UTC 发生日统计，覆盖全部历史链接在所选期间的效果。
- 日期默认近7日截至昨日，最多93天。支持生成人/剧目/频道/类型/语言多选与剧名/ID搜索，1–3维组合分组、分页排序、趋势/排行/转化图和完整分组 CSV。

## 数据与安全
读 63350 只读副本 kunlunads_dev.ads_facebook_page_insight，固定 site_id=2284，索引 sd(site_id,dt)。冻结 (af_c_id,c) 二元组精确关联 (campaign_id,campaign)，不能按源 channel 排除收入行。先汇总源表，再关联单一归属，不能原始多表连接放大。

源数据失败返回503；无日记录为未同步而非0。只有部分日期有数据时保留缺日提示，合计仅含已有日；有日期分组的缺日指标必须null。未知/多归属数据不分摊；只有全部候选属于同租户的管理员可见待归属汇总，普通用户不暴露他人数据。

页面不触发YouTube API、OAuth刷新、发帖、短链生成、日报消息或任务状态写入。纯读取SQLite。查询走SQL FIFO Gate，8秒SQL、25秒子进程、全报表单次源读取并发1，范围缓存5分钟、最多8个范围；无后台定时器/新服务。
