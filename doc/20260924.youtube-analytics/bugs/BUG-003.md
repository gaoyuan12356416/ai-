# BUG-003 新接口未代理到公网

首次上线后，loopback真实Cookie报表通过但公网API返回404。根因：Nginx仅精确代理既有/api/youtube-auto-publish/，没有泛化/api转发。
修复：独立/api/youtube-analytics/代理配置，应用继续执行Cookie/导航/租户/owner鉴权，代理禁共享缓存。用GitHub新提交下的deploy_youtube_analytics_proxy.py备份有效配置、nginx -t及平滑reload，只新增此代理，不重启API或发布worker。失败移除新增配置并reload。
验收：公网匿名接口须401，授权报表/CSV须200。状态：待公网回归。
