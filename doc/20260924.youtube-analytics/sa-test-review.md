## QA 修订确认

- 测试只修改临时 fixture；catalog 读前后 SHA-256 一致，未创建数据库侧文件。
- 不从业务模块实例化发布客户端；所有 MySQL 子进程、来源查询、handler 均 mock，不读取凭证。
- 生成链接数按创建 UTC 日计数；效果按来源发生日统计；来源缺日未知与实际 0 分别验证。
- 多归属先在全 catalog 判定，普通用户不能靠筛选得到另一归属的数值；管理员不能看到跨租户歧义合计。
- CSV 包含公式转义、UTF-8 BOM、全分页导出、数据缺失提示和“充值人数逐日累加，未跨日去重”口径。
- 实际命令：`python -m unittest discover -s tests -p test_youtube_analytics.py`，40 / 40 通过（2026-09-24）。
