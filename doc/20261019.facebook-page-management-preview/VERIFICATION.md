# 验证记录

日期：2026-10-19。范围：新增 `doc/20261019.facebook-page-management-preview`，无生产接入。

## 本地验证

通过 JavaScript 语法检查及 `tests/links.cjs`：2310 路径、八字段映射、特殊字符编码、4 个星号分隔符、宏重复/未知/缺括号、UTF-8 5,000 字节边界、宏替换膨胀、缺少剧集来源、示例归因身份保护。

通过 `tests/browser-smoke.js` 全流程：

- 首次空列表、发布页空提示、无 Page 不能提交。
- 至少一个 Page、非空文案、非法/不完整宏校验。
- 搜索 Page、批量创建三个独立配置、禁止重复配置、独立修改及版本递增、刷新恢复。
- 示例剧目切换只影响宏预览，不将素材写入配置。
- 发布只展示这三个配置，默认不选择；过期授权禁选并展示原因；全选得到两个可用 Page。
- 两个 Page 文案独立；当前编辑不修改配置；切换预览与宏光标插入正确；保存草稿可恢复。
- 非法宏、替换后超长、未关联剧集的本地视频、过去预约时间均阻止提交。
- 确认逐 Page 展示两个不同模拟短链；页面没有模拟短链的可点击锚点。
- 两条任务冻结独立 ID、记录创建秒时间、文案及模板版本；八参数逐字段核对，UTF-8 编码及 `*` 保留；再次发布的模拟短链不同。
- 模板变更不改当前草稿/历史任务，显式重新套用可更新草稿；刷新后历史冻结值不变。
- 模拟本地存储配额失败保留输入，不写入或改变已保存配置。
- 1440、820、390 像素宽度：管理和发布没有页面横向溢出，编辑弹窗不超出视口，长链不溢出弹窗。桌面、手机截图已人工查看。
- 旧版本存储保留，直达 `pages.html` 进入管理页。浏览器无运行错误；网络仅同源静态 GET 和本地 blob 视频，没有 API、真实短链或平台请求。

测试中修正了测试驱动的重复按钮定位和无时长 WebM 夹具，发行页面未因此改变业务逻辑。最终测试夹具由 FFmpeg 生成，验证本地文件导入与缺失宏来源拦截。
