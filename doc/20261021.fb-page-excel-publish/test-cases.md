# 测试用例

环境：临时 SQLite、固定/可推进时钟、模拟来源/Graph、隔离浏览器。这里是测试设计；实际执行结果由 test-report.md 汇总。

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| XL-01 | 空模板、有效 IDs、两种加工/Token | 空模板不写任务；默认/显式值正确，每行使用自身准备状态 |
| XL-02 | 类型、2 MiB、200/201 行、损坏 ZIP、解压过大、虚假维度、稀疏格式超 20 万扫描单元格 | 正确边界；不截断、不无限扫描 |
| XL-03 | 空行、数值/文本 ID、超 15 位数值、小数/公式/布尔、J 列后的表头/值/公式、缺失可选尾列 | 原行号准确，拒绝精度损失/公式和额外列；正常缺省值保持可用 |
| XL-04 | 错产品/枚举、素材缺失/不合格、Page 无权/无配置 | 逐行原因；未配置 Page 整组跳过，其他保留 |
| XL-05 | 首行无效、次行同配对有效、第三行重复 | 保留首条有效，无效首行不占去重标识 |
| XL-06 | desc 覆盖/回落、宏、缺简介、最终字节上限 | 不改 Page 配置；只影响相关行；预检不建短链 |
| XL-07 | 同素材不同 Page 不同时间；先未来后立即；同时间；北京跨日 | 时间/行序后赋 page_sequence，各日正确计额 |
| XL-08 | Excel 日期、文本时间、过去时间、确认时过期 | 北京语义；不将过期改立即；复验失败不写任务 |
| XL-09 | 历史成功混合普通行，确认/不确认；全部重复 | 只有确认才重复；否则提交普通行；全跳过不建空批次 |
| XL-10 | 预检前后表/文件摘要 | 无 Page、任务、短链、成片写入 |
| XL-11 | 签名篡改、身份切换、来源/配置/历史变化、过期 | 拒绝、无部分写入，保留输入 |
| XL-12 | 并发/重复操作、首次响应丢失、同 ID 改确认选择 | 一次批次任务短链；更改冲突；恢复原结果 |
| XL-13 | 冻结中异常、额度不足 | 确认集合整批回滚，无孤立批次/任务/短链 |
| AUTH-01 | 未登录、API Token、缺模块、仅 Page 权限、跨用户/租户 | 授权正确；只读其 Excel 结果，不能读旧手动批次 |
| AUTH-02 | 旧入口传 schema 3、Excel 传旧形状 | 拒绝跨协议绕行 |
| TOKEN-01 | 多用户持有同 Page，个人模式 | 仅可信操作人关联 Facebook 身份；不混用两类用户 ID |
| TOKEN-02 | 个人授权无/空/封禁/后失效，快照策略或 owner 异常 | 跳过或安全失败，不回退他人 |
| TOKEN-03 | 范围内轮换：拒绝/回执/unknown/租约失效 | 仅明确拒绝重试；其余停止新写 |
| TOKEN-04 | 个人任务对账、旧快照缺省 | 对账同范围，旧任务旧默认 |
| TITLE-01 | 空标题与 Unicode 标题，检查 Graph mock 参数 | 非空独立提交，空值兼容旧调用，无凭证泄露 |
| POOL-01 | 空行、重复、非法、合法混合；超过 128 字符的非法输入 | 首次有效顺序；完整错误输入保留并去重，计数正确 |
| POOL-02 | 语言、池内重复、活动/unknown、缺宏值 | 逐项跳过；确认不能绕过未知占用 |
| POOL-03 | 历史成功混合，确认/不确认 | 确认才加历史项；不确认重签普通子集 |
| POOL-04 | resolve token 给原 add、版本变化、并发 | 完整签名一致；变化拒绝；同操作只入池一次 |
| POOL-05 | SQL/来源故障、读取失败、关闭后迟到响应 | 不误报全体不合格，保留输入，旧响应不触碰新弹窗 |
| UI-01 | 正常/全无效/部分有效/未配置 Page、重复点击 | 行原因可读；防重；无脚本错误 |
| UI-02 | 首次 POST 超时，查 404，原请求重试又明确拒绝 | 保留先前未知结果和原 operation，不开新操作 |
| UI-03 | 刷新/重开/换账号、预检过期恢复 | 按 tenant/user 隔离；优先查已接受操作，未确认请求不丢 |
| COMPAT-01 | v1/v2、池调度、记录、GPU、跨模块锁、额度、短链 | 既有回归通过，冻结历史不改 |
| DEPLOY-01 | 缺依赖、文件漂移、未排空、切换/恢复失败 | 部署拒绝或安全恢复，有 manifest，不覆盖数据库 |
| ROLLBACK-01 | 有活动/未知 schema 3 任务时回滚 | 关新入口，保留兼容 worker/对账，不退回旧策略 |

预检、成功、失败回滚、恢复分别核对表计数与关键内容。不凭 HTTP 200、服务 active 或测试数宣称真实 Facebook 发布成功。
