# Page Excel 批量发布与素材 ID 入池

## 目标与边界

2026-10-21 已确认：Page 管理页增加 Excel 批量发布；素材池改为逐行输入素材 ID。逐行给出校验结果，跳过无效项后处理有效项。只支持 Dramawave，继续使用现有素材资格、权限、队列、额度、短链和未知结果保护。

用户最后决定：**未配置的 Page 整组跳过并提醒先配置后重新发，不自动创建 Page。** 不补发历史任务，不修改既有 Page 文案、池启用状态或发布时点。

## Excel 规则

保留附件的 8 列及顺序，下载模板增加枚举下拉选项。

| 列 | 规则 |
| --- | --- |
| product | 必填，仅 Dramawave |
| page_id | 必填，须在当前用户访问范围内且已配置 |
| 制作模板id | 原片 / 随机模板；空值默认原片 |
| 是否使用默认token | 是 / 否；空值默认是 |
| resource_id | 每行一个素材 ID |
| desc | 非空覆盖本行文案；空值用 Page 文案；支持原有三个宏 |
| 发布时间 | 北京时间；空值立即发布；过去时间跳过并提示 |
| 标题 | 可选的独立视频标题；空值保持原行为 |

- 仅 `.xlsx`，上限 2 MiB、200 个非空数据行；表头、文件损坏或超限是整体错误，不截断后发布。
- ID 保持精确文本；疑似 Excel 精度损失、非整数、公式单元格提示修正，不执行或计算公式。忽略整行空白。
- 同 Page + 素材仅保留首条有效行；无效首行不能占用后续有效行的资格。
- 每行独立加工、Token 策略、标题和预约。同 Page 按时间、Excel 行序执行；立即时间在提交时统一计算。
- 历史已成功配对标记需确认。未勾选时跳过这些行，其余有效行仍可提交；全部跳过不建空批次。
- 预检展示有效/跳过数及逐行信息，不产生任务、短链、成片或配置。

## Token 归属

“是”保留同 Page 有效授权自动轮换。“否”沿可信登录身份的内部 sub_user_id，关联 ads_facebook_info.user_id -> facebookUserID -> ads_facebook_page_post.fb_user_id，仅取该身份对目标 Page 的有效授权。内部用户 ID 与 Facebook 用户 ID 不可混用。

预检只读个人授权资格/数量，不返回 Token。任务冻结策略与可信操作人内部 ID；执行及对账重新读取同一范围。个人授权缺失或失效时失败关闭，不回退其他用户。旧任务缺少新字段时保留原策略。

## 素材 ID 入池

原选择器替换为多行输入框和“确定添加”。清理首尾空白、忽略空行，最多 200 行，按首次有效出现顺序入队。重复 ID、缺失/不合格素材、语言不符、已在池内、活动/未知任务占用逐行跳过。

普通有效项不增加额外选择弹窗；历史成功项保留再次发布确认。展示成功/跳过数及原因，未添加输入保留。读取失败、版本变化、未知结果沿用原锁定、查询/重试协议。

## 技术与验收约束

- Excel 路由使用 Page 管理入口与现有模块/租户/登录校验，查询仅返回授权范围内 Excel 批次。
- schema 3 只由 Excel 路径接收，原 v1/v2 手动协议保持兼容；mixed 只用于汇总，任务冻结具体加工方式。
- 签名绑定完整请求、可信 actor、来源、配置、历史；先验完整签名，再过滤未确认历史重复。
- 有效集合一次原子冻结。操作摘要包含原始标准化请求和 allow_repeat，相同操作只能恢复同一结果。
- 逐项业务无效允许跳过；认证、SQL、签名/版本变化等整体故障不得伪装成逐行缺失。提交复验失败保留输入重新预检。
- 请求/任务快照保存新信息。网络查询在写事务外；最终守卫和冻结同事务。保持回执与 unknown 防重。
- 测试覆盖见 test-cases.md；实际结果和上线状态仅写入 test-report.md，本需求不表示已部署。
