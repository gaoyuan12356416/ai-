# X 标签画像模板页布局与账号筛选

列表移除重复的标签画像横幅、常驻隔离提示和预览入口；AI 文案开关缩为 16px。
常用操作为编辑、记录、手动执行；更多操作保留启停、复制、爆款发布和删除及原有确认。
操作人读取模板表最后更新人，缺失时回退创建人；只读补充 DTO，不改归因或历史。

编辑器复用 `/api/admin/x-accounts` 的累计收入美元与粉丝数，支持含边界的上下限、升降序、
与会员/搜索组合筛选。空值不限，未知指标不是零，排序时未知值在最后。
筛选不修改已选集合，选择当前结果只追加可见账号。指标加载失败不影响已有选择和保存。
收入使用现有账号运营统计快照，并显示过期/更新时间，不新增收入查询或改变发布规则。

验证：受影响 JS 语法、Python 编译、diff 检查；临时 SQLite 检查操作人回退和读取失败降级；
真实浏览器使用隔离 DTO 验证非空列表、更多操作、删除确认、查询/重置、16px 开关、1366px/390px
布局，以及指标边界、零/未知值、排序、组合筛选、隐藏选择保留、辅助接口失败后仍可保存。
所有浏览器发布/修改操作均在本地只读模拟端点，未发真实 Post。

部署仅改 `/root/drama_material_service`、`/usr/share/nginx/html`、
`/opt/x-tag-publisher/current` 中相应静态文件以及网关模块。
网关重启前等待其现有客户端退出；X 标签画像 Auto/Post 进程、触发器保持原状态。
脚本固定已检查的线上文件哈希，拒绝覆盖更新版本。代码备份保存在数据盘，未修改数据库。
运行目录中的旧编辑器说明为三级画像，公共版本已是两级；部署统一到已验证的公共说明和缓存版本。

安装（已从 GitHub 检出本分支精确提交后）：

```sh
python3 scripts/deploy_x_tag_template_ui.py install --folder /mnt/data-disk/x-tag-template-ui-20261119/backup
```

回滚（使用相同源码 checkout）：

```sh
python3 /mnt/data-disk/x-tag-template-ui-20261119/source/scripts/deploy_x_tag_template_ui.py rollback --folder /mnt/data-disk/x-tag-template-ui-20261119/backup
```

回滚只恢复上述代码/静态文件并重启网关，保留账号、模板、队列、发布回执和数据库。

## 同日加载优化：局部开关更新与正确的编辑首屏

X 开关成功后直接使用原接口返回的模板，更新当前行、启停数量、操作人、版本及下次执行时间。
不请求整个列表，不替换其他行，保留滚动位置、其他行展开菜单和当前开关焦点。
失败或结果不完整时仅回读当前模板；保留 expected_version、防重复提交及不自动重试写入。

FB/X 编辑页在保存配置返回前只展示加载状态，不展示新模板默认表单；读取失败提供重新加载。
模板配置与 Page 池/账号列表并行请求，导航刷新不再阻塞业务请求；收入粉丝快照在配置展示后加载。
真实配置到达即可编辑基本信息，选项加载期间保留已选数量，选项完整后才允许保存。
后到的选项只补齐各自区域，不覆盖正在修改的名称/文案；选项失败可独立重试。
保持登录权限检查和保存校验。未引入旧配置缓存，也未修改后端发布规则。

验证：真实浏览器配合本地模拟接口，覆盖开关后无列表 GET、其他行 DOM/菜单/滚动保留、
启停计数/操作人/下次时间更新、失败只回读一行；FB/X 延迟选项时首屏直接使用保存值、
输入不被后到数据覆盖、已选集合保留、详情失败不展示默认表单。
另验证选项先返回的并发顺序、选项失败重试保留选择和编辑内容，以及新建模板正常初始化。
模拟详情延迟 350ms、选项 2200ms、导航 2000ms 时，保存配置约 0.92/0.98 秒可见；
这是本地模拟验证，不代表线上端到端承诺。线上 X 原生只读详情/账号端点抽样约 0.009/0.043 秒。
