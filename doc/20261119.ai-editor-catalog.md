# 智能剪辑剧库与常驻导航

媒体库新增 DramaWave / MoboReels 两个来源，支持剧名或 ID 搜索、分页、按语言版本选剧、分集选择、后台导入、进度和失败重试。已导入视频进入当前用户的独立私有媒资库，选择后继续解析、剪辑、解说、翻译和导出。

后台导航由共享 QuickNav 常驻渲染；桌面布局为左侧导航、顶部创作工具、中部对话和视频工作区。窄屏文案面板浮层显示，手机导航保留折叠入口。使用原有浅色蓝色后台规范和共享用户栏。

## 独立边界

- 新接口全部在 `/api/ai-video-editing/catalog/` 下：`dramas`、`episodes`、`imports`、`imports/{id}/retry`。
- 不调用旧剪辑、MoboReels 后台业务接口。DramaWave 固定读取 `ads_drama_resource` 的 app 1479；MoboReels 只读 `ads_ai.cdreader_koc_drama`，限定机构、project_type=2 和在架剧目，向供应方的读取接口获取临时分集地址。
- 复用宿主的数据库连接配置和 FIFO SQL gate，只读副本验证、5 秒 SQL 限时、30 秒进程超时。搜索先走 content_id 索引，再走 name 前缀，默认浏览走 aacn 索引。MoboReels 凭证读取已有 `/etc/moboreels-library.env` 和环境变量，前端不接收供应方签名或视频原地址。
- `catalog_imports` 是独立 SQLite 增量表，租户与用户联合隔离、源版本和集号去重。单消费者每集 1 GiB / 10 分钟上限，120 秒租约和下载心跳，中断恢复最多三次。下载完成校验 MP4 后导入已有独立 assets，保留产品、剧名、语言和集号来源。失败可单条重试。
- 单次和每用户在途最多 20 集；服务器解析剧集地址，不接受客户端 URL；只允许公网 HTTPS，逐跳检查重定向。所有素材、导入记录、结果仍需原有 Cookie 权限。

## 验证与发布

- 既有 13 项独立编辑测试通过；新增 8 项测试覆盖不同租户隔离、重复导入、非法输入、过期租约恢复、真实资产入库链路、失败重试、产品来源隔离和私网地址拒绝。JS 语法与 diff 检查通过。
- Chrome 本地布局检查通过。正式环境真实剧集验收在发布后追加记录。
- GitHub 精确提交后部署，仅重启 `ai-video-editing.service`，GPU 渲染未修改；先检查本模块在途任务并在线备份 SQLite。
- 使用 `scripts/deploy_ai_video_editing.py install COMMIT`；备份位于 `/mnt/data-disk/ai-video-editing-deploy/backups/COMMIT/manifest.json`。代码回滚使用同脚本 `rollback COMMIT`，保留新增表、导入媒资和历史结果。
