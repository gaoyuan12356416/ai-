# Moboreels 推荐资源 ID 复制

推荐页增加「复制推荐资源 ID」，复制已查询的日期、业务类型、搜索、语言和推荐等级对应的全部结果，包括其他分页。输出供应方 `story_id`，每行一个，保留字符串格式、前导零和大整数精度；顺序与推荐结果一致，去除重复值。每条推荐支持单独复制。

完整结果在当前页时直接复制；否则通过现有只读推荐接口按每页 100 条读取。读取失败或分页快照变化时显示错误，不复制部分结果。切换查询会取消旧请求；空列表、查询失败及未登录状态不可复制。优先使用 Clipboard API，拒绝时尝试浏览器复制回退，两者失败时显示明确提示。

验证：`node --check static/moboreels-tools.js`、`node tests/test_moboreels_tools_ui.js`、`git diff --check`。Playwright 浏览器验证 125 条跨页复制、第二页复制全部、单条复制、筛选、未提交筛选、空列表、查询及跨页失败、剪贴板回退、失败提示，以及桌面和 390px 手机布局。

只部署 `static/moboreels-recommendations.html` 与 `static/moboreels-tools.js`，更新推荐页 JS 缓存版本。目标是 CPU 的 `/root/drama_material_service/static`、`/usr/share/nginx/html` 和当前 `/opt/moboreels-library/current/static`，不重启服务。发布前确认旧文件哈希并备份，发布后核对三处文件与公网响应哈希、两个服务的活动状态和 PID。部署清单及逐文件回滚脚本位于 `/mnt/data-disk/moboreels-copy-resource-ids-20261119/backup`，回滚仅恢复这两类静态文件，保留业务数据。
