- 入口伪造的 `af_dp/c/af_c_id` 被忽略。

- 本地页面控制台 0 error、0 warning。

## 遗留风险

- W2A 对无效 `content_id` 可能展示默认剧；未来若要前置判错，必须增加精确 resolver API 并比较实际解析 ID。
- URL 会进入 Nginx access log，不得把敏感个人信息作为透传参数。
