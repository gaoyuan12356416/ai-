# 测试用例

## 测试范围

列表默认入口、创建/编辑跳转、鉴权/权限门禁、筛选分页、原有写操作契约、响应式布局、生产静态发布边界。

## 测试数据

- 本地浏览器使用 mock Cookie 鉴权、Page 池与模板 JSON。
- 生产只读验收不创建模板、不启停模板、不手动执行。
