# BUG-001 截断尾数字误当Video ID

状态：已修复；P1；独立审查发现。

历史video_id为VARCHAR(512)。CSV在字段容量处截断时，尾段仍可能全是数字，通用stored_ids会将其作为另一个ID。直接删除不能采用该片段。

修复：core.stored_video_ids专用于此字段，满长CSV舍弃未以分隔符结束的尾段，保留完整前缀；完整JSON照常解析。source.resolve_ads使用该解析。不增加GET或删除门禁。

验证：python -m unittest discover -s tests -p test_fb_ad_asset_delete_*.py -q。包含301加重复15位数字截到512的结构，不能生成12位截断ID；覆盖完整512 CSV/JSON边界。独立测试通过。
