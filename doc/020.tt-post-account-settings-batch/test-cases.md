# 测试用例

## 测试范围

Core 原子事务、Service 批量能力与版本校验、HTTP/后台路由、管理页交互、既有单账号和发布池回归。

## 测试数据

- 3 个安全模拟账号，分别覆盖未配置、已配置和能力受限。
- 临时 SQLite，不使用生产账号设置。
- 生产只做登录态只读检测，不点击批量保存。
