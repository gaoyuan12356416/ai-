## 验证证据

- 末尾版本冲突时，前序账号设置和版本均不变化。
- 任一账号实时能力失败或能力不兼容时，批量保存 0 写入。
- 批量检测只返回共同隐私项，评论、Duet、Stitch 按全部账号能力取交集。
- 单账号接口、发布池、GPU 和三重门禁契约未改变。
- 生产候选 release 在服务器使用正式运行临时目录执行 TT 138/138 通过。
- 登录态页面显示 17 个当前允许发布的账号；批量选择全部 17 个并完成实时检测。
- 检测结果为 3 种共同观看范围，评论、Duet、Stitch 均可由运营选择；观看范围未选，互动和披露默认关闭。
- 页面“批量保存”保持禁用，验收直接退出批量模式，没有提交保存请求。
- 验收前后 SQLite 完整性均为 `ok`；账号 640 仍为版本 1，配置行数 1，队列数 0。

## 遗留风险

- TikTok 实时能力接口的延迟和可用性由上游决定；批量检测限制并发 4、单批最多 50，任一失败整批停止。
- 当前账号快照会动态变化；本次验收时账号 640 已不在 17 个可发布账号列表中，因此页面统计为已配置 0，但其历史配置行和版本仍安全保留。

## 发布建议

已按 GitHub 精确提交发布到 CPU 服务，GPU 未修改，Direct Post 三重门禁保持关闭。可以投入运营使用。
