# BUG-001：四小时同步超时后原制作仍运行

- 状态：代码修复及本地故障模拟通过；生产和长片验收待完成。
- 原任务：679e7c49acbf4af79f78bf60d76c5dd7，70 集。
- 原 CPU 11:15:01 发同步 render，15:15:01 读超时；自动重试碰到原 GPU 正在运行，返回 busy，CPU 写失败。
- 下载约 175 分钟，转码拼接约 26 分钟，14:36:48 才开始模板渲染；不能把四小时都解释为 GPU 排队。
- 根因：长制作生命周期被单次 HTTP 生命周期承载，CPU 超时重试和 GPU 实际执行状态脱离；固定阶段进度停在封面。
- 修复：持久异步任务、幂等输入/代次、短 HTTP + GET 重连、CPU lease fencing、原子完成及原生进度。
- 验证：超过四小时模拟、响应丢失、重复提交、旧代次、通知异常测试；不以真实原任务做故障注入。
