视频剪辑使用说明

上传一个素材，搭配多部短剧分别剪辑、分别出片。按下面的步骤完成选集、删减、插入、转场和成片下载。

01

开始使用

先使用飞书登录 AI 后台，再进入视频剪辑。如果看不到入口，请让管理员分配“视频剪辑”权限；能查询哪些短剧，还取决于你的产品权限。

  1. 第 1 步上传素材等待“可剪辑”
  2. 第 2 步添加短剧逐剧勾选剧集
  3. 第 3 步剪辑与插入每部剧单独编辑
  4. 第 4 步制作成片后台 GPU 执行
  5. 第 5 步预览与下载逐部剧取得结果
8 GiB默认单个上传文件上限
20 部默认每个项目最多短剧数
720 × 1280固定竖屏输出分辨率
MP4 · 30 fpsH.264 视频 / AAC 音频

一个项目选择一个素材，允许在时间线中重复插入；每部短剧单独生成一条成片。容量限制若由管理员调整，以页面提示为准。

三处入口各有用途：“素材库”负责上传和选素材，“剪辑工作台”负责编辑，“制作任务”负责看进度和取成片。

03

上传与管理素材

  1. 打开“素材库”。

    点击 上传本地素材，或把视频拖入上传区域。可以一次选择多个文件。

  2. 等待上传完成，再等待媒体校验。

    页面显示上传进度。文件由浏览器直接传到 COS；上传到 100% 后，仍需确认视频可读取、时长等信息，显示 可剪辑 后才能使用。

  3. 预览并选用素材。

    按素材名称搜索，点击 预览 检查内容，再点 用于剪辑，或回到工作台点击 选择一个素材。

上传中断怎么续传？

在同一浏览器重新选择同一个、未改动的原文件。不要改文件名、修改文件内容或清除站点数据；页面会尝试继续原上传。

短期上传签名到期会重新申请；遇到持续错误，请按页面提示处理。

谁能使用和管理素材？

有模块权限的同事共享使用素材；上传者和管理员可改名、删除。普通用户管理自己的项目和任务，管理员可查看全部。

删除是软删除，不会删除已提交任务引用的对象及已有成片。

两个“取消”含义不同：上传条目的“取消”会终止该上传会话；选集弹窗的“取消等待”仅取消自动加入时间线，详见下一节。

普通用户手动选文件上传，不需要安装或修改任何浏览器自动化扩展。素材和成片保存在 COS，通过临时链接预览、下载。

04

创建项目与添加剧集

  1. 新建并命名。

    在“剪辑工作台”点击 ＋ 新建，填写易于识别的项目名称，例如“竖屏素材 A · 两部剧剪辑”。

  2. 选择一个素材。

    从共享素材库中选择已通过媒体校验的素材。此时只是指定项目使用哪个素材，还没有将素材拼进时间线。

  3. 搜索短剧。

    点击 ＋ 添加短剧与剧集，选择产品，输入完整剧 ID 或至少两个字的剧名前缀，再点 搜索。

  4. 选择剧集并添加。

    点击短剧，勾选所需剧集，点一次 添加所选剧集。还未就绪的剧集会进入媒体校验；等待全部所选剧集就绪后统一加入。

  5. 继续添加其他短剧。

    重复以上操作。点击左侧短剧名称，切换它自己的时间线；每部剧的剪切、顺序和出片结果相互独立。

看到“已就绪 2/3，完成后自动添加”时：保持弹窗打开等待即可，不必重复点击。这里的 2/3 表示所选 3 集中已有 2 集校验就绪，不是整条成片的制作进度。

取消等待、关闭弹窗、按 Esc，或切换产品、短剧、项目，会取消本次自动加入。已排队的后台媒体校验仍会继续，稍后可重新选择并添加，复用已完成的校验。关闭整个页面后也不会自动往项目加入剧集。

05

剪切、删除与排序

只保留一段：调整入点和出点

点击时间线片段，在右侧“保留范围”中输入 入点 / 秒 和 出点 / 秒，或拖动入点、出点滑块。例如原视频长 60 秒，入点填 5、出点填 45，表示保留原视频第 5～45 秒，共 40 秒。

注意两种时间：入点、出点指原视频中的时间；播放器下方显示的是整条时间线的播放位置。前面插入素材、删除内容或加入淡化后，两者通常不再相同。

删掉中间：切两次，再删中间片段

示例：60 秒视频，删除原视频第 10～20 秒

为方便对照，示例假设该集从时间线 0 秒开始，尚未插入素材或设置淡化。

  1. 在删除起点切割。

    选中该集，移动播放位置到 10 秒，点击 ✂ 在播放位置切割。

  2. 选中后半段，再在删除终点切割。

    点击刚产生的后半段（原 10～60 秒），移动播放位置到 20 秒，再点击切割。

  3. 删除中间那段。

    选择原 10～20 秒片段，点击 删除选中片段。播放检查新的连接点。

需要删除同一集的多个区间，就重复操作。每删一段，后续内容在时间线上的位置会前移；请重新定位画面，不要直接沿用原视频秒数作为时间线播放位置。

整集移除

选中该集任一片段，点击“移除此剧集的全部片段”，移除当前短剧时间线中这一集的全部引用。误操作可立即撤销。

调整顺序

拖动时间线片段，或选中后点“左移 / 右移”。拆分后的片段可以分别排序；当前每部短剧最多 300 个片段。

06

插入素材与公共设置

手动插入：适合每部剧精细编辑

  1. 确定插入点。

    插在剧集中间时，先在目标位置切割，再选中相邻片段；片头、片尾可直接选择。

  2. 打开“插入素材”。

    点击 ＋ 插入素材，设置本次引用的素材入点、出点。

  3. 选择位置并确认。

    选择“选中片段之前”“选中片段之后”“片头”或“片尾”，点击 插入时间线。

同一个素材可多次插入，每次分别设置保留范围、画面适配和声音。只在左侧选好素材，不会自动加入成片。

多剧公共设置：一次应用到所有短剧

在时间线下方“多剧公共设置”中，选好“素材位置”和“衔接”，点击 应用到所有短剧。

素材位置点击后会怎样适用场景
片头 / 片尾替换各剧中当前素材已有的插入引用，再把整段素材放到指定位置；同时应用所选衔接。先给所有短剧统一片头或片尾，再逐剧精修。
仅应用衔接只统一各切点的衔接方式，保留当前素材引用的位置和裁剪。已精修好插入位置，只想统一直接切换或淡化。
应用前确认：公共设置会保留剧集已有剪切点和顺序，但“片头 / 片尾”会替换已编辑的素材插入。建议先应用公共规则，再逐剧调整；精修完成后要保留素材位置，请使用“仅应用衔接”。
07

画面、声音与转场

先选中时间线片段，再在右侧设置。下面的画面和声音选项只影响当前片段。

设置效果与操作
完整显示默认选项。完整保留原画面，比例不一致时空白补黑，适合需要保留边缘字幕或画面内容的素材。
铺满裁切居中裁切并铺满竖屏，画面两侧或上下内容可能被裁掉；请检查人物与字幕。
保留片段原声默认保留。取消勾选可将当前片段静音；没有音轨的原视频不会自动增加配乐。
直接切换默认衔接方式，前一段结束后直接进入下一段。
交叉淡化 · 0.3 秒当前片段与下一片段重叠淡化 0.3 秒，声音同步过渡。最后一段没有后续转场。
时长怎么算？所有保留片段的时长相加，再减去每个淡化切点的 0.3 秒重叠。例如 5 秒 + 10 秒，中间使用一次交叉淡化，预计总时长为 14.7 秒。

片段太短、无法容纳相邻淡化时，页面会指出具体短剧和片段位置。需要延长保留范围，或把相关切点改为直接切换后再制作；系统不会悄悄改变你选择的效果。

浏览器预览主要用于定位和检查片段顺序。最终转场、声音同步和画面适配，请以制作出的成片为准。

08

保存与撤销

  • 自动保存：修改后会保存草稿，也可主动点击 保存草稿。离开前确认出现“已保存”或“已自动保存 · vN”，其中 N 是项目版本号。
  • 继续编辑：用 打开项目… 选择已保存项目。媒体信息载入时先等待；失败时点 重试载入。
  • 撤销：点击 ↶ 撤销 回退当前页面、当前项目的最近编辑。刷新或重新打开项目后，不保留这段撤销历史。
  • 版本冲突：多个标签页或多人同时修改时，按提示处理。需要保住当前未保存内容，可点 将本地修改另存副本；确认不需要本地修改后，再刷新读取服务器版本。

修改已提交制作的项目，会形成新版本。已经提交的配方和已有成片不会被新的草稿覆盖。

09

制作、预览与下载

  1. 逐剧检查，再点击“制作成片”。

    确认各剧的保留内容、素材插入和转场。一次提交会为每部短剧创建独立制作任务。

  2. 在“制作任务”看进度。

    任务由 GPU 服务器执行下载、剪切、拼接和成片上传。提交成功并出现任务后，即使离开页面，后台也会继续处理。

  3. 完成后预览、下载。

    在该剧任务中点击 预览 或 下载。原素材和成片使用临时访问链接，页面提示有效期；过期后重新点击获取新链接。

看到的阶段含义你需要做什么
排队等待制作槽位，与其他视频任务共享 GPU 调度。等待即可，不需要重复提交。
准备 / 下载获取原素材、剧集并检查媒体；大文件可能耗时较长。查看当前阶段进度，稍后再看。
制作按保存的片段、顺序和转场制作。等待；显示的进度属于当前阶段。
上传成片正在存入 COS 并核实结果。等到“制作完成”再取成片。
制作完成该剧成片已可用。预览检查，再下载。
失败 / 结果待核实某阶段失败，或暂时无法确认上传结果。按错误提示处理，在原任务点“核实并重试”。
重试只处理需要恢复的任务：同一项目版本重复提交会返回原批次。某一部剧失败时，用它自己的“核实并重试”，其他已成功的剧无需重做。需要改剪辑内容时，先修改并保存新版本，再提交制作。

成片规格固定：MP4、H.264 / AAC、720 × 1280、30 fps。下载后建议完整播放一遍，重点检查切点、音画同步、字幕是否被裁切。

外部制作及盈量入库：待接入。当前可完成剪辑出片、预览和下载；不会自动调用外部制作接口，也不会自动推送盈量自定义素材库。
10

常见问题

点击问题展开。异常时保留页面提示和对应项目、任务信息，便于管理员定位。

点击“添加所选剧集”后为什么没有立即出现片段？

先看弹窗的媒体校验进度。出现“已就绪 x/y，完成后自动添加”表示请求已受理，全部所选剧集就绪后会统一加入。保持弹窗打开，不要反复点；如果明确报错，按该条提示处理。

点“取消等待”会停止 GPU 校验或制作吗？

不会。它只取消这一次自动加入时间线的意图，已经排队的后台媒体校验仍会继续，也不会取消已经提交的制作任务。下次重新添加时可使用已完成的校验。

素材已选好，为什么成片里没有？

选择项目素材不等于插入。请点击“插入素材”并确认“插入时间线”，或使用多剧公共设置添加片头、片尾；提交前检查时间线上是否确实有素材片段。

上传到 100% 后，为什么还不能使用？

文件上传和媒体校验是两个阶段。等素材显示“可剪辑”再选用；若提示校验异常，可使用“核实媒体校验”。结果未知时先核实原会话，不要重复上传同一内容。

搜索不到短剧怎么办？

先确认产品选对；剧 ID 要填写完整，剧名搜索至少输入两个字的前缀。仍查不到时，请管理员核对你的产品权限和该剧的数据状态。

为什么切割按钮提示“请将播放位置移到片段内部”？

必须先选中要切的片段，再将播放位置放到它的内部，不能在片段的起点或终点重复切割。注意播放器时间是整条时间线位置，入点、出点则是原视频时间。

为什么应用公共片头后，之前插入的素材不见了？

公共“片头 / 片尾”会替换当前素材已有的插入引用，并重新插入整段素材。可以立即撤销；保留精修过的素材位置和裁剪时，请改选“仅应用衔接”。剧集本身的剪切点和顺序会保留。

制作等待较久，能不能关闭页面？

确认提交成功、已出现制作任务后可以关闭。排队、下载大体积剧集和成片上传都需要时间；稍后打开“制作任务”或点击“刷新任务”查看。还在本地上传或尚未保存草稿时，请先完成这些步骤。

一部剧失败了，要把整个项目重新做一遍吗？

不需要。找到失败或结果待核实的原任务，按提示使用“核实并重试”。无法确认远端结果时，系统可能继续核实；不要新建重复任务绕过。共享校验若提示无恢复权限，请联系发起人或管理员。

视频链接过期或下载失败怎么办？

回到素材或成片的原记录，重新点击预览、下载获取临时链接。不要把过期的临时链接作为永久交付地址；这份使用说明的公开 COS 地址与视频的临时访问链接不同。

能直接推送到盈量自定义素材库吗？

本期不支持自动推送，外部制作接口显示“待接入”。当前先下载剪辑成片，后续接口接入后的操作以新版说明为准。

11

出片前检查

  • 每部短剧都选对了剧集和顺序。
  • 不需要的中间内容已切割并删除。
  • 素材已真正插入每条所需时间线。
  • 素材各次插入的保留范围已确认。
  • 画面适配不会裁掉人物或关键字幕。
  • 原声、静音和每个切点的衔接已检查。
  • 短片段与淡化的校验提示已处理。
  • 草稿已保存，预计时长符合预期。
