# BUG-008 点击添加缺少反馈、校验完成不能自动继续

状态：已修复并通过本地/浏览器验收，待静态发布回读。

## 证据与根因

用户截图选中三集，其中两集已有媒体数据、第三集校验中，点击“添加所选剧集”后没有即时忙态，底部要求完成后再次点击。正式账本第三集北京时间14:53:14创建、14:53:17.818 GPU开始、14:53:32.242 GPU完成、14:53:37 CPU ready，总23秒，generation=1无错误。

`addEpisodes`在首个await前没有加载/锁定，校验提交后return；后台轮询不会继续添加。轮询每6秒查询全部列表中前20个未就绪来源，4轮80个GET中76个为未选且没有校验任务的剧集。没有轮询单飞，旧异步响应缺少弹窗/项目归属检查。

产品读取使用本地共享缓存，无重复SQL瓶颈证据。详见私有本地验收证据`output/video-editing-responsive-validation/probe-latency-before.json`，不包含媒体URL或凭据。

## 修复要求

立即忙态与弹窗内进度；单次选集自动续加；关闭/切换取消自动继续；防重复/过期响应；仅选中来源有界单飞轮询；保留原探测恢复与提交幂等语义。验证结果、部署提交与回滚在完成后补充。

## 验证结果

51/51前端测试及独立只读审查通过；最终Chrome慢请求验收立即显示2/3，单次probe、仅跟踪第三集，自动加入3片/30秒。取消/关闭仅取消自动添加意图，未知提交保留逐源查证；共享task权限隐藏不触发替代任务。详见test-report与sa-code-review。本次只发布三个页面文件；技能上下文新增一条可复用规则，已有个人技能条目及memory文件保留。
