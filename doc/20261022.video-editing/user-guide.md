# 视频剪辑一期使用说明

完整图解版见 [HTML 使用说明](user-guide.html)，包括工作台示意、删除中间内容的分步示例和常见问题。

入口：[AI 后台视频剪辑](https://ai.yingliangads.com/video-editing.html)。使用原有飞书登录；管理员可在用户管理中分配“视频剪辑”权限。剧目列表还受现有产品权限控制。

## 1. 上传与选择素材

打开“素材库”，点击“上传本地素材”或拖入视频，支持一次选择多个文件。单个视频最大 8 GiB，文件从浏览器直接上传到 COS。页面显示上传进度；上传后还会进行媒体校验，成为“可剪辑”状态后才能使用。

上传中断或刷新页面后，重新选择同一原文件即可续传。请勿改名、修改文件内容后当作原文件继续；对于“正在核实结果”的上传，先等待原会话核实，不反复创建新上传。

有模块权限的同事可使用共享素材；上传者和管理员可以改名、软删除。删除后不能用于新项目，已提交任务使用的冻结对象仍保留。

## 2. 为每部短剧建立时间线

在“剪辑工作台”填写项目名称，选择一个素材，再点击“添加短剧与剧集”。选择产品后，用完整剧 ID 或至少两个字的剧名前缀搜索，选择所需剧集并添加。选择项目素材不会自动将素材拼入时间线，还需使用“插入素材”或公共片头、片尾规则。

点一次“添加所选剧集”后，未就绪剧集会进入媒体校验；弹窗显示就绪数量，全部就绪后自动统一加入，无需重复点击。“取消等待”、关闭弹窗、Esc 或切换产品、短剧、项目会取消本次自动加入，已排队的后台校验仍会继续。关闭页面后也不会自动加入；稍后可重新选择并添加。

一个项目最多添加 20 部短剧，每部剧分别编辑、分别出片。左侧切换短剧不会覆盖其他剧的剪辑内容。

## 3. 剪切、排序和插入

- 点击时间线片段，在右侧输入入点、出点（原视频中的秒数），或拖动范围滑块。播放器位置指整条时间线，插入、删除和淡化后通常与原视频秒数不同。
- 删除一集的中间内容：选中片段，把播放位置移到删除区间起点，点击“在播放位置切割”；选中刚产生的后半段，在删除终点再切一次，选择中间片段并删除。可重复删除多个区间，每次删除后重新定位画面。
- “移除此剧集的全部片段”会移除当前时间线中这集的全部引用；误操作可用“撤销”。
- 拖动片段或用“左移 / 右移”调整顺序。
- 在任意切点先选中相邻片段，再点“插入素材”，选择片段之前或之后。也可直接插入片头或片尾，同一素材可重复插入，并分别设置保留范围。
- “多剧公共设置”的片头、片尾会替换每部剧中当前素材已有的插入引用，重新插入整段素材并统一衔接；剧集片段已有剪切点和顺序保留。需要保留精修的素材裁剪及重复插入位置时，选“仅应用衔接”。

草稿自动保存，也可手动“保存草稿”。请确认显示“已保存”或“已自动保存 · vN”后关闭页面。多人或多标签同时编辑发生版本冲突时，可将本地修改另存副本；确认不需要本地修改后再刷新读取服务器版本。撤销只保留当前页面当前项目的最近操作历史，刷新或重新打开项目后不保留。项目媒体信息加载失败时使用“重试载入”。

## 4. 画面、声音和衔接

输出统一为 MP4、H.264/AAC、720×1280、30 fps。“完整显示”保留完整画面并补黑；“铺满裁切”居中裁切填满竖屏。取消“保留片段原声”可单独静音。

每个衔接点默认直接切换，也可选择 0.3 秒交叉淡化，声音同步过渡。时间线预计时长会扣除重叠；片段太短时，页面指出具体短剧及片段位置，需要调整后再制作。浏览器预览用于定位剪切，最终画面和声音以成片为准。

## 5. 制作、预览和下载

点击“制作成片”后，在“制作任务”中分别查看每部剧的排队、下载、制作、上传和完成状态。制作共用现有 GPU 单渲染槽位；原剧视频较大时，下载阶段可能较长，可离开页面，后台会继续处理。

成功任务可预览、下载。链接有有效期，过期后重新点击预览、下载获取新链接。同一项目版本再次提交会返回原有制作批次，包括刷新或重新打开项目后的提交。失败或结果待核实的任务使用该任务的“核实并重试”，不需要重新制作已成功的其他剧。编辑已提交项目会形成新版本，已提交配方和原成片不会被覆盖。

失败任务停止 24 小时后会清理临时媒体。确认尚未上传过成片的任务仍可通过恢复入口重新制作；上传结果不明或存储暂时不可查时会保留查证限制，不能用重复提交绕过。

“外部制作及盈量自定义素材库推送”当前显示“待接入”，不会调用外部接口。
