# Mobo 社媒分销收入日报

目标群：`oc_57b890fed0b872cf15ef3f5b6899f53e`。每天北京时间 10:00，以前一天日期读取 Mobo 分销收益，按人和渠道播报。视觉结构参考现有 11:00 社媒发布人日报。

收入采用现有 Mobo Effects 投影：充值减退款加广告收入，保留 Decimal 精度和真实发布人归属。机构范围来自服务器受保护配置；仅此独立系统日报读取机构全部数据，网页身份、模块权限、租户和用户校验不变。多渠道共用／待归属金额只计一次并单列。未同步数据标为不完整，不宣称零收入。收入按供应方来源日期（时区未注明），点击按北京时间，Post 按 UTC 自然日，页面说明三者差异。

发布量使用成功短链的冻结创建人、任务 ID、账号和素材，与原生发布回执再次匹配，并按平台＋账号＋Post ID 去重。当前实际 Mobo 自动发布来源为 Facebook 自动任务和 X 发布日志（含标签发布库）。结果未知、失败、短链创建、非发布用途不计成功；其他类型出现时显示接入缺口，不推断成功或外部手动发布量。只读连接原生 SQLite，不实例化任何调度器、同步器或发布服务。

`features/moboreels_daily_report/{transport,delivery}.py` 基于线上 11 点日报已经验证的发送实现保存独立快照，改为独立命名空间。分片先冻结再发送，保留每片 UUID、消息 ID 和发送状态。确认成功不再发送，未知发送需读原回执核对，不能因超时清账本重发。每日日期＋目标群唯一。

独立服务 `/opt/moboreels-social-daily-report/current`；持久目录 `/mnt/data-disk/moboreels-social-daily-report`。唯一发送调度为服务器 `moboreels-social-daily-report.timer`，每日北京时间 10:00 触发，不依赖本地电脑。`Persistent=false` 避免首次安装后立即补发；当天服务启动前会检查日期和 10 点截止。部署不执行 `--send`，不修改 11 点定时器或任何发布队列。本聊天的 Codex automation 每日 10:05 只读核对回执，不能发送或重发群消息。

验证：`python -m unittest discover -s tests -p test_moboreels_daily_report.py -v`；服务器 `python3 scripts/moboreels_social_daily_report.py --preview`。样例与真实发送分目录，预览不写发送账本。

回滚：`systemctl disable --now moboreels-social-daily-report.timer`（只停计时器，不停止正在发送的服务），暂停对应 Codex automation，等本服务本次调用自然结束，恢复部署 manifest 中的前一 release（若有），或移除本次新装的 service。保留全部日报、冻结载荷和发送回执；不回滚业务源数据，不重启发布服务。
