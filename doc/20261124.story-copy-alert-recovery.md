# Caption alert recovery and diagnostics

Delayed quota alerts could describe captions that had already recovered. A packet
could also count the same task twice when both its automatic and operator retries
failed. Provider failures retained only a generic reason, losing the upstream
error needed for diagnosis.

Before a packet's first delivery, read the current caption state and the native
final receipt. Suppress recovered/AI/manual/off tasks using an additive
`alert_resolutions` audit table; do not fabricate a sent timestamp or receipt.
Defer an event still being regenerated without delaying other events. A native
fallback receipt remains a real failed AI caption and is explicitly described as
having adopted the existing copy. Deduplicate packet items by task key and show
both the original alert time and the status-check time in Beijing time.

Already-attempted packets retain their exact body, membership and idempotency key
until the delivery receipt is reconciled. Existing sent messages are not edited
or withdrawn. Automatic retry count and publication behavior are unchanged.

Provider RPC/turn failures now retain bounded, redacted error details in the
generation batch's `reason` JSON and worker journal. Public failure codes remain
compatible. No credential files or full provider responses are logged.

Validation: `python -m unittest tests.test_story_copy -q`. Coverage includes
recovered suppression, native-receipt precedence, duplicate task counts,
regeneration deferral, immutable retries after an unknown alert delivery, and
redacted provider details persisted with the failed task's batch.

Deploy from the pushed commit using
`python3 ops/story_copy/deploy_alert_recovery.py prepare /mnt/data-disk/story-copy-deploy/alert-recovery-20261124`,
then the same command with `apply`. The installer checks the active base, saves a
SQLite backup, waits for current generation batches to finish, and switches only
`story-copy-worker.service`. Native publishers and their receipts keep running.
Use the same installer with `rollback` to switch code back; never restore the
database over newer task or publication state.
