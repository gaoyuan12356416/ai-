# 验收用例

| 分组 | 必测结果 |
|---|---|
| 页面 | 1366×768/1920×1080 无横向溢出，共享导航/顶栏，无演示按钮 |
| 表单 | 素材、频道、标题、描述必填；首评选填；提交失败保留草稿；相同请求复用 operation_id |
| 素材 | SQL 空态无查询/无 fallback；无效 SELECT/跨产品/重复 ID 拒绝；提交重新校验素材 |
| 宏 | 三字段单次展开；未知/双层宏报错；名称含大括号不递归；url 原合成参数与编码一致 |
| 本地封面 | JPG/PNG 实际解码；大小/像素边界；非法格式与篡改摘要拒绝；先预览后上传 |
| AI/审核 | 未批准不能 enqueue；拒绝意见必填；新版历史保留；旧版 CAS409；通过及手动替代各一次交接 |
| 权限 | 匿名401、无权限403、跨租户/跨owner404、管理员替换封面可被原创建者继续访问 |
| 状态机 | private上传；封面失败不能 public；processing pending 不能 public；public读回成功才记录发布 |
| 异常 | 上传缺Location/断线未知不得重新建会话；重启 lease fence；首评未知不能自动重复 |
| 通知 | 审核卡片稳定 uuid/outbox；发送失败可从后台审核；无任何模拟发送入口 |
| 兼容性 | 原 synthesis/canary/encoding/HK/统一账本回归原样通过 |

外部 API 使用 mock，不进行真实 YouTube 发布、首评或飞书发送。生产 SQL 保留空态。
