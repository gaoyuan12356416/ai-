# BUG-001 上传会话未知结果可能被错误降级

严重度：P1；状态：已修复、离线回归通过。
复现：begin_resumable返回HTTP200但缺少Location；或者先出现传输未知结果，再查询会话收到403。原处理会把结果认作明确失败，造成重新建会话/重复上传风险。
修复：reviewed engine将身份未确认状态持久化为unknown，不准创建替代会话；后续查询拒绝保持unknown；同素材有session仍阻止替代。
文件：features/youtube_auto_publish/engine.py，features/drama_synthesis/core.py。
验证：`python scripts/test_youtube_auto_engine.py`，41项通过（含上述两个明确复现）。
