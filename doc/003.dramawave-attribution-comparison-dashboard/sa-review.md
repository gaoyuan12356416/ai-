## 决策记录

- 页面默认 D0 指标，同时提供 D7 累计切换。
- 事实缓存不保存行级 ROAS；所有比率在查询聚合后计算。
- Campaign/Ad Set/所有大整数 ID 按 TEXT 处理。
- CSV 走后端同一查询编译器，避免页面展示和导出口径分叉。
- 使用 TT 看板同等 Feishu 租户鉴权门禁，但独立 Nginx location、服务和缓存。
