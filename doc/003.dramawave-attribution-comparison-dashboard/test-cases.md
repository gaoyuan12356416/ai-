# 测试用例

## 测试范围

覆盖 D7/D30 数据口径、分层映射、SQLite 刷新原子性、60 天保留、服务端聚合 API、前端交互、Feishu 鉴权与服务器定时调度。业务源库验证仅使用 63350 只读连接。

## 测试数据

- 固定边界：北京时间 `2026-07-29`（含当天）。
- 真实点样本：`2026-07-29 / ad_id=120250136876120737`，新 D30 表 D0 收入 `225.54`、D7 累计收入 `245.23`。
- 单元测试 fixture：同一实体 Android/iOS 多行、Ad/Ad Set/Campaign fallback、一对多歧义、零分母、刷新故障注入。
- 浏览器测试：临时 SQLite fixture + 本地只读 Web 服务；生产缓存/API、未登录飞书跳转已验证，已授权生产会话视觉检查待首次登录补验。

- 业务 MySQL 无 DDL/DML；只读连接校验仍然生效。
