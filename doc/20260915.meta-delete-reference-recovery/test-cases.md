# 测试用例

- 原输入/资源展开、App/W2A权限、固定阶段、未知结果 fencing、成功跳过、历史只读全部回归。
- 完整空快照与非空快照；精确视频 ID，不串产品/账户；CSV/JSON去重；超过250目标分段SQLite查询。
- 源EOF缺完成标记、非零退出、超时、重复源行、只读证明缺失均不发布；fresh失败不回退旧索引。
- TTL从开始计、原子发布失败、fsync失败、SQLite失败、磁盘不足、全局构建锁与畸形视频字段。
- recheck幂等、执行互斥、冻结ID/成功项/attempts不变、权限撤销、永久归属冲突保持阻止；核验后必须人工执行。
- Meta完整错误白名单脱敏；实际凭证与探测凭证区分；账户停用提示但不声称具体子码语义；无隐式DELETE重试。
- UI核验期间按钮锁定、提交未知保留request_id、dirty/历史任务禁用、详情XSS转义。
