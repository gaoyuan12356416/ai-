# Moboreels 剧库加载优化

首次打开页面同时读取登录态、目录和同步状态，只有登录与模块权限验证成功才显示内容。缩略图仅适用于无签名查询的已知供应方 CDN，前 8 行优先加载；失败仅回退原图一次。推广状态轮询仅修改按钮，避免重复构造封面节点。过时筛选请求取消，相同读取合并，后台标签页停止轮询。

目录公共字段使用进程内 30 秒、64 项缓存并合并同查询；同步任务状态变化失效。每个用户的推广状态在目录副本上单独添加，不共享缓存。HTTP API 保持 no-store，开启 JSON 压缩；JS/CSS 使用内容哈希版本沿用站点不可变缓存。读取仍走既有 SQL FIFO。

本地验证：87 项 Python 测试、Node UI 状态流测试通过。上线前样本：列表 DB 读取 4.124/2.890/3.130 秒；首张封面原图 88,100 字节，120×168 边界 WebP 缩略图 7,146 字节，减少约 92%。这些是接口和图片样本，不代表浏览器整页耗时。

部署：GitHub 推送后服务器取精确提交，在对应 release 运行 `python3 ops/moboreels-load-20261113/deploy.py COMMIT`。安装器校验 f787e620 线上基线、备份文件与 SQLite、只重启 moboreels-library.service 并 reload Nginx。其他发布服务不重启。

回滚：执行安装器返回备份目录下的 `python3 rollback.py`。只回滚代码与配置，保留当前目录、推广记录、同步进度和回执。部署后的实测指标另存验收记录。
