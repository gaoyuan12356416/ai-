# BUG-002 恢复旧版首页后健康状态仍指向新日报

独立QA在发布前以内存publisher复现：恢复上次v3首页成功，但独立status.json仍指向本次新日期，导致页面提示与实际入口不一致。

修复：备份存在旧v3首页时的成功health；若发布前health为failed，取last_success。内容回滚校验不依赖可变健康状态，成功恢复旧v3首页后同步备份成功health。首次升级没有旧v3首页时保留新页面与对应health，只恢复旧alias。

验证：test_publisher新增两项，含failed状态在期间变化和首次升级保留准确状态。20项publisher测试通过；完整回归见test-report。
