# BUG-001：未知发布长期阻塞整个 Page

- 严重度：P1。
- 复现：同 Page 存在 worker_interrupted / unknown，上传不同素材 Excel，整页所有行被跳过，后续 queued 也不能领取。
- 根因：Page-wide guards、unique index、cross-family triggers、前序任务条件和中心未知资源隔离同时生效。
- 修复：精确素材未决保护，只有活跃写入持 Page 锁；原生约束和中心投影一致升级。
- 状态：已修复、测试通过并上线；18 条真实未知任务已迁为素材隔离，截图 15 行解除误拦。见 test-report.md。
