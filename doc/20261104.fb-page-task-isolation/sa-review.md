## 结论

同意把不确定结果的防重边界缩小为真实 Page ID + 素材 ID。未知任务继续保留原账本、短链和回执核对；不同素材可继续提交、准备和发布。真实在途 POST 仍按 Page 串行，已有对象 ID 的任务只做 GET 对账。

以下问题必须由实现和验证共同关闭。此文档是设计评审，不能代替测试通过或上线证明。

## 决策记录

- 真实 Page 和素材身份不按租户拆分；同素材未知不能通过另一租户、另一个批次、另一个 Token 或 manual/auto 切换绕过。
- `status != unknown` 但 `unknown_outcome=1` 的历史记录仍是未决素材；源账本与发布账本需共同覆盖。
- 缺失或非法素材 ID 的历史未决记录不能凭空获得素材级身份；优先从冻结证据唯一解析，无法解析时保留明确的保守保护并告知，不能无条件放行。
- 已成功重复发布仍沿用既有显式重复确认，不能因缩小锁范围自动重发。
- 不借此扩大 Page 授权、Token 使用范围或自动恢复已停用计划；不补发用户未授权的其他 Page。
- 没有证据证明未提交的旧任务不得重置成 queued；允许不同素材继续并不等于允许旧任务再试。
- 本批新导入跳过的 15 行不自动补发；仅修复阻塞和已存在的两条旧任务，之后由用户重新上传原 Excel 保留原设置。
