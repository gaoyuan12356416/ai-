# BUG-003 线上能力提示与实际开关不一致

## 发现阶段

最终线上浏览器验收。

## 现象

真实暂停、复制和调度开关已经开放，但规则组页面顶部仍显示硬编码的“自动调度尚未发布”，容易让测试人员误判接口未接通。

## 根因分析

页面提示文案没有消费 `/api/ad-control/v3/meta` 返回的能力状态。

## 修复说明

由标准 JavaScript 根据 `scheduler_enabled`、`scheduler_live_enabled` 和 live 权限动态渲染三种状态：未开放、仅观察、正式执行可用。

## 验证结果

线上已登录页面显示“真实暂停、复制与自动调度已开放”和“正式执行可用”；按钮可操作，页面无业务脚本错误。

## 回归结论

关闭。
