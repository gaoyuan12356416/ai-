# BUG-001 ad-control-v3-live-execution

## 发现阶段

SA 代码评审。

## 现象

组合复制函数若在拿到一个新对象 ID 后、完整返回结果前失败，调用者最初无法看到局部 ID，隔离逻辑可能漏掉该对象。

## 复现步骤

让 Campaign `/copies` 返回新 ID，再让随后的 GET 回读失败。

## 期望结果

新 Campaign ID 立即进入隔离状态，异常处理能将其重新 PAUSE。

## 实际结果

初版只在整个 `_copy_tree` 返回后赋值，局部异常时外层状态为空。

## 根因分析

复制状态使用函数返回值而非贯穿各层的可变事务状态。

## 修复说明

在每次 POST 响应取得 copied ID 后立即写入共享 state，再执行 GET/映射验证；任意后续异常均遍历该 state 执行 PAUSE。

## 影响文件

`features/ad_control_v3/live_execution.py`

## 验证命令与结果

Python compile、V3 151 项和 V2/共享调控 115 项定向回归全部通过。

## 回归结论

关闭。
