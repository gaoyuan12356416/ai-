# BUG-028：现有 MySQL batch 输出重复转义 OAuth JSON

类型 P1，实机集成兼容缺陷。59f95e6 的 CPU/v3 writer 部署和 272 项离线回归通过后，单次 canary prepare 在 credential 阶段返回 youtube_channel_not_eligible；此时发布行、短链、真实上传和评论均为 0。

CPU 63350 对精确账户 255/频道 263 的直接驱动读取证明原 JSON 正常、状态启用、四种必要 scope 和 refresh token 均存在。现有 run_mysql 的 batch 输出使 JSON 中的斜杠多转义一层，repository 得到带字面反斜杠的 scope，因而安全门禁误拒绝。不是原授权失效，也不能要求用户重新授权来掩盖解析问题。

修复范围仅 YouTube repository 两个 JSON 列：SQL HEX 传输，严格 hex→UTF-8→JSON object 还原；不改全局 run_mysql、不修改原表或 Token、不放宽 scope/身份条件，不打印原文。新增真实转义形状、Unicode、坏 hex/UTF-8/JSON 和缺权限拒绝用例。原始 token/client 指纹仅保存在 CPU 私有证据用于守恒比对。
