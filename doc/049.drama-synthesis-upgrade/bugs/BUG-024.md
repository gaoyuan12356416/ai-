# BUG-024 演练 datadir 缺少真实路径隔离检查

独立 QA 报 P1：原实现只比对 Docker datadir Source 字符串，未排除 data 子路径 symlink、异设备或同设备嵌套 bind 指向既有数据；凭据父目录验证不足以覆盖此风险。现场本轮目录正确，未观察到实际越界写入。

已增加全部路径组件 lstat、无 symlink、真实目录/resolve、同 st_dev、独立 data mount 与 findmnt 实际覆盖路径检查，Docker mount 类型必须 bind；均发生于数据库连接和 DDL 前。专项包括 symlink、嵌套 bind 与异常元数据拒绝。最终独立回归见 [测试报告](../test-report.md)。
