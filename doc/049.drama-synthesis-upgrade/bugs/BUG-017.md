# BUG-017 分辨率切换导致随机模板丢失片头时长

2026-08-27，P1，已关闭。时间轴与时长校验已修复，当前 HK release `e1f5a1d04cfb510df9c2444ac592adec2827508b` 的 v3 auto/manual 完整下载解码和重启复用已验收；独立只读复核报告及 8 PNG 无新阻断。此前 c719 的重复 POST 失败已由 BUG-020 闭环，不再列作当前未修复项。

## 发现与修复

历史复现输入为 1 秒 1280×720 片头、两段各 2 秒 360×640 素材；输入 5.021016 秒，原随机图生成 3.966667 秒却通过旧 codec/尺寸检查。分辨率切换重建滤镜图时源分支 `setpts=PTS-STARTPTS` 再次归零，损坏时间轴。

仅在 drama 适配器精确替换首个源分支为 `setpts=PTS`，保持四个资产分支和 FB 原图不变；缺失/重复目标前缀或上游引入 copyts 时失败关闭。不额外加全局 copyts/start_at_zero。再增加源时长、输出容器时长、输出视频流时长的固定 0.15 秒容差，防止用音频填充掩盖视频截短或长视频比例容差容忍整秒丢失。
