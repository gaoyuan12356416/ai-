## 根因与修复

根因：mono reference 的标准差为零时仍直接相除；全静音和 L=-R 反相立体声都受影响。直接把该情况全部归零又会丢失反相素材。

修复：单样本使用总体标准差，mono reference 近零时回退全声道标准差；常量/近静音才使用单位分母；空输入、非有限输入统计及非有限模型输出明确拒绝。
