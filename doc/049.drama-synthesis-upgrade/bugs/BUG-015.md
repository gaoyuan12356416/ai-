# BUG-015 Demucs 静音与反相立体声归一化产生 NaN

2026-08-27，P2。状态：代码修复、离线边界复验与真实静音/反相 CUDA 专项 PASS，修复起于 `647f6ceec6bdd440b2e08d28dfaba03288cd09f3` 并包含在已 QA 候选 `c719bebf72be900ec3853858dc53b36b83beffd2`。HK c719beb 正常样本的真实 no-BGM/auto 制作也通过。

## 根因与修复

根因：mono reference 的标准差为零时仍直接相除；全静音和 L=-R 反相立体声都受影响。直接把该情况全部归零又会丢失反相素材。

修复：单样本使用总体标准差，mono reference 近零时回退全声道标准差；常量/近静音才使用单位分母；空输入、非有限输入统计及非有限模型输出明确拒绝。

## 验证边界

早期修复复核为 11/11 adapter 单测，以及真实 adapter 主流程加假模型的静音、反相、单样本、正常、空、输入 NaN、输出 NaN 七项探针；这是历史轮次，不与本轮统计相加。最新独立合并回归 166/166 PASS 已覆盖 runtime 测试，25 文件语法/Python 3.9 AST PASS。

主代理已回报并在 [HK 实测](../hk-gpu-setup-20260827.md) 记录专项：专用服务用户、真实 CUDA 与 mdx_extra_q 四模型，1 秒静音得到 44100 帧、peak 0；2 秒反相立体声得到 88200 帧、peak 0.0079345703125；两者均 finite，非假模型。该证据关闭本条归一化缺陷，不将其他 fake 边界冒充真实推理。
