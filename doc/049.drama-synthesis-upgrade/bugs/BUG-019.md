# BUG-019 Canary 未验证 writer 健康即开始上传

2026-08-27，P1。状态：修复并经独立 QA 复核 PASS，包含在候选 `c719bebf72be900ec3853858dc53b36b83beffd2`。最小复现使用 fake，无真实 OAuth refresh/YouTube 上传。

## 最小复现与根因

为 UnifiedYouTubeWriter 配置一个会抛异常的 executor，CLI 只检查配置存在即推进任务；writer 从未被调用时，fake begin/upload 已各发生一次。18837 不可用或账号/schema/grants 不合法也会直到上传后才暴露，无法满足外部副作用前的前置门禁。

## 修复

在任何任务 claim、上传 attempt、OAuth refresh 或视频请求前，必须执行 writer.preflight。复用既有鉴权 GET `127.0.0.1:18837/health` 的只读检查，不新建宽权限接口、不暴露凭据或 grants 原文。

服务端每次检查 CURRENT_USER、@@read_only、精确 schema/index 和最小权限闭包，成功仅返回严格合同：ok=true、contract=drama-youtube-writer-preflight-v1、schema=kunlunads_dev、writer_identity=drama_youtube_writer@43.166.187.96、writable/schema_verified/indexes_verified=true、64 位 grant_fingerprint。客户端拒绝缺字段/额外字段、旧合同、身份/权限/结构漂移、401、跳转、超时和异常；仅配置 URL/凭据或进程存活不算通过。

涉及 scripts/drama_youtube_canary.py、features/drama_synthesis/unified_youtube.py、unified_youtube_rpc.py 与对应测试。普通 public 接口权限未放宽；长期 writer 仍只允许三表级 SELECT/INSERT/UPDATE，不持有 DDL。

## 独立验证

test_run_requires_writer_before_upload 和 test_writer_health_schema_or_grant_drift_stops_before_any_youtube_call 覆盖未配置、伪 executor、健康失败/异常/超时/重定向、错 schema/identity/grants 等路径。独立重跑原探针后 claim、refresh、begin/upload 均为 0，上传 attempt 不变；成功合同才允许继续精确 canary task。

与 BUG-018 合计九项独立定向复核 PASS，已包含合并 166/166，不重复计数。当前生产 ads_aius 仅 SELECT/SHOW VIEW，无合法 admin/migrator/writer，故此修复应继续阻断实际上传；不能为通过测试绕过健康门禁、打开正式 live 或伪造健康返回。
