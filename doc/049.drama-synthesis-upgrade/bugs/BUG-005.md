# BUG-005 lease 仅有 owner/时间而缺少持久化 generation fencing

> 2026-08-26：本文保留为历史缺陷证据；generation fencing 要求继续有效，但旧表/状态描述不得覆盖本轮精确 SQLite 合同。

- 级别：P0 重领并发状态安全
- 发现：独立 QA Wave 2
- 现象：lease 到期被第二 worker 重领后，第一 worker 仍可用仅按 task id 的更新覆盖新 worker 的 session、published 或 failure 状态。
- 修复：SQLite 增量增加 `lease_generation INTEGER NOT NULL DEFAULT 0`；claim 原子递增并返回 generation；session、offset、video/comment published、fail、comment attempt、renew 全部以 task+owner+generation 为写入条件，stale claim 返回 409 且不写事件/状态。下载分块与每次外部调用前续租。
- 回归：旧 SQLite additive migration；双 worker expiry/reclaim 对抗拒绝 stale session/offset/published/fail/comment 写；current owner 完整成功；评论 attempt 后 runtime 中断保持 unknown。
- 状态：已关闭；独立 stale-write 回归 5/5、migration concurrency 400/400 PASS。
