# BUG-012 香港 GPU 运行交付缺失

## 发现阶段

2026-08-27 生产发布前只读预检，P1。运行交付缺陷已修复，独立代码 QA 与香港 GPU 实际沙箱媒体验收通过；不代表 CPU/YouTube 正式发布完成。

## 现象与复现

候选 unit 指定系统 Python 3.9，香港 GPU 未安装应用第三方依赖。默认 Demucs 解释器/脚本位于不存在的 `/root` 路径，且与 `ProtectHome=yes` 冲突；候选未包含该脚本、依赖锁或已校验模型包。

## 期望

从精确 GitHub SHA 和固定运行依赖即可安装；专用用户在 sandbox 内可执行真实 CUDA 去背景音乐及随机视频制作，不依赖旧主机私人路径。

## 根因

离线代码 QA 未覆盖干净香港主机的可安装性及 systemd 沙箱下的完整运行依赖。

## 修复与验证

补齐独立 Python 3.10.20、55 项固定依赖、torch/torchaudio 2.5.1+cu124、可版本化 Demucs 脚本、四个已核对 SHA 的模型、20 个只读 FB-v3 资产及 env/service 配置。专用用户和实际 systemd 沙箱预检、真实 CUDA tensor、静音/反相四模型分离均通过。

最终 HK 运行 e1f5a1d04cfb510df9c2444ac592adec2827508b，v3 自动/手动模式四产物、下载解码、封面回调、即时重复 POST 与服务重启重放通过；独立 QA 核验报告及 8 帧 PASS。详细证据见 [HK 实测记录](../hk-gpu-setup-20260827.md)。本运行交付缺陷关闭；生产目标库授权仍阻塞 CPU 应用切换和指定频道真实测试，见 [部署状态](../deployment-status-20260827.md)。
