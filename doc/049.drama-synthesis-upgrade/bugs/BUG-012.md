# BUG-012 香港 GPU 运行交付缺失

## 发现阶段

2026-08-27 生产发布前只读预检，P1，待修复与独立复验。

## 现象与复现

候选 unit 指定系统 Python 3.9，香港 GPU 未安装应用第三方依赖。默认 Demucs 解释器/脚本位于不存在的 `/root` 路径，且与 `ProtectHome=yes` 冲突；候选未包含该脚本、依赖锁或已校验模型包。

## 期望

从精确 GitHub SHA 和固定运行依赖即可安装；专用用户在 sandbox 内可执行真实 CUDA 去背景音乐及随机视频制作，不依赖旧主机私人路径。

## 根因

离线代码 QA 未覆盖干净香港主机的可安装性及 systemd 沙箱下的完整运行依赖。

## 修复与验证

补齐独立 runtime、可版本化脚本、模型清单、env/service 配置及自动化检查；实际进度见 `../hk-gpu-setup-20260827.md`。尚未验收，不预填 PASS。
