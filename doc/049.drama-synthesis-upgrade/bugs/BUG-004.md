# BUG-004 刷新 token 未与冻结频道做运行时绑定

- 级别：P0 外部发布身份
- 发现：独立 QA Wave 2
- 现象：服务端凭证行与冻结 `channel_id` 在入队时匹配，但刷新出的 bearer 未在外部发布前查询实际授权频道；凭证漂移可能把视频或评论发到错误频道。
- 修复：eligibility 新增 identity-read scope 门禁；每次刷新后、创建 resumable session 前、评论前调用只读 `channels.list(part=id,mine=true)`，只接受唯一 item 且 ID 与冻结频道恒等。空、多项、不匹配、401/403 均失败关闭；网络/5xx 仅在外部 mutation 前安全 retry。
- 回归：fake HTTP 覆盖 mismatch/empty/multiple/transient，engine 覆盖四种情况下 begin/upload/comment 计数均为 0；成功链路核验三次。
- 状态：已关闭；独立 identity 回归 PASS（7/7），未触发真实 mutation。
