## 发现与根因

附件规定内部 unlisted canary，但旧任务冻结、YouTube 上传/处理验证和统一表 writer 均硬编码 public。直接打开正式入口测试会偏离附件。另发现新功能评论请求未完整提交 channelId、误把 thread ID 当作 comment ID；正式 public 与 canary 路径均需修正。

## 修复合同

- 内部 CLI 必须显式授权并确认 app 1479、channel_local_id 263、youtube_account_id 255、channel_id UCHJ1jFaYuW8g5EM7hM5pPpg。固定 operation 为 drama-hk-deploy-unlisted-20260827-shahrul-263；重复操作员复用同一行，只 claim 精确 canary_task_id。
- prepare 从已完成真实 job 的冻结结果选择 source，不接受任意 source_url；复用描述 {{url}} 短链和完整发布/评论/outbox 链。配置来自私有文件/环境，输出不泄露凭据或 session URI。
- 正式 HTTP/UI 固定 public，拒绝内部 privacy/operation；普通 worker/outbox 跳过 canary。内部模式保持正式 live/sync=0，上传冻结 unlisted、notifySubscribers=false，绝不更新为 public。
- 视频必须精确匹配 ID、processed/succeeded/unlisted。上传会话创建前持久化 intent，unknown 只对账原 session/video；评论 unknown 持久阻断，不重新 POST。已成功评论不会因同步重跑而重发。
- 所有发布引擎的评论均传冻结 channelId/videoId，仅接受相符的 snippet.topLevelComment.id；2xx 缺失/错配仍 unknown。官方合同：[commentThreads.insert](https://developers.google.com/youtube/v3/docs/commentThreads/insert)、[commentThreads 资源](https://developers.google.com/youtube/v3/docs/commentThreads)、[videos 资源](https://developers.google.com/youtube/v3/docs/videos)。
- 后续独立复核发现并修复的同步隐私漂移与上传前 writer 门禁分别见 [BUG-018](BUG-018.md)、[BUG-019](BUG-019.md)。
