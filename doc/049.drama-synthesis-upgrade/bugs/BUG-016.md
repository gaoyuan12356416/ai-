# BUG-016 香港 GPU 随机滤镜自动线程池超出服务上限

2026-08-27，P1。状态：线程限制适配已修复，包含在候选 `c719bebf72be900ec3853858dc53b36b83beffd2`；独立 QA 与 HK 真实 auto 随机制作通过。完整发布仍 HOLD，不等于所有模式/重复请求已验收。

## 发现与根因

现象：片头/拼接/去背景音乐/COS 上传成功，随机成片返回 500。同一命令在普通服务用户进程下成功；在与制作服务一致的 TasksMax=128、CPUQuota=200% 中原命令 0.66 秒失败，FFmpeg 报 `Resource temporarily unavailable`。

原因：复用的 FB 多层滤镜图自动扩展线程池，超出独立剧集合成服务的线程数预算。

## 修复与复验

仅剧集合成适配器为该命令显式添加 `-filter_complex_threads 2`；不扩大系统线程限制，不改 FB 服务及其构图函数。独立合并回归 166/166 与 25 文件语法/Python 3.9 AST PASS；代码测试不冒充 FFmpeg 实测。

主代理已在同服务沙箱复验并使 c719beb 的 auto concat/no-BGM/random 全部完成，COS 三文件下载、5 秒/150 帧/解码检查通过。随后同 job/payload 二次 POST 发现新的幂等失败；该问题与本线程故障分开记录，仍禁止 CPU 切流。完整双模式及最终运行证据见 [HK 实测](../hk-gpu-setup-20260827.md)，本条不将未执行项预填 PASS。
