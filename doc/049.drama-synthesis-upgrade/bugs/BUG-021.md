# BUG-021 新缓存缺少随机成片 profile 仍可返回

## 发现阶段与风险

2026-08-27 缓存增量独立代码评审，P2，尚未发布该增量。正常 renderer 会写 profile；损坏或缺字段的版本 2 manifest 却只验证 URL/大小及两个 SHA，仍可能返回 200，与新格式必须完整的合同不符。该问题没有触发实际云写入或重新制作。

## 修复与复现

`gpu_cache.verify_artifacts` 对任何已保存的随机产物，在发起 HEAD 之前要求 `random_template_output_profile == RECIPE_PROFILE`，并验证 output/recipe SHA。不能因为本次仅请求 concat 就接受同一 manifest 中缺失的随机产物字段。

新增用例覆盖 profile 缺失、错误值、正确值；前两者失败关闭且 HEAD 调用为 0。实现者 focused 22/22 PASS；独立对抗复验通过，P2 已关闭。188 项合并及文档修复定向复测见测试报告，不重复计入旧 166 例统计。
