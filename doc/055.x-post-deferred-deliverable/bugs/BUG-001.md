# BUG-001 x-post-deferred-deliverable

## 发现阶段

生产运营截图与只读诊断。

## 现象

未到可投放时间的素材显示“不可用”；到达可投放时间三天后仍未再次校验或参与排期。

## 复现步骤

1. 入池一条 `deploy_time > now` 的 Dramawave 素材。
2. 确认保存 `drama_not_yet_deliverable`。
3. 推进当前时间超过 `deploy_time`，执行素材候选查询。
4. 该行未返回，`last_checked_at` 不变。

## 期望结果

显示“待可投放”；边界前不发布，边界后进入下一次自然排期复检并可在完整预检通过后
原子建队列。

## 实际结果

记录派生为 `validation_failed`，且候选 SQL 不包含该错误码，形成永久冻结。

## 根因分析

`REVALIDATABLE_MATERIAL_VALIDATION_CODES` 和候选 SQL 漏掉
`drama_not_yet_deliverable`；事务 FIFO 临时跳过集合也漏掉该码；API/UI 又把所有非
非阻断错误统一显示为 `validation_failed`。

## 修复说明

已新增派生 deferred 状态、候选复检、同批次 FIFO 证据和 UI/API 合同。被选中的历史
等待行还必须携带本轮 selector 返回且已到点的 `drama_deploy_time`，否则事务拒绝建队列。
