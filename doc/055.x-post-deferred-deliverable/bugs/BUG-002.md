# BUG-002 旧素材阻断判定兼容性

## 发现阶段

X 全量命名回归。

## 现象

`scripts/test_x_posts.py` 仍调用 `_material_validation_is_blocking`，实现改为三态派生函数后
旧符号不存在，502 项回归中出现 1 个 `AttributeError`。

## 根因

三态重构删除了既有私有兼容入口，但仓库内仍有调用者依赖该入口。

## 修复

恢复薄兼容函数；它委托 `_material_validation_availability`，仅当结果为
`validation_failed` 时返回真。`deferred` 与历史非阻断提示都不会被误判成永久失败。

## 验证

- 原失败用例：1/1 通过。
- 完整 `test_x_post*.py`：502 项通过，skip=1，失败 0。

## 状态

已关闭。
