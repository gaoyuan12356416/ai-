# X 标签画像模板手动终止

运行记录操作栏为 queued/running 批次增加「终止」，确认后调用现有登录和页面权限保护下的 `POST /api/admin/x-tag-auto-publish/runs/{id}/terminate`。只终止本次批次，不修改模板或后续计划。

同一事务记录操作人、终止批次及未发布任务，停止已生成但未发出请求的原生队列；保留素材占用和去重账本。已发出的请求及未知结果继续保留回执核对。旧筛选/准备线程的晚到结果由任务终态触发器拦截。原生发布每次授权读取来源时，拒绝已终止批次继续提交新的请求。重复终止幂等，不重复创建发布或审计事件。

验证：`python scripts/test_x_tag_run_control.py` 覆盖队列/回执、并发晚到结果、幂等、范围隔离、鉴权、同源和原生发布来源；`node scripts/test_x_tag_run_control_ui.js` 执行真实页面脚本验证按钮、确认、重复点击、刷新与错误恢复。生产部署前在真实数据库副本演练。

部署仅覆盖 Tag 网关及本页静态资源，在 GitHub 提交后由服务器拉取。运行 `python3 scripts/deploy_x_tag_run_control.py apply --directory /mnt/data-disk/x-tag-run-terminate-20261117/deployment`。安装现有 Tag 专用 admission hold，等待完整的在途 publish claim 结束，仅重启 `x-tag-gateway.service`；不重启发布、Auto 或共享协调器，不停止其他渠道。prepare 和 Auto 选择由原生服务继续执行，不等待无关制作完成；网关只承担 publish 的来源/归因查询，切换前还等待网关已有连接结束。finally 在网关健康后释放临时 hold，记录前后 PID 和逐文件校验。页面同时更新 runtime/main/Nginx 三份及缓存版本。

回滚：在同一 GitHub source 目录执行 `python3 scripts/deploy_x_tag_run_control.py rollback --directory /mnt/data-disk/x-tag-run-terminate-20261117/deployment`。从 record.json 中的逐文件备份恢复代码并只重启网关。保留当前数据库、取消事实、去重占用和终态触发器，不恢复数据库快照。若已终止批次还有在途回执，保留网关保护直至核对结束，回滚脚本会明确拒绝撤掉这层保护。
