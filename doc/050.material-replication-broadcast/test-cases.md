# 测试用例

## 测试范围

2026-08-27 测试计划，以下用例全部待执行，不代表通过。

覆盖新接口、两种消息、精确制作人映射、独立 outbox、幂等、冻结投递、未知结果、安全窗口、租约、兜底及旧链路回归。不覆盖上游聚合作业的内部实现，也不以真实飞书发送作为验收手段。

## 测试数据

- 使用虚构用户名 `editor_a` / `editor_b`、测试邮箱、虚构 `ou_` / `oc_` ID；实际制作人与优化师刻意不同。
- 临时数据库同时预置旧 outbox 的历史、排队和重试行；新表初始化两次，逐行比较旧数据。
- 两种事件分别准备 1、50、51 项；准备中文、emoji、引号、反斜杠、换行及边界长度。超 wire 容量用合成数据或降低测试常量构造，禁止绕过生产校验。
- 注入假时钟、租约竞争、HTTP 假响应和发送后落库失败；拦截外部网络，仅允许测试自建 loopback HTTP 服务。
- 3300 秒是本阶段首次可能发送后的固定安全窗口，不是每次重试的新窗口。
