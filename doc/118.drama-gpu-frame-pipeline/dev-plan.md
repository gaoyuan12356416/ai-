# 开发计划与完成记录

1. 固定实际 60 秒素材，比较 30 秒制作片段的基线、缓存和原生 GPU 路径。
2. 独立 RGBA V2 缓存：复用已验证像素、恢复原始 PTS/duration，18 项全量校验。
3. NVDEC/CUDA/NVENC 子进程：显存内转换、同配方合成、QP19 IPP 编码，复用已有拼接和音频。
4. 接入原有子进程跟踪、进度、检查点和启动预检；依赖精确版本与 wheel SHA 锁定。
5. 330 项自动回归；实际 GPU 的像素、时间轴、循环、整片、续跑和服务账号验证。
6. GitHub 提交、精确 SHA release、备份、单服务切换、原任务恢复与隧道核验。

代码与数据库边界：CPU 无需此次代码部署，无 DDL。详见 deploy.md。
