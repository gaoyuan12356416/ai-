# SA 需求评审

结论：在固定输入媒体回归与真实服务预检通过后可部署。范围限 HK 剧素材 worker，CPU 业务边界不变。

| 风险 | 处理 |
| --- | --- |
| 透明 VP9 无法直接按现有路径完整硬解 alpha | 离线原解码器解出 RGBA，逐帧验证并缓存 |
| NVIDIA 1.0.2 demux/seek 不保留可靠 PTS | PyAV demux + 无 B 帧 FIFO；不调用不可靠 seek |
| 横竖屏 SPS 切换及分片音画对齐 | 显式重建 decoder；容器时钟；原视频独立逐帧 QA |
| 缓存耗尽、篡改或旧时间戳 | 空间上限、只读哈希回执、V2 独立目录，失败关闭 |
| 重启重复制作或混用旧分片 | 内容指纹含代码/内核/运行时；保留检查点和进程证据 |

评审为本次执行者自审；没有声称独立人员复核。
