# 036.TT 随机叠加制作与剧名宏需求/技术设计

## 背景

TT 素材池发布与 TT 自动发布当前临时使用 `source_direct`，GPU 不执行 FFmpeg。现需恢复视频制作，但不得复用或删除历史片尾制作方案；新方案通过轻量随机几何变换及五类模板叠加生成差异较小的排重视频。

## 目标

1. 两套 TT 发布入口支持精确宏 `{{drama_name}}`。
2. 新增独立可回滚 media profile，保留 `source_direct`、`direct_outro` 及其历史。
3. 每个发布任务从边框、光效、透明度视频、四角动画、透明底五类各选一个模板，生成并冻结唯一制作配方。
4. 修复导出素材中的不透明黑底，不要求产品重新导出。

## 范围

### 包含

- 素材池预览、配置、排期/自动队列和立即测试的服务端文案渲染。
- 自动发布模板校验、任务文案冻结和重试。
- GPU 新模式 `random_overlay` 与 profile `tt-post-random-overlay-hevc-720x1280-v1`。
- 五类模板资产的版本清单、哈希校验、黑底转 Alpha、循环叠加、随机配方和成片校验。
- CPU 素材池、CPU 自动发布、GPU 三方 profile/trim 同步切换。

### 不包含

- 删除或改写旧片尾、转场、`direct_outro` 历史成片。
- 迁移已经 consumed/published/unknown 的历史任务。
- 为验收触发真实 TikTok 发帖。

## 业务规则

1. `{{drama_name}}` 只接受精确小写双花括号写法，替换为素材冻结的真实剧名。
2. 模板使用该宏但剧名为空时，预览/入队/自动任务必须失败关闭，禁止退回 Drama ID。
3. 每个 GPU `job_id` 的配方必须稳定：同一任务重试复用；不同发布任务重新随机。
4. 配方由不可变任务身份和资产集版本确定并写入 GPU manifest，包含五个文件、透明底最终 Alpha、旋转角和缩放比例。
5. 旋转为连续离散化值 `-2.000..2.000` 度；缩放为 `0.9800..1.0200`；透明底最终 Alpha 为 `0.1000..0.2000`。
6. 98% 缩小或旋转露边时，以未变形同帧原视频补边；主画面完整居中。
7. 新制作保留原视频完整时长和原音频，不加旧片尾、不做旧转场、不裁尾。
8. 动画层循环至源视频结束。叠加顺序固定：原视频补边 -> 旋转/缩放主画面 -> 透明底 -> 透明度视频 -> 光效 -> 边框 -> 四角动画。

## 模板资产规则

- 边框：3 个 PNG，使用原 Alpha。
- 光效：2 个 GIF；黑色视为导出底色，转为带柔边 Alpha。
- 透明度视频：5 个 GIF；先按已知 5% 黑底预乘关系恢复 RGB，再转为最大约 5% Alpha，不再次乘 5%。
- 四角动画：3 个 GIF，保留原 Alpha。
- 透明底：7 个 PNG；每次选一个，并把 Alpha 覆盖为配方中的最终 10%-20%，不是和文件原 Alpha 相乘。
- 大文件不进入 Git；部署到 GPU 数据盘的版本化目录，Git 只保存构建脚本、清单契约和非敏感哈希。

## 技术设计

### 文案

共享 `render_caption_template` 增加 `drama_name`/`defer_drama_name`。旧素材池和自动发布所有真实渲染点必须传入冻结剧名；配置语法检查可 defer，实际预览和任务冻结不可 defer。

### GPU

- `WorkerConfig` 在 `random_overlay` 模式启动时加载并完整校验资产 manifest、文件路径和 SHA-256。
- 配方通过稳定 SHA-256 字节流派生，不依赖进程内随机状态；manifest 记录配方及资产集 SHA。
- 新 FFmpeg filter graph 只使用已验证的模板文件，所有参数由边界化数值格式化，不接受请求侧 filter 文本。
- 成片沿用 720x1280、30fps、yuv420p、AAC-LC、HEVC/H.264 交付契约。

## 验收标准

1. 两套入口正确渲染 Unicode 剧名；缺剧名时返回稳定错误且不创建发布任务。
2. 五类各抽一个，数值均在边界内；同 job 重试配方和输出身份稳定，不同 job 配方可变化。
3. 光效/透明度视频黑底在成片中不形成黑色矩形；透明边缘无明显硬边。
4. 输出时长与源视频一致（允许编码容差），音频保留，旧片尾不存在。
5. 三方健康检查显示同一新 profile、trim=0，旧 profile 仍可通过配置回滚。
6. 全量 TT 回归通过；验收不产生新的 TikTok publish_id。
