- 真实长视频的 GPU 编码耗时和输出码率仍需在生产 GPU 上用只 prepare、不 publish 的受控样本确认。
- 附件动效本身较明显，这是模板设计效果；代码未额外降低边框、光效和四角动效的不透明度。
