# BUG-005 旧 SQLite 不支持迁移测试的 DROP COLUMN

2026-09-11 CPU Python 3.9.6 上，509 项回归仅迁移夹具失败（另有一个既有图片 fixture 跳过）。测试通过 ALTER TABLE DROP COLUMN 模拟旧结构，但生产 SQLite 不支持该语法。生产 migration 本身只追加列，并未使用 DROP COLUMN。

修复：测试用兼容旧 SQLite 的建表、复制、替换临时夹具构建旧结构，再验证已有视频 ID、会话及尝试次数不变。不能跳过迁移验证。修复与 CPU 复验结果在测试报告记录。生产代码未因该问题修改。

验证完成：本地33项专项通过；CPU最终509项回归508通过、1历史图片fixture跳过，迁移项通过。修复提交aa450e964d344151b7bb940718022685073112d0。
