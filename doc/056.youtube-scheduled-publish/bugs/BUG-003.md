# BUG-003：预约未知结果轮询可能反复创建异常提醒

- 级别：P2；发现方式：独立跨模块代码评审。
- 场景：预约写入结果未知后，worker 定时只读核验同一视频，每轮更新账本 updated_at_utc。
- 根因：历史异常提醒事件键使用 updated_at_utc；如果预约轮询沿用该时间，就会把同一次未知结果误认为新的失败。
- 修复：预约状态机持久 schedule_event_at，仅在预约意图/状态或错误原因改变时更新；通知器在 schedule 阶段使用该时间，其他历史阶段沿用原事件键。
- 验证：`python scripts/test_youtube_schedule_service.py` 15/15 通过。`test_readonly_schedule_polling_keeps_one_notification` 使用真实候选查询与独立通知 SQLite：两个新的轮询时间只保留一条通知、一条 outbox；明确新意图时间才创建第二条通知。
- 状态：通知器修复已验证；状态机 schedule_event_at 保持性由 engine 专项回归确认。
