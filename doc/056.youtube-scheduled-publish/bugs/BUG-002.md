# BUG-002：过期任务审核导致重复错过时间提醒

- 级别：P2；发现方式：独立隔离行为复现。
- 场景：任务错过预约时间后，用户再批准该封面。
- 复现：使用 scripts.test_youtube_auto_service.WorkflowCase 创建并生成封面，将预约改成过去，第一次 _mark_schedule_missed 固定为 10:00；10:05 再 approve；比较 _failure_event_fields 的事件键。
- 实测：同一预约 before_notice_time=2026-09-11T10:00:00Z，after_notice_time=2026-09-11T10:05:00Z，duplicate_event=true。
- 根因：review() 清空 body.error 后才调用 _mark_schedule_missed，抹掉用于可靠去重的 missed_at。
- 修复要求：同一预约跨审核动作保留初次 missed_at，只在明确重新安排后重置；增加固定时钟回归断言两个 event_key 相同。
- 文件：features/youtube_auto_publish/service.py、相关 service/通知回归。
- 修复：review() 在同一预约仍然到期时直接保留旧 error 调用 _mark_schedule_missed；只有非过期路径清空 error。
- 验证：`python scripts/test_youtube_schedule_service.py` 14/14 通过，新增 `test_missed_review_keeps_the_original_notice_event` 固定 10:00/10:05 两个时刻，断言审核前后同一 event_key、初次 missed_at 不变，且没有入队上传。
- 状态：已修复并通过回归。
