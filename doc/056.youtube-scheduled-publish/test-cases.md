# 测试用例

## 测试范围

新建发布可选时间、审核/入队延迟、原生预约状态机、修改/取消竞争、首评栅栏、异常提醒与页面状态。全部自动化使用临时 SQLite、固定时钟及假平台；不得创建测试生产任务、视频、首评或飞书消息。

## 测试数据

- 时间 T0 固定；合法预约 T0+1h，过去 T0-1m，边界 T0 及平台安全窗口内时间。
- 原视频 V、频道 C、封面版本 V1/SHA 固定；平台 private / processing / public、预约不同值、items=[]、请求超时均可注入。
- 同租户所有者 A、另一用户 B、同租户管理员、其他租户；两个请求使用相同或过期 revision。
