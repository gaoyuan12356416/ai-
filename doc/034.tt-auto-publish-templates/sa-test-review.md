# SA 测试用例评审

## 结论

测试设计评审通过。当前 108 个新系统测试与 64 个旧 TT 回归已全部通过，覆盖高风险身份映射、完整日指标、两层排序、永久冻结、并发竞态和 TikTok unknown outcome；桌面端与移动端浏览器无发布验收已完成，部署关闭默认验收仍待明确授权后执行。

## 必须保留的回归门禁

- 黑名单 type=0/type=1 使用同一文本值时不得跨类型误杀。
- spend=0 的 ROAS 在升序和降序均位于末尾。
- 预览不得写 ledger；正式选择最终复核后才冻结。
- 终态失败不得释放素材。
- 旧 TT 页面、模块和 API 契约无差异。
- 没有精确 canary 授权时，任何测试均不得调用真实 publish。
- 自动调度必须在事务内复核 `enabled_at_utc`、当前版本和启用状态，陈旧快照不得建 run。
- 手动执行相同幂等键必须返回同一 run，网络未知时前端不得生成新键。
- 浏览器 API 不得暴露源素材 URL、准备后 URL或黑名单值明细。
