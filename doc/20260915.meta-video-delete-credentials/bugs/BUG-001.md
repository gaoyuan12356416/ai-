# BUG-001 Video只选择首个UserToken，未适配Page身份

状态：代码修复、回归及生产只读验收完成，b0d5790已上线。Meta实际删除结果仍待操作人触发后确认。

现象：源Video请求收到Meta200/HTTP403 publish_actions废弃错误；同时已有匹配广告Page的当前授权。原Graph.video_credential只按内部user_ids取首个UserToken，没有Page解析或元数据区分。

修复范围：Graph/SqlSource/Bridge动态选择精确Page或候选上传User；Service/Store预写身份审计；页面显示安全诊断。仅凭Creative关联不能证明真实上传者，不改目标ID、不恢复Video读取门禁、不自动换Token重写。

验证：模块回归、独立凭证测试、PageToken真实GET-only probe。实际DELETE是否通过取决于Meta响应，本次不使用真实删除作为测试。
