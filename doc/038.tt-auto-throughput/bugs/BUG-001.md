# BUG-001 无效长视频制作与发布调度饥饿

## 现象

自动发布任务长时间停在 pending/preparing；已 ready 的任务仍需等待长转码结束。部分长视频制作完成后才因账号时长上限失败。

## 根因

1. 账号最长视频限制只在发布前读取。
2. 4 个 runner worker 同步等待 GPU prepare，没有发布保留槽。
3. 自动运行到发布时间才创建，制作耗时全部计入发布延迟。
4. GPU 缺少阶段计时，无法区分下载、GPU 排队、转码和上传。

## 修复

- Creator Info 前移到选择前并收紧素材时长规则。
- 自动任务提前制作，ready 发布仍受原时间闸门约束。
- runner 拆分 3 制作 + 1 发布/对账 lane。
- GPU manifest 和任务事件写入阶段耗时。

## 验证

141 项核心测试及 82 项复合契约测试通过；生产自然任务验证待部署后完成。
