# 频道画像与发布共用标签语义

`features/x_tag_revenue/tag_dictionary.json` 是唯一字典源，当前版本 `x-drama-tags-20261109-v1`。
包含 233 个标准 ID、简体中文显示名称与多语言别名；其中 232 个已确认，1 个含义待核对。
另有 2 个歧义标签独立保留。运行时不翻译、不模糊合并，也不按跨语言剧目的标签位置推断含义。

同一剧目先将别名转换成标准 ID，再去重并平均分摊收入。不同剧语言的来源匹配和频道语言要求不变。
历史画像必须从剧目及收入重新计算，不能对旧标签汇总金额简单改名相加。
频道列表、详情、模板预览、运行记录和发布日志均使用统一中文名称。
任务冻结时保存画像和映射版本；后续显示翻译不重选任务、不覆盖原始审计或回执。

韩语 `판타지`、德语 `Fantasie` 在资料中同时对应 Fantasy 与 Fantasy World，分别显示“奇幻（韩语歧义待核对）”“奇幻（德语歧义待核对）”。
`Male-priented Reverse` 显示“男性向反转（待核对）”。这些收入仍完整保留，但不用于偏好权重。
未来未知标签按原文归一化后的摘要生成稳定 ID，显示“待映射标签（编号…）”，同样仅跳过该标签的偏好匹配。
有可用标签则继续按其权重分配；全部不可用则沿用合格候选排序并记录降级原因。

后续新增别名需核实语义，更新版本并完整重算画像。不能把复仇/逆袭、公主/王妃、一见钟情/命定伴侣等不同概念合并。
同 series_code 不同语言的标签位置只可用于发现候选别名，不能作为自动确认依据。

## 验证与升级

同一真实只读样本：103 个历史频道、1,088 个原始标签写法，6,302,834 美分。
新旧算法逐频道总收入完全一致；每个频道及标签下钻金额守恒。样本覆盖 235 个标准或待核对标签。
此数字是验证快照，不是固定业务常量。

从 GitHub 拉取 clean 精确提交后：

```sh
python3 -B scripts/deploy_x_tag_semantics.py install
```

先构建独立运行版本、运行 17 + 27 项测试、从完整来源重算临时画像，再备份与原子切换。
原画像刷新锁仅覆盖切换阶段。只短暂停新发布流程的触发器，并等待其已开始的调度完成；有发布在途时保留执行且返回可观察原因。
仅重新加载新流程三个服务及画像 API，不重启原发布或主 API，不创建业务配置或任务。
指标采集不受影响。备份、旧画像和精确版本位于 `/mnt/data-disk/x-channel-tag-revenue/semantic-backups/<UTC>/`。

回滚同一次升级：

```sh
python3 -B scripts/deploy_x_tag_semantics.py rollback --backup /mnt/data-disk/x-channel-tag-revenue/semantic-backups/<UTC>
```

恢复上一个运行链接、代码、静态文件及画像，保留全部业务数据库、有效占用、凭据、发布回执和短链。
这只撤销标签语义升级；新发布功能整体回滚见 `20261109.x-tag-profile-publishing.md`。
