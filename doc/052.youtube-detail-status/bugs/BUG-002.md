# BUG-002：静态发布遗漏共享运行时导致页面初始化中止

## 现象

进入 AI 后台后只显示页面外壳：左侧导航为空、顶部用户显示 `--`、产品和任务列表无数据。

## 根因

两份新 HTML 在初始化前加载 `/drama-job-runtime.js` 并调用 `DramaJobRuntime.install(...)`。首次生产发布只复制了 HTML，没有把同一提交内的共享运行时脚本发布到 Nginx 静态目录，请求返回 404，随后顶层 JavaScript 抛出 `DramaJobRuntime is not defined`，所以数据接口尚未发起页面就已停止。

## 修复

1. 从精确提交 `7ac4b55a402c90a590610505d2280f5aec6c6afc` 的发布目录原子补发 `drama-job-runtime.js`。
2. 校验服务静态目录、Nginx 静态目录和公网响应 SHA-256 完全一致。
3. 将共享运行时加入 `deploy/live_feature_guard.json` 的候选文件及公网文件检查。
4. 增加回归测试，确保部署守卫不会再次漏掉该依赖。

## 生产结果

- `/drama-job-runtime.js?v=20260828-async-v1`：HTTP 200，`Content-Type: application/javascript`。
- SHA-256：`b2723e89478e30159800799cc186b0fb406828bff18df6ac342a6787e88cbf99`。
- API 和 YouTube Worker 保持 `active`，没有重启、没有测试发布、没有重放未知状态发布。

## 状态

已关闭。
