# 验证矩阵
1. 双机同条竞争唯一领取，同账号互斥，不同账号并发；渠道/批次公平。
2. 制作下一条与发布上一条重叠；主机池全渠道共享。
3. 制作失联复用身份；写入后失联待核对；重复/迟到回执只计一次。
4. 错误绑定、变更请求SHA、重复意图不发凭据；长期凭据不落节点。
5. 原始/修复/成片指纹、随机配方、profile、COS参数一致，另一节点仅下载发布。
6. 单条祖先豁免延续；历史暂停不占账号与排序，素材去重保留。
7. 审核、语言、剧集、预约、转发、首评不被绕过。
8. 自动增减、管理员缩容不终止在途；第三节点动态登记和接单。
9. 管理员/普通用户范围、默认入口/深链、唯一成功数、延迟/未记录提示，桌面/移动。
10. 线上四渠道、双机分别实际制作发布及正常到期回执；不创建测试帖。
