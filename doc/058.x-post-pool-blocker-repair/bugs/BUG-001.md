# BUG-001 配置中异常账号拖住整个素材批次

根因：plan gate扫描configured全部账号，且publish fence再次扩大到configured；历史unknown被包装成当前plan unknown，掩盖原始原因。锁定账号的profile verify仍成功。
修复：配置/可用/实际范围分开；首轮隔离两种明确账号阻塞、事务重验targets/最终relay、实际冻结queue范围fence、已知计划错误携带write-outcome字段。冻结历史和unknown不改。
