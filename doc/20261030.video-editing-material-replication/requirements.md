# 剪辑成片素材复刻：需求与设计

日期：2026-10-30。基线：`120f03167f7fe76531baf6617a7e4f905e7d73be`。

## 背景与目标

剪辑工作台已支持成片制作和逐条上传 A 组素材库，外部制作入口仍为占位提示。生产联调已验证 B 组素材复刻接口。本需求将用户确认的 `video-editing-replica-preview-v2` 交互接入正式工作台，提供受理回执和持久历史。

## 已确认范围

- 保留工作台、免费集、素材库、制作任务四栏目和原剪辑、上传、入库流程。
- 仅已完成且入库成功、具有正式 A 组素材 ID 的单条成片可提交“素材复刻”。
- 复刻类型：多语种 `1`、竞品 `3`、爆款反转 `4`；默认多语种。
- 配音：无配音 `0`、人工 `1`、AI `2`；默认无配音。成品形态：非解说 `1`、解说 `2`；默认非解说。
- 解说必须填写开始与结束时间，结束不得超过母素材时长；支持毫秒。非解说不提交旧区间。
- `no_bgm` 表示母素材没有背景音乐，默认不勾选；不表示移除背景音乐。
- 目标语种默认空，每次主动选择，可多选，允许母素材原语种。
- 源语种来自已入库素材的冻结信息，不由英文剧名推断。
- 默认归属为素材创建人对应盈量账号，普通成员只读、管理员可改。无唯一映射时明确阻断并由管理员指定，不能猜当前操作者姓名。
- 首版仅提交回执和历史，不查询成品制作或回推进度；受理成功不显示“成品完成”。
- 不批量、不自动复刻、不扩展 GPU 渲染、不停原渲染或入库 worker。

## 状态、幂等与权限

提交先写本地复刻账本，由独立 worker 调用 B 组。前端不能直连 B 组或取得固定 token。冻结母素材身份、实际操作者、成品归属、完整参数、申请/有效/unsupported 语种及 B 组回执。

连续点击、刷新和响应丢失不得重复生产。分别判断 HTTP 和业务码；duplicate 引用既有任务，部分受理保留真实语种集合。网络超时、发送中崩溃、无法确定的响应进入待核实，不自动重新 POST。明确拒绝允许用户修正后发起新操作。

沿用模块、同源 JSON、任务对象权限：普通成员仅本人任务，管理员全量。改成品归属不改变原项目或任务 owner。后端再次校验权限和参数。

## 数据与读取

新增 `ve_material_replication` 账本及所需元信息，迁移仅增量建表/索引，不改写旧任务、输出、素材入库记录。列表轮询只读 SQLite 摘要；打开单条 GET 加载上下文和历史，避免 3 秒轮询访问外部目录。

## 发布与回滚边界

本地验证后推送 GitHub，CPU 从独立干净 checkout 部署确切 SHA。备份在已验证挂载的 `/mnt/data-disk/video-editing/backups`，使用 SQLite backup API，并在副本演练迁移。先关闭新功能，导入已知历史并验证复用，再显式开放。

只重启主 API 和新复刻 worker，原 worker ActiveState/MainPID 保持。token 仅新 worker 读取已有私密 env，不进 Git、前端、日志或 manifest。回滚先关新入口、停新 worker，再恢复旧文件；所有 SQLite 业务记录保留。

## 验收

参数和权限正确、同操作不重复发送、未知结果不自动重试、回执历史刷新保留、原流程无回归、390px 布局可用；部署与回滚有实测证据。历史导入和复用验证不发起新生产请求。
