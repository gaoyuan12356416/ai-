# 测试用例

| 编号 | 场景 | 预期 |
|---|---|---|
| UI-01 | 制作中、完成未入库、入库成功 | 仅最后一种可提交，其他状态说明原因 |
| UI-02 | 打开/关闭/切换不同成片 | 上下文正确，目标默认空且可选源语种，旧异步响应不串单 |
| UI-03 | 三类型、三配音、两形态、no_bgm | 参数独立正确，切换非解说不提交旧区间 |
| UI-04 | 解说空值/格式/起止相等/超时长/毫秒 | 非法阻断，合法边界准确 |
| UI-05 | 普通成员/管理员/伪造 operator | 前后端权限一致，普通成员不能改归属 |
| UI-06 | 连点/关闭重开/刷新/丢响应 | 不重复生产，历史持久，未知结果不自动重试 |
| UI-07 | queued/waiting_download/duplicate/unsupported/失败 | 精确展示回执，不假称成品或回推完成 |
| UI-08 | 390px、键盘、长内容 | 无横向溢出、提交可达、焦点和错误可理解 |
| API-01 | 未登录/无模块/跨用户/非同源 | 拒绝且不泄露上下文历史 |
| API-02 | 缺素材 ID/语言/时长/映射歧义 | 提交前阻断，无外部请求 |
| API-03 | 越界/重复语种/非枚举/伪造母素材字段 | 规范化或明确拒绝，服务端决定母素材 |
| API-04 | 同操作重放/修改输入/新操作 | 幂等一致，不覆盖冻结历史 |
| API-05 | HTTP/业务失败/坏 JSON/超时/发送后崩溃 | 已知拒绝和未知结果分类正确，不盲目重发 |
| API-06 | 导入样例后复用 | 无额外外部请求，归属及既有回执保持 |
| API-07 | 任务列表轮询 | 仅 SQLite 摘要，不逐条访问外部目录 |
| DEP-01 | 非预期仓库/未推送 SHA/脏 checkout | 变更前拒绝 |
| DEP-02 | 磁盘 UUID/空间/文件漂移/私密 env 权限异常 | 变更前拒绝，不输出 secret |
| DEP-03 | 并发写期间 SQLite 备份/副本迁移 | 完整性通过，旧账本不被迁移改写 |
| DEP-04 | 安装成功 | 新功能仍关闭，只重启主 API/新 worker，旧 PID 不变 |
| DEP-05 | 中途失败/回滚/备份损坏 | 有效备份精确恢复，坏备份先拒绝，新账本保留 |
| DEP-06 | 导入复用验证后开放 | 可追溯地移除新 marker，无自动生产测试 |
| REG-01 | 原剪辑/预览/下载/入库/资源版本 | 原功能和权限无回归 |

以上为计划，执行结果见 test-report.md。
