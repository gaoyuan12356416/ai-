# BUG-001：复刻出站鉴权头与已验证协议不一致

严重度：P1。发现者：主代理。日期：2026-10-30。状态：本地代码已修复并读回复核，未为修复重新发送生产请求。

## 原因

初版独立 worker 使用 Authorization: Bearer，但真实成功联调所用的是自定义 token 请求头。这会使正式提交鉴权失败。

## 修复

features/video_editing/material_replication.py 的注入 HTTP 客户端及 requests.Session 两条分支均改为 headers={'token': token}。token 仍仅由新 worker 从私密 env 读取；API/前端不读取，不打印。

## 验证

独立代码审查核对两条分支均为 token 请求头；后端测试已加入真实协议请求头断言，最终执行统计由主代理/后端代理补充。api-doc.md 和 deploy.md 已同步明确该协议。
