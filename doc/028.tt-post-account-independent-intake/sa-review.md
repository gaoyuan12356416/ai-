# SA 需求评审

## 结论

通过。实现必须把“素材可入池”和“账号可立即发布”拆开，同时保留最终发布前实时门禁。

## 决策记录

| 编号 | 决策 | 结论 |
| --- | --- | --- |
| SA-01 | 是否改库以支持无账号素材 | 不改库；服务端稳定分配到已保存账号 |
| SA-02 | 配置保存是否调用 Creator Info | 不调用；仅可信账号快照、本地设置、canary 锁 |
| SA-03 | 预制作是否按账号最大时长阻断 | 不阻断；最大时长延迟到真正发布前复核 |
| SA-04 | 立即测试是否去账号校验 | 不去除，保持现有显式账号和实时门禁 |
| SA-05 | 旧客户端兼容 | 保留显式 `source_account_id` 路径 |

## 风险控制

- 配置版本必须匹配，账号列表不能为空。
- 分配算法必须稳定、可测试、不可使用 Python 进程随机 hash。
- 最终自动发布路径的 Creator Info 与时长检查不得改动。
- 生产验收只读，不用真实发布验证。

## PM 修订确认

需求无需扩大为“无账号配置也可入池”；自动发布仍要求至少保存一个目标账号。
