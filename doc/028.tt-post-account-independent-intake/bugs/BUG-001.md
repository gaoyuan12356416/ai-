# BUG-001 素材入池误绑定账号能力校验

## 现象

素材校验已通过，但页面仍要求选账号；配置保存和后台预制作还会调用 Creator Info。账号能力接口短暂失败时，素材无法进入等待队列。

## 根因

入池、预制作和发布执行复用了过强的账号实时能力门禁，没有按阶段拆分。

## 修复

- 配置保存只校验可信账号和本地设置。
- 入池由服务端在已保存账号中稳定分配。
- 预制作只处理素材；账号能力延迟到真正发布前检查。
- 立即测试和最终发布门禁保持不变。

## 状态

已修复；本地 344/344 Python 测试及 53/53 Node 断言通过，待生产部署与只读验收。
