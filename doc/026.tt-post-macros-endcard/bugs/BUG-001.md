# BUG-001 `{desc}` 在 intake 后未确定性贯穿 pool/queue

## 基本信息

- 严重级别：P0
- 发现日期：2026-08-03
- 发现阶段：`{desc}` 需求/代码路径评审
- 当前状态：已修复并完成生产迁移验收
- 外部影响：本轮未创建真实 TikTok Post

## 现象

素材解析器已经能从素材对应的 `ads_drama_resource.desc` 暴露 `description`，material intake 路径也能承载或参与请求身份，但基线的 recurring pool 和 queue 没有完整、可审计的 description 冻结字段与复制链路。

因此如果直接支持 `{desc}`，可能出现以下任一结果：

- intake 预览正确，异步 prepare 完成进入 pool 后 description 丢失；
- queue 只能重新查源库或依赖客户端传值，导致入池后 desc 漂移；
- 重试/幂等回放使用不同 description；
- 最终 caption 留下字面量 `{desc}`、为空，或与 UI 预览不一致。

## 复现步骤

仅在隔离数据库/单元测试复现：

1. 准备一条唯一映射的素材，`ads_drama_resource.desc = "description-v1"`。
2. 以包含 `{desc}` 的 caption template 创建 material intake。
3. 完成异步制作，使其进入 recurring pool。
4. 创建隔离 queue，读取 intake、pool、queue 的 description 与 caption。
5. 将测试源库 desc 改为 `description-v2`，再执行重试/幂等回放。

基线缺陷可表现为 pool/queue 没有 v1，或需要重新查到 v2 才能渲染。复现不得触发生产 runner 或真实 publish。

## 期望结果

- `description-v1` 由后端在 intake 创建时清洗并冻结。
- pool 只从 intake 复制 v1；queue 只从 pool/intake 复制 v1。
- 源库变为 v2 后，已有 intake/pool/queue 及 final caption 仍为 v1。
- 客户端 description 字段被拒绝。
- 模板单次渲染；final caption 为空或 >2200 UTF-16 时 fail closed，不截断、不消费素材。

## 实际结果

基线缺少上述完整贯穿合同，无法保证 `{desc}` 的确定性、幂等性和历史可追溯性。因此在修复前必须阻塞 `{desc}` 正式发布。

## 根因分析

1. 既有 caption 只围绕 Drama ID 和 rendered caption 设计，description 不是 pool/queue 的一级冻结事实。
2. 异步 intake completion、recurring run、legacy queue-create 是三条不同路径，新增字段没有统一从 schema、store signature、service call 到幂等比较全链路传递。
3. URL 宏分支增加了 material/drama/language/tag 和 short-link 字段，但 description 没有同步纳入 recurring pool/queue。
4. 如果在 queue 阶段临时查询源库，会破坏入池时冻结与重试可重复性；如果信任 UI，则形成事实数据注入。

## 修复说明

- `render_caption_template` 支持精确 `{desc}`，清洗 authoritative description，单次非递归替换并统一 UTF-16 计数。
- `tt_post_material_intake`、`tt_post_recurring_pool`、`tt_post_queue` 使用 `description TEXT NOT NULL DEFAULT ''` 的 additive migration。
- 入池时后端 resolver 重新获取 `ads_drama_resource.desc`；请求体不允许 description。
- intake completion、recurring execution 和兼容 queue-create 均显式传递 frozen description。
- 幂等比较加入 description；同 key 不同值返回 409。
- 历史已发布 queue 不回写；available 老记录模板含 `{desc}` 而 description 为空时阻断，待回填重算或重新入池。
