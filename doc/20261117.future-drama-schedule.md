# X / FB 模板上线时间范围与未来剧排期

适用于当前导航的 X 标签画像自动发布模板和 FB 自动发布模板。

- `0` 保持不限已上线天数，`7` 保持近 7 天；原有整数配置无需迁移。
- 新增包含边界的整数范围 `下限~上限`，值表示「当前时间减可投放时间」的天数，每天按 24 小时计算。`-1~0` 选择现在至未来 24 小时内可投放的剧；`-2~-1` 选择未来 24–48 小时，`0~7` 选择过去 7 天。
- 支持输入 `【-1~0】` / `[-1~0]`，保存为 `-1~0`。范围端点为 -3650 至 3650，反向、空白和非法范围返回参数错误。
- 普通模板选中的未来剧按其有效 `deploy_time` 冻结发布时间，提前量为 0；制作可以提前，发布必须等到冻结时间。X 沿用已有的来源任务/队列身份校验和发布前时间门禁；FB 沿用按任务时间领取发布的原子条件。
- 新任务保存时间策略 `template_release_time_v1`。原配置、历史任务、原有显式爆款发布策略和发布回执不回写。普通素材/语言/画像/指标/冷却/防重条件继续生效。

变更集中在共享范围解析、两个模板编辑器与验证器、候选查询、任务时间冻结和 X 后续素材校验。当前 X 入口由 `quick-nav.js` 指向 `/x-tag-auto-publish-templates.html`；已经退役的旧 X 页面与旧发布链路不恢复。

## 验证

本地运行 Python 语法检查、`node --check`、`node scripts/test_drama_launch_range_ui.js`，后者执行实际 X/FB 编辑器的请求构造函数。服务器在当前完整运行时的隔离副本运行：

```sh
python3 -B scripts/test_drama_launch_range.py --platform fb
python3 -B scripts/test_drama_launch_range.py --platform x
```

覆盖范围边界、旧整数含义、未来素材筛选、指标/防重保留、SQLite 真实任务时间冻结、发布前禁止领取和到点放行。所有平台写操作使用离线夹具；不发送真实测试帖。

本地分支不含所有线上复合模块，旧测试夹具也有与当前账号冷却接口不一致的问题；完整行为验收以当前运行时的隔离副本为准，不据本地导入失败调整线上业务规则。

## 部署与回滚

先提交 GitHub，CPU `43.166.187.96` 拉取精确提交，再运行 `scripts/deploy_drama_launch_range.py prepare|apply|verify --folder <部署目录>`。安装器核对当前文件基线，仅覆盖受影响文件，备份 SQLite 和代码，并记录此前调度状态。FB HTTP owner 排空后重启，X Auto owner 正常排空重启；保留原生 GPU/上传/发布工作进程。受影响的 FB/X 调度器按部署前状态恢复。

回滚命令为同一源目录运行 `python3 -B scripts/deploy_drama_launch_range.py rollback --folder <部署目录>`，随后 `verify`。只回滚本次代码与静态文件，不恢复旧 SQLite、凭据或回执。已有带范围的模板需要恢复兼容整数后才可由旧代码创建新任务；已冻结的未来任务和发布时间保持原状。
