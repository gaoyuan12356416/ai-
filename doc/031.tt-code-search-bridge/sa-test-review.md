## 评审要求

1. 满容量逻辑不得用生产 DB 造 1,679,616 条数据；实现需允许在测试中注入小 alphabet/length 或独立 allocator 模型。
2. B03/B05 的“不误触”不能只检查 CSS；必须派发真实 pointer/touch/mouse 序列并断言 resolver 调用数为 0。
3. G07 必须先植入与 SQLite 不一致的旧缓存，证明代码不会仅依赖 TTL 自愈。
4. H07 必须提供调用/ledger 基线，不能只以“未看到 Post”作为证据。
5. F13 的已发布 code 对应剧下架语义需要实现与 API 文档保持一致；当前需求默认沿用现有 fail-closed，无可验证剧则不显示 CTA。
