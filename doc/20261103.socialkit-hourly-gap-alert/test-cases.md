# 测试用例

| 场景 | 预期 |
|---|---|
| SocialKit 0 / 我方 0 | 不提醒 |
| SocialKit 1 分 / 我方 0 | 提醒 |
| 我方有正收入，退款抵消收入 | 不提醒；只按原始收入 |
| 同名异 ID、跨平台同 ID、HotDrama | 不混算，HotDrama 排除 |
| FB 双站点同剧 | 合并金额，保留各自来源校验 |
| 历史已发/从未成功/重复对象 | 分类与计数正确 |
| 查询失败/无日期/过期/冲突 | 不当成零，其他平台继续 |
| 同日重复、重启、状态变更 | 不重发已认领事件 |
| 同日新剧、次日同剧 | 可以新提醒 |
| 分卡中未知/失败 | 保存回执，不盲目重发，不影响新事件 |
| 预览/空候选 | 不发送；预览不认领 |
| UTC/北京时间边界/错过11点 | 窗口及补回算正确 |
| 刷新失败/提醒失败 | 前者保留旧报表；后者保留新报表 |
| 回滚遇后续改动 | 拒绝覆盖，数据/回执保留 |

真实源：固定成功版本，核对三平台日期/来源时间、候选金额和历史发布，首发回执及下一小时去重/新增行为。
