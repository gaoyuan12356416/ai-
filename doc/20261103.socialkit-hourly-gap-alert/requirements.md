# SocialKit 小时更新与收入差异提醒

## 已确认需求

报表每小时更新，保留现有所有产品/平台。独立提醒只比较 Dramawave（1479）的 Facebook、YouTube、X：同平台、同精确 content ID，SocialKit 当天原始收入大于零、我方 AI 后台自有社媒当天原始收入恰好等于零。美元整数分，不扣退款，不比较付费广告。

双方使用 UTC 统计日，北京时间 08:00 切日。每个群、统计日、产品、平台、剧目只提醒一次。全部历史可信成功发布零条标记“未查到成功发布”；有记录标记“已发布，今日未出收入”。未知、冲突、缺失或过期不当成零。HotDrama、TikTok、Instagram 不参与提醒，但保留原报表。

## 数据与调度

- 北京时间每小时整点，默认重算当前 UTC 日及前两日；每日 11:00 到期回算前 14 个完整 UTC 日加当前日，错过后下一轮补做，成功发布 manifest 才记录回算完成日期。
- 保留收入只读端口 63350、FIFO Gate、外部 SocialKit 只读源、既有三张中间表、完整核对和原子快照发布。
- 每轮成功后固定刚发布版本；我方冻结目录按平台独立比较。既有站点：YouTube 2284、X 2116、Facebook 2049+2310，FB 同时校验冻结 Page/material 来源。
- 新 release 携带与线上主 API 完全一致的已验证社媒归因模块；不覆盖共享 app.py、导航或发布服务。
