# BUG-002 未确认发布已有收入被误判为零

独立审查通过真实 build_report/restrict 测试复现：有冻结 X campaign 身份但发布结果未确认时，AI 后台范围过滤会暂时排除已入库正收入；只读最终报表会把缺失剧目行当成零，误发未发布提醒。

要求：在提醒采集层使用同次缓存的原始来源指标及精确冻结身份，检查被范围过滤排除的收入；可信正收入禁止零收入提醒，不确定身份/发布事实标记待核实。保留现有报表和发布业务语义，不修改源任务。

状态：已修复。真实 build_report/restrict 与缓存原始指标回归：正/负非零收入均待核实不提醒，真实零收入仍可提醒；FB 精确来源隔离测试通过，独立审查复验通过。
