# X Post report: profile lane and per-account plans

The independent report omitted the profile publisher and expanded each new
single-account automatic run to the template's entire account list. Read both
lanes, present profile sources separately, and use frozen `social_random_day`
targets for the new policy. Legacy whole-batch plans keep their previous scope.
Missing historical evidence stays unknown. Explicit cancellation remains a
policy skip, including when a former dispatch hold is still present.

Confirmed Posts deduplicate by Post ID across native logs and Auto bridges;
Reposts use source Post and target account. Queue IDs remain scoped to their
database. Prior-plan arrivals and estimated publishing costs include both
lanes. Missing profile ledgers produce an explicit unavailable result.
Backlog scans share the corrected target interpretation and namespace profile
plan identities. They do not create plans or import publisher stores.

Each account's random plan contract permits only distinct minute slots, at
least 60 minutes apart; equal minutes across different accounts remain separate
targets. The report does not regenerate random times from current settings.
