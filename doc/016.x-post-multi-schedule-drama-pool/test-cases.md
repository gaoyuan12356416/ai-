# 测试用例

## 测试范围

排期配置、原子认领、FIFO、短剧源表审计、文案、容量、失败状态机、权限、页面合同和旧 X 发布回归。

## 测试数据

- 临时 SQLite，账号 ID 2/3/4。
- 伪造只读 `ads_drama_resource` 行，包含重复 app 行、缺集、URL 冲突、空标签和多行描述。
- 发布时间覆盖普通分钟、相邻分钟和 23:59 跨午夜。
