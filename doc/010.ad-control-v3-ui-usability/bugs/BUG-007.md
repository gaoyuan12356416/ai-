# BUG-007 产品下拉被业务卡片和底部操作栏裁切

## 现象

编辑器第 1 步打开短剧产品下拉后，菜单只显示顶部少量内容；其余部分在业务范围卡片边界处被截断，并与底部 sticky 操作栏重叠。

## 根因

菜单使用绝对定位且高度最多 300px，但父级 `.section-card` 固定为 `overflow:hidden`。菜单自身的 `z-index:20` 无法越过父级裁切；底部 `.editor-footer` 又以 `z-index:9` 建立覆盖层。矮视口下即使释放父级 overflow，固定 300px 菜单也可能超出可视区。

## 修复

- 仅在菜单打开时为所属业务卡片添加 `has-open-menu`，提升层级并释放 overflow；关闭后恢复原卡片裁切。
- JS 根据触发器与当前视口的实际距离，自动选择向上或向下展开。
- 将可用高度写入 `--menu-available-height`，菜单主体在视口内滚动，不再伸出屏幕。
- resize 与任意滚动容器滚动时使用 `requestAnimationFrame` 合并重算。
