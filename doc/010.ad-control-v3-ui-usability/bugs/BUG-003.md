# BUG-003 短剧产品不完整

## 发现阶段

用户验收。

## 现象与根因

目录只有 15 个 `custom_source_insight.product` 报表枚举，无法选择具体 App/W2A 投放产品。

## 修复说明

按审核 FB App ID 索引等值读取 `ads_apps_setting`，Dramawave 当前 129 条；生成稳定 `app:/w2a:` selector，并保存具体 App/W2A 查询证据。原 15 条保留兼容。

## 验证

同步 dry-run/apply 均为 129，63350 回读 129 条唯一具体产品；`w2a:1723` 真实估算得到 9 个账户、98 个 Campaign。状态关闭。
