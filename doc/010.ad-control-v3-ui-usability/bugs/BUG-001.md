# BUG-001 优化师下拉不可搜索

## 发现阶段

生产浏览器验收。

## 现象

管理员只能在 394 条原生 select option 中滚动查找优化师。

## 复现步骤

新建规则组 -> 业务范围 -> 点击优化师。

## 期望结果

支持姓名、邮箱、ID 搜索。

## 实际结果

无搜索输入框。

## 根因分析

编辑器、列表和日志都直接拼接原生 select。

## 修复说明

统一为动态搜索单选，菜单关闭时不生成全部选项。

## 影响文件

`features/ad_control_v3/assets/app.js|app.css`

## 验证命令与结果

自动化合同通过；本地 394 名优化师中搜索 `qa-393` 为 1 条；生产按邮箱搜索优化师 717 也为 1 条。

## 回归结论

关闭。
