# BUG-001 OAuth callback日志与账号列表代理缺口

- 严重级别：P0
- 状态：已修复
- 发现阶段：代码评审

## 现象

初版 Nginx 片段只代理 `/api/x-accounts/` 子路径，精确列表 `/api/x-accounts` 会落到静态站点；callback 还会由默认 access log记录含 `code/state` 的完整请求。

## 修复

- 增加 `location = /api/x-accounts`。
- callback 精确 location设置 `access_log off`。
- sidecar `log_message` 只记录 HTTP method与 path。

## 回归

本地配置审查、日志单测和部署后公网路由检查。
