# BUG-002 Token刷新与重新授权并发一致性

- 严重级别：P1
- 状态：已修复
- 发现阶段：代码评审

## 现象

初版仅按数据库记录 ID锁住 verify，callback 未共用锁。并发刷新与重新授权可能使 Token文件和账号元数据来自不同请求。

## 修复

- callback 与 verify 统一按 `x_user_id` 使用进程内互斥锁。
- verify 获取锁后重新读取账号和 Token。
- callback 写 Token 后如 DB upsert失败，恢复部署前 Token文件。
- 新增 callback-vs-verify 与双 verify并发回归测试。
