# 测试用例

| 范围 | 验证行为 |
|---|---|
| 恢复 | 60 条旧排队记录不遮挡中断任务；新鲜租约不重复领取 |
| 观察 | 两个独立观察槽，第三条等待；同时退出；--once 仅一条 |
| 配置 | 观察并发仅 1/2，双观察需异步 GPU |
| 预取 | 默认等待渲染；显式开启后允许当前下载与队首预取重叠，总下载并发最多 8 |
| 互斥 | 不占制作名额；预取退出后同任务才开始制作 |
| 关停 | 预取未退出时实例锁不释放 |
| 异常 | 预取异常不失败/重试制作，不暴露 URL/Token |
| 文件 | 正式下载无需网络即可复用预取记录 |
| 预算 | 空间不足零网络；文件超限在正文前取消 |
| 页面 | 预取展示下载数量，状态仍排队 |
| 回归 | 远端恢复、HTTP、渲染互斥、下载续传、路由隔离、规格统一 |
| 生产 | 精确版本、健康、两个租约、原任务更新、下一任务预下载 |
