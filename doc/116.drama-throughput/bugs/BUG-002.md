# BUG-002 预下载中断后不再尝试

状态：本地回归通过，生产验收见 test-report.md。

线上初次预下载累计约 21 MB 后退回排队；旧实现吞掉异常，无法还原该次具体网络错误。代码存在单次 HTTP 尝试、每代仅预取一次，以及并行取消可能覆盖首个错误的问题。

修复：单文件采用 3 次有界传输尝试，读超时 30 秒；保留首个异常。只有 download_failed 允许等待 30/60 秒后重试预下载，每代总计最多 3 轮。容量、来源变更、校验失败及其他错误停止预取，由正式执行继续检查。私有记录和日志只保存白名单错误码；旧中断记录可以接回，任务 ID、generation 和制作状态不改变。

验证：新增 5 项覆盖 Range 续传、同组取消保留首错、退避后成功、持久次数上限和旧记录接回。合计 297 项离线回归通过。
