# X 素材发布取消产品限制

管理员输入的素材 ID 在入池、素材池排期和手动立即/定时发布时，不再因
`ads_custom_source.product` 不是 `Dramawave` 而被拒绝。产品为空同样不构成拒绝理由。
产品字段不参与素材身份：全局素材 ID 及既有去重键保持一致。

历史未绑定队列的 `material_product_mismatch` 可重新进入正常预检。扫描不会直接把
旧错误改成可用；只有完整预检成功后，在原有事务冻结队列时清除错误，或使用正式素材
复核流程更新当前校验结果。已绑定队列、已发布和结果不明的记录不因此获得重试资格。

素材媒体、时长、剧目映射、可投放时间、账号权限、语言、Premium 和去重校验继续生效。
未扩展自动模板的候选来源查询，也未改变短剧池、发布模板或归因链接。

## 验证

- 素材池和手动选择接受 Dramawave、其他产品、社媒专用产品及空产品，保持原顺序和素材身份。
- 其他产品的时长缺失、剧目映射冲突继续返回准确错误。
- 历史产品错误可被扫描，不能未经重新校验跳过 FIFO；成功冻结时清除错误，绑定后仍不能自动复用。
- 回归素材池、排期、手动、媒体复核和发布账本测试；测试使用临时数据库及模拟网络。

本地两组回归共 437 项：436 项通过，1 项现存 UI 合约断言失败。
失败项 `test_x_post_navigation_and_dom_link_allowlists` 仍要求页面包含旧的
`countFor({ availability: "deferred" })` 文本；该测试文件与页面均和部署基线完全一致，
本次未修改。新产品、重新校验、FIFO 和去重用例全部通过。
Python 编译、共享导航 JavaScript 语法及 `git diff --check` 通过。

## 部署与回滚

基于在线 X 版本 `5f1d88455fb22634d27898f6762f9b2cd3768f70`，先提交 GitHub，
服务器读取精确提交生成不可变版本。发布前备份 SQLite、两个运行目录受影响文件及
非敏感 Token 哈希/权限清单。主 API 的 selector 副本落后于 X 当前版本，本次一并与
已在线使用的选择器行为对齐，避免入池和排期判断不一致。

同步 `features/x_posts/selector.py` 和 `features/x_posts/service.py` 到主 API；
仅重启主 API 和 X sidecar，恢复原定时器状态。验证服务、文件哈希、目标素材当前校验、
队列/日志计数和 SQLite 完整性。部署不创建发布任务或调用 X Post/Repost。

回滚切回上述旧 X 版本，恢复备份中的主 API 两个模块，重启两个服务并恢复定时器。
保留当前 SQLite 和 Token，不恢复历史数据库、不删除队列或日志。
