# 随机模板同源视频叠层

用户于 2026-09-20 确认 60 秒试片效果，授权融合到随机模板并全局生效。

## 业务规则

Drama 后台（自动与手选资产）、TT 随机模板、FB Page 随机模板的新配方均自动追加同源视频层。使用模板处理前的同一源视频，同步播放、静音，保持宽高比铺满 720×1280 后放大 110%–150%，居中裁切，不旋转，以 2%–5% 不透明度放在所有模板层之上。每个任务随机一次并冻结；原视频唯一音轨继续保留。

旧的资产选择、主画面旋转/缩放、调色和投放编码规格不改变。无 source_overlay 字段的历史冻结配方保持原样，已完成素材不回填重做。direct_outro 路由不变。

## 数据与接口

配方新增可选 source_overlay={version:1,opacity_bp:200..500,scale_bp:11000..15000}。整数基点；字段完整且精确，拒绝布尔值、空值、未知键、越界。参数来源于任务身份与独立稳定标签，不消耗原来的随机序列。新字段参与配方/缓存内容哈希。

CPU 在任务创建时持久化；TT/FB 在渲染和上传之前持久化配方收据，重试校验源文件 SHA 和原资产集合。无法验证时停止，不能重新抽取。

## 验收

三个生产入口均支持新层；范围和随机稳定性测试通过；CPU、OpenCL、CUDA 顺序一致。真实 GPU 验证新旧配方和 60 秒素材，尺寸、帧率、时长、单音轨符合原媒体合同。GitHub 可追溯、备份、切换及回滚有记录，后台展示已冻结参数。
