# 接口补充

请求接口不新增必填项。现有随机模板创建自动生成 source_overlay；详情 random_template_recipe 返回冻结值，后台审计卡展示百分比。

```json
{"source_overlay":{"version":1,"opacity_bp":350,"scale_bp":13000}}
```

source_overlay 缺失合法且表示历史原效果；对象存在必须严格验证，拒绝部分字段或范围不符。Drama healthz 与 TT/FB health 返回 source_overlay_version=1 作为能力证据，媒体 profile 保持原值。
