# 测试用例

- 新配方参数上下界，确定性，多任务分布，旧的资产和几何选择不变。
- 旧配方无字段正常加载与渲染；损坏对象、布尔、未知键、空值全部拒绝。
- CPU/共享 OpenCL/Drama OpenCL/CUDA 均在 corners 后叠加未经模板处理的源；居中放大，无旋转、时间偏移或重复音轨。
- 缓存哈希随新参数变化；旧内核和旧冻结内容不变。
- 上传失败、重试、默认资产目录变化时复用原收据；源 SHA 不一致拒绝，清理保留收据。
- GPU 新旧真实视频可解码、720×1280/30 fps/单音轨，60 秒试片完整。
- 生产三路健康、CPU 冻结与 UI、隧道和原触发器恢复核对。
