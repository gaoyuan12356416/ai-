# BUG-002：用户管理无法单独授权 AI 自动调控 V3

## 现象

用户管理只显示旧版“AI自动规则调控”，没有“AI自动调控 V3”权限项，管理员无法只给某个普通用户开放 V3。

## 根因

旧版导航和 V3 导航共用 `ad_control_center`。用户管理按模块键去重，因此 V3 分组被旧版模块吞并；V3 页面和 API 也继续校验旧版权限，无法独立授权。

## 修复

- 新增可分配模块 `ad_control_v3`，普通用户默认关闭，管理员默认开启。
- V3 动态页面、受保护资产和 API 统一校验 `ad_control_v3`。
- V3 导航分组及两个页面使用 `ad_control_v3`；旧版继续使用 `ad_control_center`。
- 历史权限 JSON 没有 V3 键时，临时继承原 `ad_control_center` 值；管理员首次保存后以显式 V3 值为准。
- 用户管理继续合并后端模块枚举，即使导航配置暂时过期也仍能显示 V3 权限。

## 验收

1. 管理员进入用户管理，可同时看到“AI自动规则调控（旧版）”和“AI自动调控 V3”。
2. 普通用户只勾选 V3 后，可访问 V3 两个动态页面和 API，仍不能访问旧版调控。
3. 只勾选旧版且显式关闭 V3 后，V3 返回 403。
4. 历史上已拥有旧版权限、尚未保存 V3 独立值的用户保持原 V3 访问，不发生突发权限回收。

## 回滚

恢复 `app.py`、`features/ad_control_v3/routes.py` 和线上 `navigation.json` 的发布前备份。数据库不需要回滚；若已有用户权限 JSON 保存了 `ad_control_v3`，旧版本会忽略该未知键。
