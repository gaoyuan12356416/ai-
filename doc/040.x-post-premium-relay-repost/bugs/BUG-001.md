# BUG-001 原帖成功后 Repost 未知不得重发

## 现象与根因

开发评审发现：若沿用旧的单阶段 `published` 语义，Repost 失败后重跑会再次上传并创建原帖，或原帖成功时过早推进短剧。

## 修复

新增独立 `x_post_repost_ledger` 和 `source_published -> reposting -> reposted` 状态；`source_published` 后发布入口只允许目标 Repost。未知结果落为 `needs_review`，不允许自动重试。

## 验证

`test_sidecar_unknown_repost_never_republishes_source` 断言原帖调用 1 次、Repost 调用 1 次，第二次执行直接被 unknown 栅栏阻止。专项及全量 X 回归通过。
