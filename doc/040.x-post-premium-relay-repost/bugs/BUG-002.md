# BUG-002 原帖已确认但本地提交失败时必须同步中转账本

## 现象与风险

代码评审发现，原 Post 已返回 ID、最终本地提交失败的故障分支最初只把发布日志标记为未知；中转账本更新片段还误落在“发布前失败”方法中并引用不存在的变量。故障注入时可能产生二次异常以及日志/中转账本状态不一致。

## 修复

把 `source_post_id/source_post_url` 与 `needs_review + unknown_outcome=1` 写入放回 `mark_post_commit_unknown` 的同一 SQLite 事务；“发布前失败”仅写入明确失败，且保持 `source_attempt_count=0`、原帖 ID 为空。

## 验证

- `test_confirmed_source_with_lost_ledger_commit_is_fenced`：原帖证据被持久化，双账本均进入未知栅栏。
- `test_relay_pre_x_failure_updates_both_ledgers`：发布前失败无未定义变量、无伪造原帖证据。
- 专项与全量 X 回归通过。
