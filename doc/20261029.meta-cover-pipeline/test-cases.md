# 测试用例

以事件同步、伪 Graph/SQL 和临时 SQLite 验证，不调用真实 Meta 写接口。

| ID | 场景 | 预期 |
|---|---|---|
| PIPE-01 | 阻塞清理，执行至少两个广告周期 | 第二周期在清理结束前完成；仅一个清理循环 |
| PIPE-02 | 账户 A 一条慢任务，B/C 有待执行任务 | 完成即补位，A 不超账户上限，无整波屏障 |
| PIPE-03 | 广告/清理共同争用请求 slot | 同一个 Governor 保持总 32、账户 2、24 req/s |
| PIPE-04 | 记录 SQL 准备线程，广告网络同时执行 | SQL 不进入网络 worker、不跨线程复用 session |
| PIPE-05 | 查询慢/账户拥塞/时钟超过 TTL | 过期上下文重取或暂缓，不发送创建/绑定 |
| PIPE-06 | 来源身份、凭据归属、封面在准备间变化 | 新快照发现变化，不跨周期复用旧身份 |
| PIPE-07 | 广告预约旧 Creative，清理同时尝试删除 | 共享预约拦截 DELETE，无关任务可继续 |
| PIPE-08 | 引用缺页、仍被引用、删前快照过期 | 不发送 DELETE，保留原因和下次检查时间 |
| PIPE-09 | 未知创建/绑定/删除及已消费删除意图 | 不重发写请求，仅只读核实；失败不自动重试 |
| PIPE-10 | 工作中停止或 legacy priority handoff | 停止提交，两循环排空落账后释放 lease |
| PIPE-11 | 清理活跃时进入下一广告周期 | 不执行全量 inflight/reservation 回收 |
| PIPE-12 | 清理局部错误/账本错误/广告异常 | 明确隔离范围，无孤儿线程，不丢 unknown |
| PIPE-13 | 新旧日志混合，两个 lane 时间重叠 | 分母不重复累计，旧记录和空闲排除兼容 |
| PIPE-14 | 失败/过期/停止发生且有在途 future | 已提交任务落账一次，未开始保持 pending |
| PIPE-15 | 恢复与线程启动顺序 | 恢复先于并发；Runtime/SQL连接归属正确 |
| PIPE-16 | 现有全模块回归 | 一次删除、参数验证、审核等待、报表窗口不退化 |

生产仅观察既有授权队列，不通过复位历史失败/未知制造样本。
补充：PIPE-02/04 增加错峰完成且候选超过首次buffer的测试，验证正常满负载下消费已有buffer而非每完成一条就查询一条。PIPE-07增加同Creative本地未完成任务过滤、未知只读确认后自然eligible、其他账户和废扫描行不阻挡。
