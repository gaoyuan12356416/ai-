# 测试用例

## 测试范围

覆盖源码 GET、HTML 提取、精确 ID 校验、SQLite 持久缓存、并发租约、公开 API 兼容、最近 3 日预热、featured LKG 和部署回滚。

## 测试数据

- 有效样本：`Ag0rfr5F0F`，预期标题 `Her Beast`。
- 错误样本：合法格式但 W2A 回退到其他剧的 ID。
- HTML 样本：正常、缺深链、重复深链、缺标题、描述元素缺失、描述元素为空、缺封面、超大、恶意 URL 和非 UTF-8 声明。
- SQLite：临时数据盘目录、重启复用、WAL 并发、租约过期、锁等待，以及首次校验后的 parent `st_dev`/软链接/目录身份漂移。
- 投放候选：0、1、500、501、3000、5000、5001 个去重 ID，并包含花费顺序变化、cursor 目标消失和失败重试积压样本。
