# 测试用例

## 测试范围

覆盖 DDL、动态产品范围、两种数据层级、API 分批、金额精度、幂等写入、待结算回刷、局部失败、秘密脱敏、定时防重入和生产样本查询。

## 测试数据

- 固定 API 响应夹具：终态、`UNDER_PROTECTION`、`CONFIRMING`、多币种、零金额和错误响应。
- 固定产品映射：DramaWaveMinis `3346`、BestReelsMinis `3380`、MyShort `3416`，以及一个临时新增小程序映射。
- 生产验收日期：DramaWaveMinis `2026-09-02`。
- 测试夹具仅使用占位 Token 和虚构对象 ID，不复制生产秘密。

## 回归范围

- 使用新 Token 只读调用现有 Native Growth 报表接口，确认其权限和响应结构不回退。
- 现有 TT 小程序看板、播报 cron、锁和日志不修改。
- 新 cron 与现有 `:00/:05/:10/:13/:43` 任务不共用锁且不在高峰分钟启动。
