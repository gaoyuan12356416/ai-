# Packed-RGB NVENC changes output color signaling

Prototype output used BT.601 while baseline retained BT.709. Confirmed with ffprobe and official FFmpeg n7.1 libavcodec/nvenc.c, nvenc_setup_h264_config and nvenc_setup_hevc_config: RGB input explicitly sets colourMatrix=BT470BG. Output -colorspace does not override it.
