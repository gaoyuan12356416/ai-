# Design review
Self-review: driver/FFmpeg upgrade rejected as unnecessary rollout risk. Existing FFmpeg 7.1 supports OpenCL and NVENC; final output stays YUV420 because the packed-RGB encoder path changes color signaling. CUDA scale cannot convert YUV to RGB on this version. Custom OpenCL fitting preserves the existing compositor. CPU plane transfer and final output conversion remain; do not claim zero CPU. Resolution-change, color, timestamps and audio checks passed. Platform publication logic is unchanged; the worker lease guard was separately hardened for transient heartbeat reconfirmation, preserving rejection, expiry and unknown-result fences.
