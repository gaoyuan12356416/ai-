# BUG-001 手动发布失败原因显示为笼统英文

## 发现阶段

生产运营反馈，2026-08-14。

## 现象

#15/#16/#17 页面显示 `material_not_found_or_ineligible` 或
`repaired_media_invalid` 加英文文本，无法区分不存在、时长为0和文件超限。

## 复现步骤

打开素材池手动发布任务结果弹窗，读取失败任务的错误区域。

## 期望结果

只显示素材 ID 和简短中文具体原因。

## 实际结果

直接拼接后台错误码与英文原文。

## 根因分析

selector 在 SQL 中提前过滤多种条件，丢失具体分支；GPU 多个产物校验共用一个错误码和英文消息；前端无业务映射直接拼接字段。

## 修复说明

exact-ID 查询后逐项拆码；GPU 返回具体中文明细；manual runner 归一细码并附素材 ID；前端隐藏错误码并输出中文原因。

## 影响文件

见 `dev-plan.md`。

## 验证命令与结果

59 项针对性测试、410 项 X 全量命名回归、107 项核心附加回归均通过；生产零发帖验收通过。

## 回归结论

已关闭。生产自然 timer 连续返回 `no_pending`，queue/log 保持 253/243，unknown=0，未创建真实 X Post。
