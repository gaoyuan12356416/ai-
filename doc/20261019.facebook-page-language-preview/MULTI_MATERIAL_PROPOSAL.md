# 多素材与多 Page 对应建议（尚未实现）

推荐采用“剧语言自动匹配 + 可编辑对应清单”。最终提交对象是一条条明确的“素材 × Page”配对。

## 操作流程

1. 多选素材。每行清楚展示剧名、剧语言、素材名称/ID；同剧的不同片段仍是不同素材。
2. 多选目标 Page。范围仅限已配置 Page，显示剧语言及授权状态。选择 Page 只限定本批目标范围，不等于立即创建全部任务。
3. 点击“按剧语言匹配”。在选择范围内，为每条素材勾选所有同语言且可用的 Page；未知语言和异常授权不匹配，也不默认兜底到其他 Page。
4. 查看并调整对应清单。每行一个素材，后面列出已对应的 Page 标签，允许增加/取消同语言 Page。支持按语言、Page、未匹配筛选，显示总任务数和各 Page 待发条数。
5. 逐配对预览并确认。以目标 Page 的文案模板替换该素材的剧名、简介、短链；可只修改这个配对的本次文案。提交前确认最终配对数。

## 示例

选中三条素材和三个 Page：

| 素材 | 剧语言 | Page A 中文 | Page B 中文 | Page C 英语 |
| --- | --- | --- | --- | --- |
| 素材 1 | 中文 | 已匹配 | 已匹配 | 不匹配 |
| 素材 2 | 中文 | 已匹配 | 已匹配 | 不匹配 |
| 素材 3 | 英语 | 不匹配 | 不匹配 | 已匹配 |

默认共 5 条任务。若只想让“素材 1 → A，素材 2 → B”，取消另两个勾选即可，最终是 3 条任务。列表形式适合较多 Page；小规模时可切矩阵查看。手机使用“素材卡片 + Page 多选标签”。

## 任务与文案规则

- 每个配对冻结素材 ID、content_id、剧语言、Page ID、配置实例与模板版本、最终文案、任务 ID、短链和长链。一个素材发到两个 Page，也生成两条任务和两个独立短链。
- 同一批内重复的“素材 ID + Page ID”只保留一次。跨批历史重复给出提醒，让用户明确选择是否继续；不要把视频处理模板和发布重复检查混为一谈。
- 一个 Page 收到多条素材时，确认页按该 Page 汇总，支持调整发布顺序与间隔。失败、取消、重试按单个配对处理，不重发整个批次；真实集成时未知结果需先核对。
- 无匹配 Page 的素材明确标为“未分配”。用户可补充 Page 配置或主动从本批移除；确认前不静默丢弃。
- 所有保留配对都必须通过授权、剧语言、宏来源、文案长度校验。任务数量变化即时更新，确认页展示实际将生成的任务数。
- 归因仍为现有八项规则，落地页 2310；`af_c_id` 对应每个配对的独立任务 ID，`c` 使用该任务自己的记录创建时间和记录 ID。

首版建议先实现上述同语言全匹配与手工调整。若以后需要“均匀分配给多个同语言 Page”，再增加明确的分配模式，避免默认随机或按列表顺序猜测用户意图。
