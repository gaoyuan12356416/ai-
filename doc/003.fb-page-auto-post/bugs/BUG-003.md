# BUG-003 GPU 系统 Python 不支持候选语法

## 发现阶段

生产 GPU closed-gate 预启动检查。

## 现象

候选 unit 使用 `/usr/bin/python3`，导入 `features.fb_gpu.prepare_worker` 时提示 `future feature annotations is not defined`，服务在启动前安全失败。

## 根因分析

GPU 系统 Python 版本早于项目代码要求；现有 TT GPU 生产 worker 实际运行在 `/root/miniconda3/envs/drama-voice/bin/python`，该环境同时具备当前 Python 语法、`requests` 与 COS SDK。

## 修复说明

FB prepare-only GPU unit 固定使用已验证的 Conda Python，且部署契约测试锁定解释器路径，避免回退到系统 Python。

## 回归结论

本地部署契约通过；生产将以 Conda Python 重跑 import、asset manifest 与 COS client 预启动检查后才允许启动 unit。
