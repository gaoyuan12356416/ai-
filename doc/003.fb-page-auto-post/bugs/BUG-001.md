# BUG-001 SQLite 连接退出后未关闭

## 发现阶段

首次 focused unit test。

## 现象

业务断言通过，但 Windows 清理临时目录报 WinError 32，SQLite 文件仍被占用。

## 复现步骤

运行 `python -m unittest scripts.test_fb_auto_store -v`。

## 期望结果

每个 `with store.connect()` 退出时提交/回滚并关闭句柄。

## 实际结果

标准 sqlite connection context 只提交/回滚，不关闭连接。

## 根因分析

误把 `sqlite3.Connection.__exit__` 当成自动 close。

## 修复说明

增加 `_ClosingConnection`，父级 `__exit__` 后 finally close。

## 影响文件

`features/fb_auto_posts/core.py`。

## 验证命令与结果

`python -m unittest scripts.test_fb_auto_store -v`：3/3 通过，临时目录可删除。

## 回归结论

已关闭。
