# BUG-006 COS SDK 自定义元数据键缺少协议前缀

## 现象

2026-08-18 prepare-only 生产 canary 完成下载、NVENC 和 COS PUT 后返回 502；同一 job 重试发现内容寻址对象已存在，但 HEAD 缺少 `x-cos-meta-sha256/profile`，因此按 fail-closed 合同返回 `fb_gpu_cos_identity_conflict`。未创建 FB 任务或调用 Graph。

## 根因

当前 GPU 环境的腾讯云 COS Python SDK 会把 `Metadata` 字典中的键直接作为 HTTP header 发送。代码传入 `sha256/profile`，没有使用 `x-cos-meta-` 前缀，服务端未保存为用户元数据；测试 fake client 没有断言真实 header 语义。

## 修复

- PUT 改为 `Metadata={"x-cos-meta-sha256": ..., "x-cos-meta-profile": ...}`。
- 保持 HEAD 只接受 size 与 `x-cos-meta-sha256` 同时匹配；不放宽已存在对象身份门禁。
- 测试精确断言 SDK Metadata header 名。

## 验证

重新发布 GPU immutable release 后，用新的稳定 job 进行真实 NVENC/COS canary；验证 public-read HTTPS HEAD、`video/mp4`、size/hash 元数据、相同 job 复用及临时文件清理。结果记录在 `test-report.md`。
