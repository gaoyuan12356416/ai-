# BUG-001 立即测试错误绑定自动素材池

## 状态 / 严重级别

- 状态：已实现候选修复，待完整回归。
- 严重级别：P0。

## 现象与根因

旧页面调用 `/run-now`，服务端只收到账号并领取该账号自动池最早的 available 素材，无法表达“用刚校验的素材测试”，也会改变 FIFO/pool 状态。legacy pool/queue 的 material 唯一约束也不能承载同素材多次测试。

## 修复

- 新增独立 `tt_post_direct_test` 与 `POST /api/admin/tt-posts/test-publish`。
- 请求精确包含单目标账号、单素材、保存配置版本、幂等键和 consent；目标账号可不属于 auto-config，版本只冻结描述模板。
- 历史 published 素材可新测；同素材 active/unknown direct-test 或 legacy queue 阻断。direct 明确终态后不阻断原自动池未来正常消费。
- 每次任务生成新 `tttest-*` GPU job；不读写自动 pool/queue/run。
- `GET /direct-tests` 查询任务；没有管理端 detail/manual reconcile。
- 旧 `/run-now` 保留兼容，但新 UI 不再调用。

## 验证

- D01-D23、N07-N09。
- 必须证明非自动成员账号可测、历史 published 可再测、同素材活动阻断、pool 全字段 0 diff、每次新 GPU job。
