# BUG-002 自动发布配置不是原子多账号快照

## 状态 / 严重级别

- 状态：已实现候选修复，待完整回归。
- 严重级别：P0。

## 现象与根因

描述、自动开关/时间和账号选择分散，旧模型以逐账号 schedule 为核心，无法保证三部分属于同一版本，也无法直观看出成员。

## 修复

- 新增单例 `tt_post_auto_publish_config`，用一个 version 原子保存 `caption_template/enabled/publish_times/account_ids/consent`，并在同一事务同步 legacy schedule。
- POST 使用 `source_account_ids`，响应 item 使用 `account_ids`；当前只允许一个共同时间、最多 50 个账号。
- 账号项返回 `auto_publish_selected`、`auto_publish_state(active|paused|attention_required|not_selected)`、`auto_publish_config_version`。
- `enabled=false` 不要求/解析 accepted=true consent，保留已有 consent；启用时才实时校验全部成员。
- mixed legacy 首次必须保存关闭的统一配置，下一版本才可启用。
- 测试账号单选与自动成员多选独立；自动入池账号仍必须属于成员。

## 验证

C01-C22、M03-M07；重点断言版本冲突/末尾账号失败 0 部分写入和关闭 consent 特例。

## 回归结论
