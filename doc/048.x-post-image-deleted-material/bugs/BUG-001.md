# BUG-001 图片零时长归因被旧视频校验拒绝

单元测试 / SA 代码评审。

图片预检正确冻结 `preflight_duration=0`，但构造 W2A URL 时返回“视频时长无效”。

对合法图片执行 `_preflight_candidate`，进入 `build_w2a_url(video_duration_seconds=0)`。

图片沿用 `af_channel=short`，同时继续拒绝非零且小于 0.5 秒的异常视频。

旧 `_w2a_channel_for_duration` 拒绝所有小于 0.5 的值。

原模型只有视频，没有“无视频时长”的表达。

仅将精确 `0` 映射为 `short`；负数、非有限值、`0 < duration < 0.5` 仍拒绝。

`features/x_posts/service.py`、`scripts/test_x_posts.py`、`scripts/test_x_post_daily.py`。

`python scripts/test_x_posts.py`：43/43；`python scripts/test_x_post_daily.py`：62/62。

通过，140 秒边界、Premium 长视频和历史 `AIpost` 校验均保持原行为。
