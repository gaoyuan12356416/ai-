# Independent editor: narration and subtitle corrections

The supplied 30-second narration exposed robotic eSpeak speech, unlimited audio
compression, candidate-order scripts against reordered clips and simultaneous
original dialogue. New narration follows the final cut order, has explicit word
budgets, uses neural speech with measured word timings, caps fitting at 1.12x,
and mutes the source dialogue when adding voiceover. Automatic text can be
shortened once; errors remain visible and do not silently use robotic fallback.

Horizontal flip detects light outlined subtitle glyphs inside the selected
region, inpaints their mirrored positions, then restores the original glyph
pixels. It does not preserve an unflipped background strip. OCR samples the
selected clips to narrow detection; failed region detection uses 55–92%.
Operators can set boundaries manually or disable protection. Light conventional
hard captions are supported; colored/stylized captions need output review.
New ASS subtitles are applied after mirror. Historical outputs remain unchanged.


Narration and translation settings show a playable source preview with live
height, size, color, outline, alignment and bilingual examples. The height is
the bottom anchor measured from the canvas top; preview and render both use a
720x1280 canvas and 30px horizontal margins. Examples are not final translations.

and `node --check static/video-editing-ai-studio.js`.
