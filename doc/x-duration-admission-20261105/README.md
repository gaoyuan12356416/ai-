# X 长视频账号分配与提前校验

素材超过 1200 秒时，新素材池定时任务只从已配置、同语言、通过账号预检的会员账号中选择最终发布账号。短素材优先使用普通账号，保留会员容量；缺少会员容量时记录可重验的素材原因，继续扫描其他素材。新计划使用 `material-random-premium-direct-v2`，不再为普通账号新建素材池长视频转帖计划。短剧池及已冻结的历史转帖任务保持原合同。

手动发布保留明确的素材与账号配对。选择列表和配对区提示超过 1200 秒的素材；无会员或会员未知的账号不能勾选对应长视频。核对发布前刷新账号资料。服务端预览及首次提交分别读取可信账号/素材，使用 token 派生的 `subscription_type`（`basic/premium/premium_plus`）校验。账号素材池的添加预览、添加复验和调度复用同一校验；单条长素材不妨碍其他合格素材入池。Excel 保持逐行反馈。1200 秒整可用普通账号。

这只是提前反馈。最终上传仍核对实际媒体与当前 token 会员资格。已接受操作的幂等查询不受后续会员变化影响；不重写历史账号、队列、回执、预约，不自动补发截图里的失败任务。

验证覆盖时长边界、三种会员、未知状态、同语言范围、会员容量保留、无会员后继续短素材、提交前会员降级、原操作幂等和真实临时 SQLite 入池。前端 Node VM 执行实际配对渲染及请求生成，不调用 X。

部署：GitHub 提交后，服务器检出精确提交，运行 `scripts/deploy_x_duration_admission.py --phase prepare`，在返回的候选 release 上运行相关测试。然后 `--phase drain --folder BACKUP`、`--phase switch --folder BACKUP`。复用既有 X 范围排空，等待已接受任务正常结束，切换 X 服务并恢复原触发状态。仅同步相关主 API 文件与 Nginx 静态文件，不重启主 API、其他渠道或 GPU。

回滚：使用同一部署脚本 `--phase rollback --folder BACKUP`，等待其 `status` 无在途 X 作业后 `--phase switch --folder BACKUP`。只回滚代码；保留当前数据库、凭据、回执和发布事实。若排空尚未切换，可用 `--phase abort --folder BACKUP` 恢复入口。
