# X 受众与题材两级画像

2026-11-10 用户将画像改为“受众方向 → 题材”，取代此前的三级分配规则。剧类型不再参与收入分组、抽样优先级或兜底顺序。原始分类中的类型字段仅为历史来源信息；LGBTQ+ 仍按现有标签规则归类，本次不引入剧情简介推导。

频道列表展示两列：受众占频道总收入；题材展示收入最高受众下的前三项，占该受众收入。点击受众展开其全部题材，再点击题材查看贡献剧目。保留并行加载、当前弹窗树复用、50 条分页和磁盘查询副本。

同一频道所有类型的剧目合并到受众，再按各剧去重题材平均分摊。迁移从已核验快照中的唯一剧目收入重建，不能简单相加已四舍五入的旧叶子金额；收入、剧目数、发布计数与各层分币尾差保持一致。`ads_ai.x_channel_revenue_profile` 继续是权威存储，SQL 校验后发布新的只读 SQLite 索引。分类规则版本保持原版，画像结构版本为 `x-audience-theme-20261110-v2`，选择策略为 `revenue-audience-theme-weighted-v4`。

画像自动发布使用 `ProfileSelector`：先得到模板规则合格的剧目，按频道受众收入概率选择受众、再按该受众内部题材收入概率选择题材。按此顺序检查候选剧及其素材，素材排序、资格、语言、时长、防重仍遵循本流程原规则。同一受众/题材内本土和翻译不再有优先差别。

画像素材池使用同一个 `Decision` 给每个频道的合格素材排序。先同受众内放宽题材，无合格素材才改选其他受众并使用其题材偏好；频道无正收入或有效受众画像时沿用原排序，仅题材画像无效时保留受众偏好。排序结果不是每批固定配额，每次选材的随机顺序按任务与画像版本可重放。

执行阶段实际保留 ProfileSelector 类型并冻结 `tag_profile`。上线前只读核查最近 100 条已选材任务：45 条命中首选组合，53 条无正收入降级，2 条受众无效降级；任务 9000000000255 的冻结组合为本土/LGBTQ+/悬疑冒险，且已发布。素材池尚无冻结审计行，因此不宣称已有素材池真实发帖验收。

本地验证：55 项画像/存储/权限测试及 37 项实际选择器/执行器/素材池隔离测试通过；包括合并不同类型、2 层条件概率、类型不影响优先级、跨批候选不足兜底、缺失与负收入、实际执行保留画像选择器、冻结后不重选、50/25 分页及存储失败回退。前端异常/超时/重试测试及真实浏览器两级展开验证通过。

部署脚本 `scripts/deploy_x_audience_theme.py install` 从 GitHub 精确提交执行，复制当前线上运行时并只替换画像相关模块，保留统一制作发布调度及其他并行修改。短暂暂停画像选材触发器并等待对应在途选材，切换画像 Auto、网关及只读画像 API；不切换原发布服务、画像 Post 上传服务或统一协调器。已有冻结任务和历史审计保留旧版本，不重新选材；新任务采用新版本。

回滚：同一脚本 `rollback --backup <本次备份目录>`，恢复代码并从备份剧目事实生成旧结构的新画像版本。保留全部当前发布配置、任务、素材占用、防重、归因、平台回执和账本，不恢复旧业务数据库。
