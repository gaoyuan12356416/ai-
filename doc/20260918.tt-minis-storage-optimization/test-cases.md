# 测试范围

- 挂载 UUID、根盘路径、低空间拒绝。
- 源版本复用/变更/备份中变化，并发两个请求共享一次真实 SQLite backup。
- 租约、pin、历史源码引用、打开 FD、最近两份、修改后的文件身份保护。
- 7 天闲置回收、40 GiB 上限、不能安全释放时停止创建；未登记副本不自动删。
- 全部未变零读取零写入；历史回填只更新一个分区；空分区、文件缺失/截断重建。
- 编码版本变化全量重建；行数/刷新版本改变时旧 manifest 保持可读。
- 古老分区刚退出后仍保留满 24 小时；损坏存档禁止清理；路径越界拒绝。
- 原有数据查询、凭据脱敏、监控及浏览器缓存契约回归。
