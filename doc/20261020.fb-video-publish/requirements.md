# Facebook 视频批量发布

批准日期：2026-10-20。交互基准为已验收 V0.5；正式开发以 FB 运行版本
`41b5ca4f1e8f64945f56b2482e8e3dd96e2c9e89` 为基础，主 API/导航使用当前线上文件做定点集成。

## 用户目标

通过正式后台管理 Page 的剧语言及发布文案，多选 FB 素材、按剧语言分配 Page，
逐配对核对文案后立即或预约批量发布，并保留可追溯的任务、归因和平台回执。
新增权限 `fb_video_publish`，普通用户默认无权，管理员通过现有用户管理分配。

## 配置与身份

- 同租户 Page 配置共用，唯一键 tenant + PageID；访问仍受现有负责人 Page 池范围限制，
  候选固定 DramaWave 并按真实 Page ID 去重。界面不展示组。
- 第一次配置为空。支持批量创建、单独编辑、删除。配置记录剧语言、文案、实例 UUID、
  单调版本和更新人。编辑/删除携带实例和版本；冲突 409，保留输入。重建新实例。
- 删除只移除模块配置；不修改 Facebook Page、授权、既有任务或历史。配置预览使用示例剧目。
- 草稿按 tenant + user 隔离；任务持久保存。普通用户仅本人，同租户管理员可查看全部。
- 使用飞书 Cookie，校验 tenant/user、模块、导航及同源 JSON。服务端解析身份和邮箱，
  邮箱必须唯一映射有效 sub_user_id，管理员也无例外。已失去 Page 范围/映射仍可查询、
  取消自己尚未发送的任务；新提交必须重新授权。

## 素材与交互

- 固定 app_id=1479、product=Dramawave、data_source=6；有效未删除视频、剧集上架且到
  投放时间、黑名单、剧语言和安全媒体校验沿用 FB。列表不得触发选材排名或逐素材探测。
- 以主键游标分页，默认 50、最大 100；支持 ID、名称、剧名、剧语言，提交按所选 ID 批量 fresh 校验。
- 多选素材与已配置 Page，默认不选中。授权异常显示原因并禁选。显式按剧语言配对，
  可手动调整；任一素材未配对拒绝整批。每个素材 × Page 独立编辑、版本、任务、链接。
- 保留素材顺序，立即或北京时间预约，同 Page 间隔 0–1440 分钟、默认 0。
  0 仍串行上传，后序不因加工提前完成越过未完成前序。
- 默认不去重（original），可选真实随机加工（random_overlay），移除占位模板。
  每配对冻结独立 GPU job 和配方，恢复同 job，失败不降级原片。

## 提交和状态机

- 预检只读，不分配真实编号；返回短链占位、文案、长链参数、重复事实及有期限签名摘要。
  摘要绑定 tenant/user、完整配对/顺序/文案、素材和配置快照、加工、时间及重复指纹。
- 提交带稳定 operation_id；fresh 复核后单事务冻结整批、任务 UUID、账本 ID 和归因，
  使用真实短链展开文案并检查 5000 UTF-8 字节。任一错误回滚整批。
  响应丢失查原 operation，不创建新批次。
- 仅成功历史允许显式确认重发；活动或 unknown 无法覆盖，新重复事实要求重新预检。
- 单批最多 200 配对，新模块每日默认 1000，按计划发布日期的北京时间预留，
  不挤占旧自动日配额；GPU 共用原容量上限。
- 异步短链/GPU 完成必须核对 lease 与取消状态。链接文件不可覆盖、读回校验成功并且
  最终文案合规后才进入发布。每次执行重新读取 Page 授权；平台接受后持续对账，
  确认完成才标成功；结果不明禁止换 Token 重发。
- 实际 Page 占用、Page + 素材活动占用、unknown 阻断跨租户及旧/新入口生效。
  旧外部队列冲突继续阻止。错误不泄露其他租户任务。

## 链接与文案

落地页固定 `https://www.dramawavew2a.com/ads/101/2310/view`，
短链独立 `https://gy.g2flow.com/s2l/facebook/{ledgerID}.html`。不复用/覆盖编号和文件。
严格三宏 `{name}`、`{desc}`、`{url}`，后者为真实短链；拒绝非法花括号、来源缺失、
过长文案。宏值单次替换。旧自动 2049 和旧 GPU 合同不变。

| 参数 | 冻结来源 |
| --- | --- |
| c | yingliang_post_CLV_VL_facebook_PageID*记录创建秒none素材语言*剧名*标签或none*发布记录ID |
| af_adset / af_adset_id | Page 名称 / Page ID |
| af_ad / af_ad_id | 素材名_contentid[content_id] / 源素材 ID |
| af_channel | 发布人邮箱唯一有效 sub_user_id |
| af_c_id | 每配对独立 32 位任务 UUID |
| af_dp | 素材关联 content_id |

UTF-8 URL 编码保留星号分隔符。链接目标、身份和归因不得由浏览器提供。

## 架构、交付和验收边界

新 `features/fb_video_publish` 领域挂现有 FB sidecar，独立 worker，现有 operational
SQLite 新增表；不套用旧模板任务唯一约束。公共 `/api/fb-video-publish`，写入上限 4 MiB。
共享 QuickNav/UiTopbar，Facebook 分组按子入口权限可见。

验收包括 2 中文素材 × 2 中文 Page + 1 英文素材 × 1 英文 Page = 5 任务，
权限、隔离、CAS、多页选择、草稿、冻结历史、真实链接八参、幂等/重启/取消竞态、
未知结果和旧新并发门禁。模拟 Graph 完整测试；隔离 GPU prepare-only；
不额外发布真实 Facebook 验收帖子。布局 1440/820/390，真实 API 非空数据、登录、
导航、刷新、错误保留输入。

GitHub 提交推送后，数据盘备份代码/在线 SQLite/服务和定时器状态，复制数据库演练
增量迁移，逐文件部署；只重启主 API/FB sidecar并启用新 worker，保留旧定时器状态，
不部署 GPU 源码。回滚关闭新入口和 worker，恢复代码；保留数据库、短链和发布事实，
存在新活动任务时保留跨模块占用门禁。部署证据和回滚命令见 deploy/test-report。
