# 测试用例

## 测试范围

Page 管理、视频批量发布、发布记录，以及 API 权限/同源、数据隔离、幂等批次和 worker。UI 检查使用独立 localhost 浏览器及路由夹具，不调用 Meta、GPU、真实短链服务。UI 夹具通过不等于公网实发成功。

## 测试数据

两个中文 Page、一个英文 Page、一个授权异常 Page；两条中文素材、一条英文、一条西语，正常混合批次为 5 配对。素材每页 2 项触发跨页，配置扩到 23 项验证分页，记录采用 cursor。所有 ID、用户、example.invalid 链接均为夹具；注入 409/503、POST 响应断网及 operation 查404/恢复结果。
