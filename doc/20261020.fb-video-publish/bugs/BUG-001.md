# BUG-001 预览短链占位与严格宏校验不兼容

发现阶段：独立SA集成评审，未上线。

复现：Page文案含 `{url}` 时，service.preflight把中文占位交给
只允许 `https://gy.g2flow.com/s2l/facebook/{ID}.html` 的真实文案校验器，
导致所有含链接文案无法预检。

根因：预览文本与真实短链验证共用一个严格入口，却没有明确的预览模式。
修复：独立render_preview先按最大19位真实账本短链预算校验，再返回明确占位显示；
submit仍用分配后的真实短链在整批事务内最终展开验证。

影响文件：templates.py、service.py。
验证：source/link单元测试和service端到端预检回归；实际命令结果汇总于test-report。
