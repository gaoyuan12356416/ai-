# BUG-002 回滚不得移除已发布短链路由

发现阶段：独立SA部署评审，未上线。

复现：所有新任务均published后执行最初回滚脚本，代码恢复包含原Nginx域名配置，
会移除新短链snippet，历史帖文的短链返回404。

根因：将公网不可变链接路由当成可随代码撤销的临时资源。
修复：回滚检查fb_video_link是否存在记录；只要有记录，保留域名include和独立
Facebook短链snippet。始终保留数据库、编号和文件。

影响文件：scripts/deploy_fb_video_publish.py、deploy.md。
验证：部署脚本回滚保留条件单元验证及上线后只读Nginx路由验证，见test-report。
