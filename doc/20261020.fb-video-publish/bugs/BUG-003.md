# BUG-003 平台调用前缺少尝试记录且错误换Token范围过宽

发现阶段：root代码评审，未上线。

复现：初版只在Graph响应后写attempt；进程在请求发出后退出会无attempt证据。
同时任何definite_failure都会切换凭据，包括明确业务失败。

修复：begin_attempt事务持久化started并核对lease后才调用Graph；请求中断保留unknown。
仅明确credential_failure或授权错误10/102/190/200允许换Token，其他明确失败终止；
结果不明及任何已接受对象均禁止重新上传。

影响文件：core.py、worker.py。回归包括模拟Graph在调用时读取started记录、
授权拒绝、业务拒绝、空成功ID、网络未知及进程中断。
