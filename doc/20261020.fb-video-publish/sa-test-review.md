# SA 测试用例评审

## 结论

2026-10-20 本地集成验收通过：UI 71 项检查、核心服务与 worker 41 个用例、网关 9 个用例、内部查询代理 18 个用例、部署及回滚 7 个用例。核心服务和部署用例由主开发独立复跑；UI、网关、代理与回滚由本审查代理执行。上线后的登录态非空数据检查仍由发布负责人执行。

UI 采用隔离浏览器路由夹具，核心服务使用临时 SQLite 和 fake transport，网关、SQL、systemd 调用均模拟；这些结果不宣称已完成真实 Meta 发布或 GPU 实机加工。

## QA 修订确认

UI 测试驱动已修正三个非产品误报：等待CAS异步响应、展开details后检查长链目标、通过实际禁用输入而非fieldset的Playwright语义验证编辑锁。实际产品修正：首次提交草稿保存失败、batch POST尚未发送时应解锁；已有未知提交在重试中草稿保存失败仍保留锁定。未知提交重试直接复用原token与payload，不先预检阻断恢复。

后续综合报告须分别列出 UI 夹具、服务单测、部署只读验收与任何明确授权的真实发布测试，不合并为“全部上线成功”。目前待办仅为发布负责人执行实际上线、已登录 Chrome 非空数据验证，以及视授权执行的真实发布测试。
