# YouTube 日报按 campaign ID 更正

用户要求将群内 YouTube 发布人日报同步到 AI 后台的归属规则，并补发 2026-09-29 UTC 数据。

效果通过全局唯一冻结 campaign ID 关联后台自动发布和手动短链记录。支持源库 varchar(32) 截断别名，保持大小写；名称或 source channel 不参与归属推断。完整 ID、租户、人员或维度存在冲突时单列待归属。原始统计、频道负责人和长短链接不变。

发布量按昨日 UTC 已确认公开的 video_id 去重；生成手动链接不算发布。效果覆盖全部历史链接在该统计日的数据。金额按分守恒，缺失或失败不显示假零，YouTube 曝光仍未接入。

补发以固定 campaign-id-v2 更正版单独存档和去重，保留原日报、回执、投递账本。既有 11 点定时任务以后使用新规则。无主 API 或发布器部署。
