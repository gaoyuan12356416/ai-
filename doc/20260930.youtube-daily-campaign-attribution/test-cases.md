# 测试用例

## 测试范围

2026-09-30：独立 YouTube 日报冻结 campaign ID 归属、更正版隔离与幂等、原发布量及未知数据语义。网络与飞书发送均使用 mock。

## 测试数据

仅使用合成人员、租户、视频、campaign ID 和金额；临时 SQLite 模拟手动短链及发送账本。没有生产身份或金额写入测试。
