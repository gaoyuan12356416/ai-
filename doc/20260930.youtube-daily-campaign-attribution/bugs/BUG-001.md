## 根因分析

独立日报只扫描发布账本并要求 campaign ID 与名称完全相等，没有读取手动短链冻结归属，也不兼容源库 campaign_id 截断为 32 字符。AI 页面修复不会自动替换该独立 release。

## 修复说明

复用 AI 页面唯一 campaign ID resolver 和 catalog，纳入已发布手动短链，源 SQL 按大小写敏感 ID/名称分组。保留无法唯一归属的独立桶。
