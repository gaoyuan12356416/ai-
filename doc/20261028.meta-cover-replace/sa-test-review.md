# SA 测试用例评审

2026-10-28。离线重点覆盖错误删除、参数丢失、重复写入和崩溃恢复；真实平台验收单独列出。

| 补充边界 | 落实 |
| --- | --- |
| 成功绑定和清理入队间崩溃 | 同事务及回滚测试 |
| 共享意图提交、本地意图未提交 | 只读查询 API；禁止再次 DELETE |
| 归档引用与不完整分页 | Graph 与 worker 暂缓测试 |
| 部分扫描失败 | 仅无写入意图对象可重新归批 |
| 首批完成但扫描批次还有积压 | include_pending 通知测试 |
| 纯等待任务跨小时转批 | 不重复通知旧批次 |
| 晚到删除回执 | 新通知阶段，保留旧已发送快照 |
| 未知资源已有 ID | 同 ID/账户只读证明才允许依赖任务首次绑定 |
| 未知资源没有 ID | 不猜测对象、不重发 CREATE |
| 生产封面和吞吐 | 保留首批真实回执验收项 |

既有共享/延期/账户级视频 Store 回归 55 个通过。所有测试回执均明确区分离线与生产，不将 API 接受等同已确认删除。
