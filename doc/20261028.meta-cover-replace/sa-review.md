# SA 需求与设计评审

2026-10-28。结论：按已批准方案实施；生产完成需真实首批回执，离线通过不能替代。

| 事项 | 决策与落实 |
| --- | --- |
| 在旧 Creative 直接改素材 | 用户已批准创建/复用新 Creative 再绑定原 Ad |
| 触发后统计窗口滑出 | 证据和待办永久保留，继续小时反查关联 |
| 共享或归档引用 | 阻止删除，不修改额外 Ad；完整分页为前提 |
| 绑定成功后崩溃 | 成功与清理入队同事务，避免永远漏清理 |
| 两账本间崩溃 | 共享一次意图优先，读取 get_cover_delete_once 隔离，不补发 |
| 无法完整保留参数 | 明确失败，不补默认 URL 或丢字段 |
| 无可靠封面版本 | 限制在同批复用 |
| 旧清理队列 | 不导入重放，仅共享回执、锁及未知围栏 |
| 回滚恢复已删旧 ID | 不支持；保留最新账本，旧删除 timer 保持停用 |

产品直属关系和七类政策仍由原有解析判定，不凭名称、账户归属扩大范围。SQL 继续只读 FIFO Gate；不完整来源不得作为写入依据。
