# Frozen legacy cleanup ledger

The cover deployment installer automatically preserves the legacy ledger in
place when configuration and both legacy units prove that workflow is disabled.
It no longer requires an optional CLI flag to avoid another complete copy on
every deployment. Active cover/shared ledgers retain their existing snapshots.
When the legacy workflow is not proven disabled, default behavior still takes
its snapshot; explicitly requested active-only mode retains its existing guard.

This patch changes no worker, queue, business rule, or runtime ledger. Deploy
the exact child release of the current cover release, then update its `current`
symlink after checking it has not changed. No service restart is necessary.
Rollback restores the previous symlink; never restore historical ledger files.

Validation: installer and worker-installer tests (12 tests), diff check.
