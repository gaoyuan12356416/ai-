# BUG-003: hidden manual dialog polluted existing modal selectors

Status: fixed. Existing schedule/loading browser cases used generic modal selectors and found the closed manual dialog as a second match. The manual dialog is now attached only while open and detached on close, retaining its DOM/state object for late result recovery. No edits to the existing browser tests were needed. Schedule 38 and loading-race 10 checks passed after the fix.
