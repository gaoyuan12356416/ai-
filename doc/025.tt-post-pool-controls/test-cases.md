# 测试用例

## 服务端

- 已启用排期可在缺少新 consent、creator-info、账号设置或正式门禁时关闭；只更新 `enabled/version/audit actor`，保留时间和历史 consent。
- 已关闭排期以当前版本重复关闭时幂等返回。
- 不存在排期且 `expected_version=0` 时返回默认关闭态，不创建伪造 consent 的记录。
- 错误版本关闭返回 `tt_post_schedule_version_conflict`。
- 重新开启仍执行账号、设置、creator-info、时间和 consent 的完整校验。
- 关闭后自然 due 不创建队列、不消费待发素材。
- 账号消失、被禁止发布或 Token 失效时，accounts 返回匿名管理占位，schedule 可读可停但不能重启用。
- 账号源整体故障时仅返回本地排期占位和固定通用 warning；无本地排期时为空且不能新建。

## 页面

- 取消自动发布后，无需勾选发布确认即可提交关闭；按钮和提示清楚说明素材保留。
- 开启或修改时间仍受原有校验约束，并显示具体错误。
- 后台 gate、账号或制作状态刷新不覆盖未保存的开关和时间。
- 保存期间锁定时间、开关、账号选择和账号刷新；旧 GET 不能覆盖 POST 结果。
- 409 冲突清除旧草稿并加载最新版本；普通失败保持原草稿和旧版本。
- 已选但失效的账号仍能保持选中用于关闭。
- `preparing -> ready` 会触发一次排期事实刷新；返回可用素材后手动发布按钮自动开放。
- 排期事实刷新瞬时失败后下一轮继续重试；账号级汇总变化即使对应条目不在前 100 行也能触发刷新。
- 制作中但尚无可用素材时按钮保持禁用，不得提前发布。
- 无制作任务且无可用素材时显示“暂无可立即发布素材”。

## 生产只读验收

- 公网页面、CPU sidecar、AI 后台、runner/prepare timer 和 CPU 到 GPU 隧道健康。
- 三份 TT 页面文件哈希一致且公网响应禁止缓存。
- 在登录态页面取消自动发布开关后，保存按钮可用；执行只读刷新后草稿态不被覆盖。随后刷新整页丢弃草稿，不提交保存。
- 正常账号源显示已加载；降级 warning 的自动化合同通过，生产不主动制造账号源故障。
- 已完成素材在只读刷新后计入可立即发布数量；不点击“立即发布一条”。
- 验收前后 schedule、queue、run、publish ID 和 GPU ledger 没有由本次验收新增。
