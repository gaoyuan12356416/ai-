# 配置契约

无新增业务API。RANDOM_OVERLAY_ASSET_CATALOGS为服务端JSON对象，键是64位小写SHA256，值是绝对资产根目录。默认root与manifest SHA继续使用各服务现有环境变量；helper仅选择目录，原loader仍检查manifest及每个素材。

CPU：DRAMA_RANDOM_OVERLAY_MANIFEST_FILE、DRAMA_RANDOM_OVERLAY_MANIFEST_SHA256。
Drama GPU：DRAMA_RANDOM_OVERLAY_ROOT、DRAMA_RANDOM_OVERLAY_MANIFEST_SHA256。
TT GPU：TT_POST_GPU_RANDOM_OVERLAY_ROOT、TT_POST_GPU_RANDOM_OVERLAY_MANIFEST_SHA256。
FB GPU：FB_PAGE_GPU_RANDOM_OVERLAY_ROOT、FB_PAGE_GPU_RANDOM_OVERLAY_MANIFEST_SHA256。
