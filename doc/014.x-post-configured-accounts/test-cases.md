# 014.x-post-configured-accounts 测试用例

## 测试范围

账号配置解析、双 env 一致性、动态批次、同日计划冻结、账号 DTO/UI、全批预检、原子预留、全局去重、未知结果和零补发部署门禁。

## 测试数据

- 全部使用虚构账号、素材和 X 响应 fixture；单元测试不得调用真实 X。
- 配置集合覆盖 1、3、9、50、51 个账号。
- 同日恢复 fixture：已有 3 条已冻结 queue，随后运行配置扩至 9 个。
- 生产验收只记录账号行 ID/数量与安全状态，不输出用户名或 Token。

## 回归范围

- X OAuth 授权、校验、Token 刷新和退出。
- 素材池 FIFO、合规、GPU 修复及全局排重。
- 三账号历史计划读取兼容。
- queue/log 状态机、短链和 Post 预览链接。
- timer/start-date/锁、SQLite 完整性和日志脱敏。

所有用例当前仅为评审后的计划，执行结果以 `test-report.md` 为准。
