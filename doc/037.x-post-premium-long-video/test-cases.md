# 测试用例

## 测试范围

账号字段、迁移、会员枚举、素材时长边界、混合账号分配、GPU 修复、上传类别、发布前失效、UI/DTO、回归和生产无意外发帖。

## 测试数据

- 账号：`none`、`basic`、`premium`、`premium_plus`、`unknown`，均覆盖批准/未批准和 active/非 active。
- 视频：139.0、140.0、140.001、150.0、600.0、600.001 秒；H264/AAC 合规与需要 codec/dimension 修复两类。
- 批次：非会员+会员混合，素材按短/长交错的最新优先顺序。
