# BUG-001 素材选择器过滤长视频并重排为最旧优先

## 状态

已修复。

## 现象

素材池存储层返回 `created_at DESC,id DESC`，但 `selector.py` 再次按升序排列；同时素材详情 SQL 使用 `video_duration BETWEEN 1 AND 140`。结果是 140 秒以上素材无法进入账号感知预检，最新优先合同也可能在计划事务前失配。

## 根因

素材池排序合同已升级，旧选择器和旧视频时长参数未同步。

## 修复

- 素材源查询上限统一为 600 秒。
- 池候选按 `(created_at,id)` 倒序水合。
- 更新素材池、补发和选择器测试夹具，并验证完整 X 回归。
