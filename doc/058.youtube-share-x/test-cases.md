# 测试范围

1. Cookie缺失/API Token/跨租户跨用户/双模块权限/跨站JSON/重复Content-Length拒绝，不写平台。
2. 精简DTO公开标志；未公开、无效video_id、频道不符、YouTube空列表阻断；已公开视频首评失败可分享。
3. 六种宏、单次替换、未知/缺值/格式、超长/控制字符、CJK/NFC/emoji/非标准ZWJ与链接追加。
4. 1–20账号、停用/未批准不能选择、无需Premium、陈旧预览不可提交、光标和文本保留。
5. 操作UUID重放/冲突、跨操作视频账号去重、明确失败后人工新操作、审计历史。
6. 并发创建/领取、最终账号检查、发送前记录、超时/5xx/无效返回未知、重启恢复且不重发。
7. 已发送后台账暂不可写，存储恢复仅保存结果，不再请求X；不得永远停留处理中。
8. 部分成功/重复/危险URL与XSS；关闭重开/网络未知不自动提交；首次明确409可修改，未知后的409仍锁定。
9. 部署版本哈希、健康、触发器恢复、匿名路由拒绝和真实浏览器预览。禁止用真实发帖完成此次验证。
