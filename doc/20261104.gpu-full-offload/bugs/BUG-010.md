# BUG-010 native 子进程强制退出时 mux 临时成片留在父 scratch 外

状态：代码路径已修复，父进程清理控制测试通过；真实GPU卡死不作破坏性模拟。严重性 P2，静态审查确认。

原 native_pipeline 将最终output路径直接交给CudaMP4，其mkstemp位于output.parent。若watchdog kill子进程，子进程finally不会执行，父进程只能清理自己管理的scratch，隐藏mux临时成片会留在外面。

修复：native_pipeline先mux到父进程拥有的scratch/finished.mp4，成功后才os.replace到最终output。scratch及其中临时mux文件由run_render的ExitStack在kill+wait后清理。

验证：独立运行`test_native_pipeline_control.py`5/5通过，包含总超时、继续进度、旧进度及scratch清理。该替身进程测试不是实际CUDA驱动挂死实验；代码审查确认真实mux中间文件现归scratch所有。
