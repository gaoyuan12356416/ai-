# BUG-013 HEVC 参数集允许只有 NAL header 的空 PPS

状态：已修复并真实 GPU 回归。严重性 P2，容器配置边界校验错误。

复现：独立构造合法范围的 VPS/SPS 前缀，PPS 仅两个 header 字节 `44 01`，无 RBSP；`hvcc_config` 的旧长度下限是2，因此将空 PPS 序列化为完整 hvc1 参数集。`scripts/test_gpu_hevc_mux_boundaries.py` 首次8项中该用例失败，长度为 `[22,25,2]`，其余7项通过。

修复：VPS/SPS/PPS 至少3字节，要求存在RBSP；同时保留最大65535及SPS位字段完整性约束。不将这项检查描述为完整HEVC语义验证。

复测：最新9/9真实GPU通过（2.928秒），覆盖空PPS、缺失/重复/过长/截断参数集、VPS保留子层数、single-layer约束、PTL/子层profile/level/EPB/conformance window、精确hvcC数组及IRAP key。原H26414项同时通过。12帧真实HEVC重封装前后严格全解码1,105,920 bytes且SHA相同，证据 `qa-hevc-mux/result.json`。

本组件只接收当前单层编码器的单VPS/SPS/PPS，不是任意多层HEVC解析器。新增VPS/SPS最大时间层合并及多层拒绝由独立边界测试覆盖。
