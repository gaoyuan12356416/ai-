# BUG-005 MP4 临时文件竞争时清理了其他写入者文件

状态：已修复并文件生命周期回归。严重性 P1，静态控制流确认。

原实现固定 `.mux-tmp` 名，先 exists 再 open(xb)，finally 无条件 unlink。如果另一写入者在检查后创建该文件，本次 open 会失败，随后 finally 仍会删除其他写入者的临时文件。旧实现未作线上并发故障复现。

修复：mkstemp 原子创建唯一临时文件，只清理自身创建路径；完成 flush/fsync 后原子替换输出。失败与取消保留原输出。

影响：`features/random_gpu/gpu_mux.py`。验证：独立 `test_truncation_and_cancel_preserve_output_and_foreign_temp` 预建他人 `.mux-tmp`，在截断和取消后确认其字节不变、原输出不变、自身临时文件已清理。全套 mux 9/9，2.027 秒。未启动生产并发任务。
