# BUG-014 AAC esds 码率描述固定为192k，无法准确描述X128k音频

状态：已修复并真实GPU表级回归。严重性 P2，容器描述字段错误，不是音频内容被改成192k。

审查确认 `CudaMP4.sample_entry` 旧实现无论音频包内容和目标配置，均写 `maxBitrate=192000, avgBitrate=192000`。X编码器实际目标是128000，短片实测sidecar和AAC包亦按该目标生成；固定esds值不能描述它。

修复：最大码率不推测，写0表示未知；平均码率由CUDA按完整编码包字节总数×8×媒体timescale/媒体duration计算（包含priming媒体时钟），不将编码器target伪装成实际average。

验证：新增独立esds解析用例，音轨包长31+33 bytes、duration1024+512、timescale48000，期望字段 `max=0, avg=16000`；真实GPU精确通过。原H26414项、HEVC9项与真实HEVC重封装通过。最终完整X/FB/TT验收继续使用原输出内容、音轨、时长和大小检查。
