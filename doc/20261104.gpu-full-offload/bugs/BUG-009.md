# BUG-009 重封装验证器 seek(0) 丢失极短 AAC priming 包

状态：已修复并独立真实音频包复验。严重性 P2，仅测试验证器。

`validate_gpu_mux.tracks_from_mp4`每轨复用同一container并seek(0)。0.01秒真实FFmpeg文件含AAC负PTS priming包，但seek后只取到PTS0的1包，无法忠实验证完整原始包集合。

修复：每条轨道重新open文件从头demux，不seek(0)。

验证：0.01秒参考现在取到2包，first PTS/DTS=-1024、有效展示结束480/48000秒；`qa-duration-gpu.json`三组通过，原2秒文件155packet元数据/解码哈希保持一致。不得把原来少取包结果记为源片没有priming。
