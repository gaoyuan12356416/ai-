# BUG-001 SHA 异常后错误复用

状态：已修复并独立回归。严重性 P1，发现于隔离 GPU 故障注入。

`CudaSHA256.update` 原先在设备上传成功前修改 total/pending；模拟一次分配失败后重试同一 128-byte 数据，得到摘要与 hashlib 不同。另将 final kernel 实际运行完成后包装为抛错，重试 hexdigest 会二次 padding，返回错误摘要。普通文件 wrapper 会直接传播错误；此问题出现在调用者捕获错误并复用对象时，未认定生产已输出错误文件摘要。

根因：状态变更与不可确定完成状态的 GPU 调用之间没有失败状态协议。修复：成功后提交主机状态，任何运算异常后将对象标为 broken，后续调用明确拒绝。

影响：`features/random_gpu/gpu_compute.py`。验证：`scripts/test_gpu_compute_failures.py` 中 allocation failure、unknown final completion 两项在修复前失败，修复后通过；全套 7/7，0.964 秒。测试在隔离 venv，无生产变更。
