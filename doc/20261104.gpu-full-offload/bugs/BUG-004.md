# BUG-004 MP4 接口强制常驻整片压缩数据

状态：接口已修复；整体验证仍需观察实际调用和 RSS。严重性 P2，静态审查确认，不是实测 OOM。

原 `Sample.data` 仅为 bytes，完整 Track.samples 保留全片 encoded payload；all_samples 再保留引用，直到 mux 完成。长片乘多任务并发会随总文件大小增长，不能用短片的低内存结果证明稳定。

修复：增加不可变 PacketFile(path,offset,size)，支持编码时落 spool，mux 按偏移读最多 1 MiB；metadata 仍按 sample 数增长。生产调用必须实际用 PacketFile 才能获得收益。

影响：`features/random_gpu/gpu_mux.py`。验证：独立 `test_packet_file_matches_in_memory_output` 对 PacketFile 和 bytes 输出逐字节比较相同；truncated source 明确失败且保留旧输出。全套 mux 9/9，2.027 秒。没有执行导致内存耗尽的试验。
