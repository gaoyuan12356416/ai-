# BUG-007 Annex B 长度数组混合类型导致 GPU 越界

状态：已修复并独立真实 GPU 回归。严重性 P1。

独立测试 `test_annexb_mixed_prefixes_preserves_escaped_payload_and_key` 输入仅六个短 NAL（SPS/PPS/AUD/SEI/IDR/P），在 `annexb_sample` 的 result.get 复现 `cudaErrorIllegalAddress`。同一测试进程后续 CUDA 调用均受 context 错误影响，不是多个独立错误；测试进程已退出，没有重置 GPU。

根因：`sizes`/`lengths` 为 int64，而 `cumsum(...,dtype=uint64)-lengths` 混合有/无符号 64 位会得到 float64。RawKernel 将 dest 作为 unsigned long long 指针读取，浮点位模式被当成巨大 offset，越界写入。

修复：将 lengths 明确转成 uint64 后再计算前缀与减法，确保 dest 的实际 dtype 与 RawKernel 声明匹配。

影响：`features/random_gpu/gpu_mux.py::annexb_sample`。验证脚本：`scripts/test_gpu_mux_boundaries.py`。在新测试进程复测 14/14 通过，1.402 秒，含原来触发越界的混合六 NAL 用例。没有重置设备或触碰生产服务；真实 NVENC AU 集成验证由根代理承接。
