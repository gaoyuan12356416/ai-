# BUG-003 SHA 构造器异步初始化跨流竞争

状态：已修复并真实 GPU 回归。严重性 P1。

复现：nonblocking stream 中排入短 GPU 延迟，再构造 CudaSHA256；返回默认 stream 对 `b'different-stream'` 更新并取摘要。初始状态 H2D 复制未完成，原实现稳定得到错误摘要，预期为 `399d90661a7aa4923ca977806e49724d14d0a28db7d74afa38bb449c19e5a596`。

修复：构造器在 state 上传后同步当前 stream，确保对象发布时状态可用。update/hexdigest 通过同步及对象锁保护后续状态。

影响：`features/random_gpu/gpu_compute.py`。验证：`scripts/test_gpu_compute_failures.py::test_state_initialization_is_ready_across_nonblocking_streams` 修复前失败，修复后通过；全套 7/7，0.964 秒。延迟仅单线程短时 kernel，不重置设备。
