# BUG-002 SHA/CUDA 对象没有进程归属检查

状态：已修复并独立回归。严重性 P1，发现于代码审查与模拟 PID 变化测试。

初始化 CUDA runtime/digest 后模拟 os.getpid 变化，旧实现仍允许调用，可能使用 fork 继承的 context、缓存与锁。未在生产或实际 CUDA 子进程执行危险继承实验。

修复：runtime 和 digest 均记录创建 PID；进入 CUDA 或获取对象锁前检查，明确抛出继承进程错误。

影响：`features/random_gpu/gpu_compute.py`。验证：`scripts/test_gpu_compute_failures.py` 中 digest/runtime inherited process 两项通过；全套 7/7，0.964 秒。此测试验证拒绝分支，不声称验证了跨进程共享 CUDA 的可行性。
