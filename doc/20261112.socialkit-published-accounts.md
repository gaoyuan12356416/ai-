# SocialKit 发布账号数

总览和发布执行新增 `published_accounts`（发布账号数），用于 KPI、分组明细、每日趋势、排行、排序和 CSV。收入效果视图不显示此指标。

口径：查询日期及筛选范围内至少有一次成功内容（`success > 0`）的稳定账号键数量。账号键为团队、平台、外部账号 ID；资料缺失沿用采集层的 SocialKit account ID 回退。跨天、剧目、产品重复发布在总计中只计一次，每个分组独立去重，不将分组或每日数量相加。已同步无记录为 0，未同步为缺失。沿用账号当地 `schedule_date` 和当前成功快照，不增加数据库迁移、源库查询、回填或发送。

查询和选项预计算增加版本校验，旧预计算自动回退计算，新预计算保留快速读取。
