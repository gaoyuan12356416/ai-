# BUG-001 X 发布失败与积压恢复

2026-11-03 生产回执核对发现多种独立问题，不把它们归为同一个平台故障：

1. 4 个自动任务已有唯一成功 Post，但任务展示没有同步。修复按原回执校正，并在后续同步路径收敛状态，不重新发帖。
2. 大媒体上传在 APPEND 阶段写超时。原始节点回执明确网络写超时且未到 Post。修复媒体专用超时/分片设置、独立 lease 心跳，并用精确下一代授权恢复已知失败。Post/Repost 超时和单次调用边界不放宽。
3. 源下载和内部归因只读请求偶发失败。增加有限的只读网络重试，明确拒绝与身份/内容验证失败不重试。归因重试发生在冻结短链和任何 X intent 之前。
4. 短剧候选含已被历史队列占用的 episode_key，真正建计划时被原子守卫拒绝。selector 提前排除占用，保留事务守卫和旧队列；不通过清除历史或推进集数恢复。
5. 选材期间账号可用范围变化，导致冻结快照的 FIFO 容量证明不再匹配。写入前重新验证完整原账号范围，最多有限次重建 proof，身份及快照不变。

旧未知结果、账号语言真实不一致及平台临时锁定另行处理；它们不能通过清零 attempt 或批量失败重试修复。两个账号解锁由用户确认，其他账号需独立核实。

影响与验证见 prepost-recovery.md、attribution-recovery.md、drama-episode-recovery.md、test-report.md。第一轮已收到真实新成功回执，第二轮部署与最终积压计数仍待上线验收追加。
