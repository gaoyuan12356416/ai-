# 测试用例

## 测试范围

回执可信性、无重复发布、计划漂移与事务、旧手动任务精确授权、媒体请求超时及独立心跳。

## 测试数据

使用临时 SQLite 数据库和 HTTP/发布接口替身，不调用真实发布接口。线上精确任务 ID、账户信息和数据库快照保存在私有计划，不作为仓库测试数据。
