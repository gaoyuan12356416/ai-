# 测试用例

1. DELETE使用冻结账户advideos路径和video_id参数；每attempt一个DELETE，无先行Meta GET、无Page凭证、无Token轮换。
2. 新预览精确来源用户优先于产品默认用户；旧预览凭冻结广告/产品/账户精确恢复；失败沿用原候选；命名空间/跨产品/跨账户不混用。
3. 一个Video关联A/B：A失败B成功；重试仅A。A的成功pair不跳过新任务B。
4. 单账户未知继续后续账户；重复提交不重发；结果未知在GET完整证明缺失前不可重试。
5. 重启保留成功、仅在途变unknown、未发送账户可人工恢复；核实A不把B标记成功。
6. 账户尝试/凭证审计先于DELETE；台账不可写立即停止。凭证不进入响应、SQLite、日志、前端。
7. Creative/Ad/Video任意阶段组合保持原顺序及失败继续规则。旧Post、旧成功结果保持。
8. 前端展示账户范围、各账户状态与诊断，成功文案限定账户素材；旧任务兼容，普通确认、分页、无额外门禁。
9. 部署双静态/hash/登录ACL/主API健康，原对象与尝试逐行保持；新表仅为空的添加。
