# Page 管理列表加载修复（2026-10-20）

用户录屏显示进入 Page 管理后表格长时间空白。此次仅修复加载路径，保持素材池、任务、短链及发布规则。

## 原因与改动

- 前端原先串行等待登录、导航配置、剧语言、Page 列表。现保留登录/模块校验，导航独立刷新，语言与 Page 列表并行；列表具有加载、失败及重试状态，刷新失败保留已有行。
- 3 个已配置 Page 原先先统计 40 个组，再读取 2,237 条成员记录、2,186 个真实 Page。现先读取本租户配置，只查询对应 Page 的有效组成员、名称及当前授权；空配置不查询远端 Page 来源。创建候选列表也不再执行无用的组汇总。
- 仅管理员的 `GET /pages` 与 `GET /pages/available` 不再查询无用途的发布人归因映射。管理员访问范围本就不使用负责人过滤。登录、模块/导航权限、租户配置隔离仍执行；普通用户读取、所有写入、预检/提交、池启用及执行前身份核验保持不变。
- 保持现有只读副本、SQL FIFO Gate、超时与容量限制；无授权缓存，无数据库迁移。
- 每个定向查询最多 200 个 ID，最多 20,000 条来源记录，保留 Page ID 去空格及真实 Page 去重语义。
