# 剪辑工作台：资源管理、免费集与字幕保护镜像

用户在2026-10-29确认实施。四栏目：工作台、免费集、素材库、制作任务。每条新上传必填一个资源，免费集不要求集号；保留多资源单元分别出片，任意同资源来源组合、单片段也可制作。

## 最小门禁
保存只校验结构、项目权限和版本；未选资源、未就绪、缺标签和剪辑范围问题保存为单元提示。正式制作逐单元检查，坏单元不阻断其他单元。英文名缺失不阻断准确资源ID；入库语言只在点击入库时要求。保留权限、凭据、数据归属、幂等及未知结果保护。

## 资源与数据
series_code是资源ID而非content_id或素材ID。按不透明字符串精确匹配，英文名来自ads_drama_info英语行，名称完整/前缀搜索使用现有name索引。缺失/冲突明确显示；排除占位值。上传源仍kind=asset，增加library_kind和series_code，SQLite增量列索引；不改变MySQL结构。

v2项目{name,schema_version:2,units:[{id,series_code,title,clips}]}。素材/免费集/在线剧集按资源选择；每单元独立任务。旧草稿仅GET提供upgrade_units，首次用户修改后保存新版本，历史快照任务不改。素材改标签不影响冻结任务。

## 镜像
片段mirror默认false；开启默认字幕带top960/bottom1280，null为无保护。保护区域的文字和背景都保持原样；区外字幕会镜像。坐标基于最终720x1280且为偶数像素。先适配、镜像、覆盖同帧原字幕带，再拼接转场。浏览器两路解码+Canvas，使用预览代理几何避免黑边错位。

## 入库
新资源任务入库时选择该资源的来源产品/语言content_id，服务端验证并冻结至原单输出账本；目标产品3214、分类dramawave_post不变。旧任务和既有入库账本复用。
