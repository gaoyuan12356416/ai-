# 验收用例

- 资源：精确ID/特殊符号、英文名称前缀、无英文名/多英文名；空目录/超时提示不影响已有草稿。
- 上传：两栏目分类、强制新标签、旧会话续传/幂等、标签修改权限及冻结任务不变。
- 草稿：空单元、未选资源、未就绪、范围错误都可保存重开；结构/权限/版本错误保持拒绝。
- 制作：免费集单片段、素材单片段、多个来源、多资源输出；错误单元局部失败；同操作重放、新操作复用、并发提交与修改标签竞争。
- 旧版：草稿读取不改库，upgrade_units可编辑；历史版本、任务、结果及恢复指纹保持兼容。
- 入库：目标选择缺失/错资源/正确版本；与在线剧集无关；既有账本忽略重选且不重发。
- 镜像：底部/顶部/多行字幕带、全镜像、切割复制撤销；同帧像素比较、渐变转场；SAR/旋转/横竖源/预览代理与contain-cover。
- 浏览器：四栏目、上传资源选择、资源前置、多单元勾选及局部重试、保存重开、字幕带拖动、慢请求/未知响应与草稿保留。
- 发布：GPU双profile双recipe、CPU增量迁移、旧账本hash、静态双副本与公网、无关服务状态。
