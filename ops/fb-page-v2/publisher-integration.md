# 发布系统接入香港 Page 画像 V2

发布机通过内网发送 `POST http://10.89.0.125:8944/api/integrations/v2/drama-page-assignments`，使用现有画像分配接口的 Bearer 和 `Content-Type: application/json`。可从发布机用 `GET http://10.89.0.125:8944/healthz` 检查连接。选页接口只计算并记录 Page 决定。

## 业务请求

直接传入队列 ID、剧 ID 和 Page 池即可调用，不要求先创建发布任务或建立队列素材关系。单次接受 1 至 100 个剧 ID，超过 100 个时分批请求，同一队列的各分片沿用相同队列 ID。返回数组保留输入次序与重复项，便于发布方逐项对应。

```json
{"external_task_id":"3092716","page_group_id":24,"drama_ids":["dqoMUlYLBQ","fhU2HzaYUX"]}
```

`external_task_id` 传稳定的队列 ID，为 1–128 字符非空字符串；数字及原有 cross/native 格式均可，不查询或校验其对应发布队列。不同队列须使用不同 ID，不能为同一队列的不同分片或重试更换 ID。Page 池必须存在、未删除且属于支持的产品；以池所属产品解析传入剧 ID 的语言和画像，不跨产品混用，也不改写传入池。只选择池内状态正常且具备 Page 权限的成员。Bearer、来源机器校验仍然有效。

业务去重唯一键为 **队列 ID＋剧 ID**（本地 `queue_drama` 表的联合主键）。同一队列同一剧复用第一次保存的 Page 决定，包括无匹配时的 `null`；换分片、顺序、重复次数或并发重试都不会重新产生不同结果。不同队列独立选页。数据库事务保证并发情况下只保留一份有效决定。Page 池不参与唯一键，但同一键请求不同池时返回 409，避免复用其他池的 Page。

完整 HTTP 回执单独保存：相同请求重试返回同一 `task_id`，不同分片可以产生不同 `task_id`，其中重复剧仍复用同一 Page。审计键附带请求指纹，长队列 ID 使用哈希短键；诊断快照保留原 `external_batch_id`、`queue_id` 和每个剧决定的来源 `pair_sources`。请求指纹只用来追踪回执，不是业务去重条件。

上线前已发出的整批回执保持原样。重试相同旧请求仍返回原结果；新分片涉及已有剧时，采用原回执中该剧第一次出现的决定，不改写历史已发出的 Page。旧回执中同一剧曾分配不同 Page 的历史事实也保留。

成功响应含 `task_id` 和 `results` 数组。每项的 `drama_id` 与输入一一对应，有画像匹配时 `page_id` 为字符串，无匹配时为 JSON `null`。开发端逐项处理，命中项采用返回的 Page，空项沿用发布后台的兜底策略。保存返回的 `task_id` 及最终实际发布 Page，方便对账。

| HTTP | 发布方处理 |
|---|---|
| 200 | 读取全部结果。同键同内容重复调用返回最初的决定和 task_id。 |
| 400 / 413 | 核对请求字段、编码、批大小和请求体大小。 |
| 401 / 403 | 核对 Bearer、来源机器，以及 Page 池是否存在、未删除且属于支持的产品。 |
| 409 | 同一队列同一剧已使用其他 Page 池，请核对队列 ID 和池；原决定保留。 |
| 503、连接中断或超时 | 保留原队列 ID，在调用方剩余时间允许时按原内容重试。已落盘的决定可以读回。 |

给一次 HTTP 调用预留至多 50 秒，包括连接和读取响应。服务端业务处理预算 47 秒。任务级重试沿用相同队列 ID。发布方执行降级时记录原因与最终实际 Page。

## 飞书异常通知

香港能收到的请求异常由 V2 上报。若发布机连不上香港或读取响应超时，请从发布进程通过独立 HTTPS 接口 `POST https://ai.yingliangads.com/api/integrations/v2/drama-page-alerts` 上报，鉴权方式相同。郜远收到首次故障、同原因五分钟汇总与恢复通知。示例和事件幂等规则见 [告警接入说明](alerts-integration.md)。

香港审计表为 `ads_ai.fb_drama_page_assignment_log`，每笔 V2 决定用 `v2_` 开头的 task_id。条目按 `item_index>0` 查询，`item_index=0` 用于请求头或共享快照。后台确认 MySQL 条数、版本和哈希后释放本地详情和已确认快照，保留原结果及回执供重试。
