1. 配置新 App

在 X 开发者后台 进入新 App → Settings → User authentication settings，启用 Read and write，类型选 Web App, Automated App or Bot。

Callback URL 必须完整填写：https://ai.yingliangads.com/x-oauth/callback

Website URL 可填 https://ai.yingliangads.com。保存后在 Keys and tokens 的 OAuth 2.0 区域找到下列两项。

2. 登录一个测试账号

点击后进入 X 官方授权页面，确认当前登录的是你准备测试的账号，再点击授权。成功后会自动返回这里。

仅在专用测试浏览器中完成授权。它会在本机接住这次回调，交给隔离环境，线上服务不会收到测试授权。

3. 验证新 App 与账号

应用检查会读取一次 XDevelopers 公开账号；账号验证会读取刚登录账号的身份与会员状态。API 读取可能计入新 App 用量。
