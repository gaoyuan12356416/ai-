指标口径与数据说明

归因：效果源表的 campaign ID 按渠道关联发布记录或手动短链账本中的 af_c_id，采用记录冻结的人员、账号和剧目信息。归属冲突的数据单列待归属，不通过名称或 af_channel 推测归属。

成功发布：YouTube 按确认公开的视频去重；X 按确认完成的目标账号发布去重，分为 Post 与 Repost，中转源 Post 不重复计数。手动短链只计效果，不计成功发布。Post / Repost 仅适用于 X。

点击 / 访问：落地页点击次数与访问次数，不代表社媒曝光或视频播放量。效果指标统计全部历史链接在所选日期产生的效果。

安装 / 付费转化：付费转化为源表充值人数，所选日期的每日人数相加，跨日不去重。安装率 = 安装 ÷ 点击；付费率 = 付费转化 ÷ 安装。分母为 0 或数据未知时显示「—」。

收入 / 退款：金额单位 USD，分别展示，不自动冲抵。

生成链接数：当前筛选下，在所选 UTC 日期内创建的有效链接数量；与效果指标按效果发生日期统计的口径不同。

数据完整性：未同步或不可用数据不按 0 统计；不完整的合计仅包含已有渠道和日期。待归属、明确排除项不计入人员合计，单独核对。管理员查看同租户数据，普通用户仅查看本人数据。
