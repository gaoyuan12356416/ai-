指标口径与数据说明

点击 / 访问：落地页点击次数与访问次数，不代表 YouTube 曝光或视频播放量。效果指标统计全部历史链接在所选日期产生的效果。

安装 / 付费转化：取自归因报表；付费转化为充值人数，所选日期的每日人数相加，跨日不去重。安装率 = 安装 ÷ 点击；付费率 = 付费转化 ÷ 安装。分母为 0 或数据未知时显示「—」。

收入 / 退款：金额单位 USD，分别展示，不自动冲抵。

生成链接数：当前筛选下，在所选 UTC 日期内创建且已发布的短链数量；与效果指标按效果发生日期统计的口径不同。

数据完整性：未同步日期显示「—」，不作为 0 计入；存在缺失日期时汇总仅包含已有日期的数据。未匹配数据不计入可归属的报表指标。管理员查看同租户数据，普通用户仅查看本人数据。
